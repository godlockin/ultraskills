# User Persona Generator

**ROI:** 8.5/10 - Saves 4h → 30min creating data-driven personas

Transforms user research into actionable personas for product/marketing decisions.

## Persona Template

**Name:** Sarah the Sales Manager
**Age:** 35-45
**Role:** VP Sales, Mid-Market SaaS
**Company Size:** 50-200 employees

### Demographics
- Industry: B2B SaaS
- Revenue: $10-50M
- Team size: 5-10 AEs

### Goals
1. Hit quarterly quota (primary)
2. Reduce sales cycle time
3. Improve forecast accuracy

### Pain Points
1. Manual reporting (10h/week wasted)
2. Poor pipeline visibility
3. Reps spending time on unqualified leads

### Behaviors
- Reads: SaaStr, Sales Hacker
- Tools: Salesforce, Gong, LinkedIn Sales Nav
- Decision style: Data-driven, needs ROI proof
- Buying process: 3-month evaluation, committee decision

### Quotes
"I need to know which deals will close this quarter, not guesses."
"My reps are drowning in bad leads from marketing."

### How We Help
- Solution: Sales funnel analyzer + objection handler
- Value prop: "Cut reporting from 10h to 30min/week"
- Key message: "See exactly which deals will close"
