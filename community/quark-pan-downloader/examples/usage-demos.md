# 使用示例

## 场景 1: 批量转存学习资料

**目标：** 将收藏的 50+ 课程分享链接转存到自己网盘

**步骤：**

1. 准备链接列表：
```bash
cat > scripts/config/url.txt << 'EOF'
https://pan.quark.cn/s/course1?pwd=1234
https://pan.quark.cn/s/course2?pwd=5678
https://pan.quark.cn/s/course3
...（50 个链接）
EOF
```

2. 运行工具：
```bash
cd community/quark-pan-downloader/scripts
python quark.py
```

3. 选择功能：
```
请选择功能:
1. 批量转存
2. 批量分享
3. 批量下载
> 1  [按 1 然后 Enter]
```

4. 等待完成：
```
正在转存: course1 ... [完成]
正在转存: course2 ... [完成]
...
全部转存完成！共 50 个文件夹
```

**结果：** 所有课程已转存到 "我的网盘/转存文件" 目录

## 场景 2: 下载大文件（绕过 VIP 限制）

**目标：** 下载 15GB 的压缩包，web 端要求 VIP

**步骤：**

1. 运行工具：
```bash
cd community/quark-pan-downloader/scripts
python quark.py
```

2. 选择下载：
```
请选择功能:
> 3  [批量下载]
```

3. 输入路径：
```
请输入网盘文件夹路径（或直接从 url.txt 读取分享链接）:
> /我的文件/大文件.zip
```

4. 下载中：
```
正在下载: 大文件.zip (15.3 GB)
进度: [████████░░] 80% (12.2 GB / 15.3 GB)
速度: 5.2 MB/s
```

**结果：** 文件下载到本地，无需 VIP

## 场景 3: 批量生成分享链接

**目标：** 将 "资源合集" 文件夹内 100+ 个文件批量生成分享链接

**步骤：**

1. 运行工具：
```bash
cd community/quark-pan-downloader/scripts
python quark.py
```

2. 选择分享：
```
请选择功能:
> 2  [批量分享]
```

3. 输入目录：
```
请输入要分享的文件夹路径:
> /我的文件/资源合集
```

4. 生成结果：
```
正在生成分享链接...
[1/103] 文件A.pdf → https://pan.quark.cn/s/xxx1
[2/103] 文件B.zip → https://pan.quark.cn/s/xxx2
...
[103/103] 文件夹Z → https://pan.quark.cn/s/xxx103

✅ 全部完成！链接已保存到 share_links.txt
```

**结果：** 获得 103 个分享链接，可批量分发

## 场景 4: 组合使用 - 资源整理完整流程

**目标：** 整理网盘资源 → 分类 → 分享给朋友

**步骤：**

1. **收集资源（批量转存）**
```bash
# url.txt 中填入 50 个分享链接
python quark.py → 选择 1
# 转存到 /临时收集 目录
```

2. **手动分类整理**
- 在网盘 web 端将文件移动到分类文件夹
- 例如：课程类、工具类、资料类

3. **批量生成分享链接**
```bash
python quark.py → 选择 2
# 输入路径: /课程类
# 生成 share_links_courses.txt
```

4. **发送给朋友**
- 复制 share_links_courses.txt 内容
- 通过微信/邮件发送

**效率对比：**
- 手动操作：~2 小时（逐个转存 + 逐个分享）
- 使用本工具：~5 分钟（全自动）

## 高级技巧

### 技巧 1: 配合 mediacrawler 采集链接

```bash
# 1. 用 mediacrawler 爬取小红书/微博上分享的网盘链接
# 2. 提取夸克网盘链接到 url.txt
# 3. 批量转存
```

### 技巧 2: 定期备份到本地

```bash
# 定时任务：每周备份网盘重要文件
crontab -e
0 2 * * 0 cd /path/to/scripts && python quark.py --mode download --path "/重要文件"
```

### 技巧 3: 分享链接管理

```bash
# 生成的分享链接按日期归档
mv share_links.txt archives/share_links_$(date +%Y%m%d).txt
```

## 常见错误

### Error: "登录超时"
```
原因: 浏览器中未完成登录或网络慢
解决: 延长等待时间，或手动配置 cookie
```

### Error: "文件已存在"
```
原因: 目标文件夹已有同名文件
解决: 跳过或重命名原文件
```

### Error: "分享链接无效"
```
原因: 链接过期或提取码错误
解决: 检查 url.txt 中的链接格式
```
