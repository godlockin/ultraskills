# 手相解读示例

## 示例 1 — 木形手 + 生命线弯曲 + 火形事业

**用户描述**:"我手很长很瘦,能看见竹节,手指间有缝。我做设计,但经常觉得心累。我的生命线有个弯,我妈说我情商高会说话。"

**skill 推演**:

1. **手型判定** = 木形手(瘦长 + 竹节 + 指缝)
2. **木形手性格**:
   - 善良是骨子里的
   - 精神完美主义
   - 世俗欲望低,精神追求高
   - 感情挑剔(要外表 + 内涵)
3. **生命线弯曲如弓** = 情商高、圆滑、社交高手(视频原话),代表:曾国藩
4. **木形手 + 设计** 是匹配(静态、思考、审美)
5. 但 **心累** → 完美主义者的通病

**输出范例**:
> 你的手型属**木形手**(瘦长竹节指缝),这是荀太虚体系中**善良完美主义**的标记 — 你做设计是因为这工作"非营利、思考、审美",而不是追求物质回报。
>
> 但你说"心累" — 在木形手体系里这是**完美主义的负担**:
> - 你对自己作品的要求永远高于市场要求
> - 你倾向**过度思考**而延误产出
> - 你需要"够用就好"的标准而非"完美"才交付
>
> 你的**生命线弯如弓** = 情商高、懂圆融。**这本来是优势**,但在完美主义 + 善良骨子里的双重作用上,你容易**为别人意见而焦虑**。建议:对外交付时**停 60 秒问"对方真的需要更好吗"**,能省去你 30% 的精力内耗。

## 示例 2 — 火形手 + 感情线长

**用户描述**:"我是火形手,感情线挺长,我一段恋爱都很投入但都不太持久。"

**skill 推演**:

1. **手型 = 火形手**(下面宽上面窄,火苗形态)
2. **性格特点**:
   - 审美天赋高
   - 外实内需、内在敏感
   - 一见钟情、发展快
3. **感情线长 + 火形手** = "在感情中追求新鲜感、热退后就觉得对方全是问题"
4. **视频明言**:"这类人如果感情线很长,就更容易被骗,在感情上会遇到更多的波折,因为他看得太重了"

**输出范例**:
> 火形手 + 长感情线 是荀太虚体系里**经典"浪漫速食"组合**。你的描述完全对得上:发展迅速、投入深,但难以持久。
>
> 关键启示:**热退之后挑毛病是必然** — 你不需要"修"这个特质,而是要**在热退时点给自己"再坚持 90 天"**。这不是强撑,而是给"新鲜感消退后的真感情"留出浮现时间。
>
> 同时提醒:**火形手易被骗**(视频原话"火行手的人容易被骗"),**前 3-5 次恋爱特别警惕**。6 个月内的"非理性投入"风险大。
>
> 建议:把"热退至真感情"作为观察期(90-180 天),过了这段再看,比"当下感觉"靠谱得多。

## 示例 3 — 金形手 + 事业线清晰

**用户描述**:"我做管理的,手方方正正,事业线挺长,我以前老觉得情感上被欺骗。"

**skill 推演**:

1. **手型 = 金形手**(长方直方、厚实弹性)
2. **性格特点**:
   - 实在、勤俭、务实派
   - 公平心、原则性、有恩必报
   - "命运是自己掌握"
3. **事业**:非常能做事、意志力强、雷厉风行 → 管理决策/军人
4. **感情观**:不懂浪漫、追求实际、不接受感情被骗、"付出真心必须换回真心"

**输出范例**:
> 你是**金形手的长方直方 + 长事业线** — 荀太虚体系里这是**"能成大事"组合**:管理决策、军警纪律职业很匹配。
>
> 但你说"情感上被欺骗",这跟金形手的**"实务但期望对等"**特质直接相关:你付出真心,但**不愿接受"对方给出的等价物不是你认为的等价"**。这未必真的是对方欺骗,可能是**你们对"真心"的定义不一致**。
>
> 建议:在感情中**先与对方聊"你认为的真心是什么"**,而非直接行动。金形手适合"先定标准再行动",而不是"先行动再评估"。

## 示例 4 — 水形手 + 互补型恋爱

**用户描述**:"我和另一半差异很大,他是金形手我是水形手,但相处很舒服。"

**skill 推演**:

1. **双方手型五行互补**:水 + 金 = 金生水 → **资源互相补充**
2. **水形手**:"容易遇到互补型对象 / 接受差异性大的关系"
3. **金形手**:"希望对象也是务实派"(可能需要一个调整)
4. **整体**:水润万物 + 金生水 = 比较平衡的搭配

**输出范例**:
> 你们是水形手 + 金形手 = **金生水** 的相生组合 — 这是五行关系里最舒服的搭配之一。水形手圆融、喜欢平衡关系;金形手原则性强、稳定输出。**你(水)给灵活性,他(金)给框架**,你们天然互补。
>
> 注意:金形手对"对方是否务实"敏感 — 水形手**别表现出"耍小聪明"**或"找捷径"姿态,这会让金形手不信任。
>
> 整体:可长期相处。

## 反例 — 何时不要硬解读

- 用户在**初次相亲/初识**场合问"他/她手相怎么样" → **拒绝**:不礼貌
- 用户**只看了左手**就要结论 → 必须**看双手**
- 用户问"我能不能活到 80 岁" → **拒绝**:生命线长 ≠ 寿命;给健康建议、就医提醒
- 用户问"我俩合不合" → 提示手相**只反映五行配对**,实际相处才是关键
- 用户有**焦虑抑郁倾向** + 手相推运 → **先关心心理状态**,再谈手相
