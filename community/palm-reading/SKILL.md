# palm-reading · 道家手相 / 手诊

> 📚 **前置知识**:`daoist-cosmology-basics`(五行、五指归属)
> 🎓 **来源**:荀太虚《面相八字手相全系统教学》视频转写(2026)

## 🎯 目标 (Goal)

基于用户描述的手掌与手纹特征,给出:
- **手型五行归属**(木/火/土/金/水型手)→ 主性格 + 事业适配
- **五大主线解读**(生命、智慧、感情、命运/事业、婚姻线)
- **九宫位 / 八丘**(对应脏腑与运势)
- **左右手对比**(先天 vs 后天)

## 🧠 核心理念 (Core Concepts)

### 1. 双手 = 先天 + 后天(视频明确反对"男左女右")

> 视频原文:"在大部分人的认知中,看手相是男左女右。**其实这是错误的**。我们把左手和右手分为先天和后天。**左手是你先天的命格出身**,自带的属性和性格。**右手是你后天通过努力和机遇显示的相**,也是你后天成长的一个性格转化。我们要**结合双手分析**才准确。"

> 流年判断:**以 30 岁为分界**(左手主 30 岁前,右手主 30 岁后)。

### 2. 看手相的礼仪

> 视频原文:"不要说我今天去相亲,我就先看看他的手相好不好,看看是不是能带来财运之类的。**这是不礼貌的**。先相处一段时间再观察。"

### 3. 五行手型 = 五种性格映射

视频原文:"手型一共分成了五种,分别是**木形手、火形手、金形手、水形手,以及土形手**。它们也对应了五种不同的性格。"

### 4. 九宫位 / 八丘观健康

> 视频原文:"古人们将手掌分为九个宫位,每一个宫位对应人体不同的腹脏器官,可以通过不同宫位的颜色纹路形态,来判断所对应的健康、财运以及性格问题。"
>
> "中医里面也会根据手掌不同的表现状态,来判断你身体哪个地方近期出了问题。"

外八丘 + 中心明堂 = 共 9 宫位。

> 男人看左手女人看右手 — **单看一手推断趋势**,结合双手分析。

### 5. 五指 / 五大主线 五行归属

- **拇指** = 土(脾)
- **食指** = 木(肝)
- **中指** = 火(心)
- **无名指** = 金(肺)
- **小指** = 水(肾)

## 🚀 使用流程 (Workflow)

### Step 1: 双手采集(必问)
- 左右手分别拍摄 / 描述
- **手型判定**(胖瘦、长短、宽厚)
- **五大主线 形态**(有 + 长度 + 深浅 + 岔纹)
- **九宫位** 饱满度
- **手指长度比例**

### Step 2: 手型五行
按 `resources/five-hand-types.md` 五型对应表归类

### Step 3: 主线逐一
按 `resources/four-major-lines.md` 起止 + 形态 + 健康/性格暗示

### Step 4: 九宫位 + 健康
按 `resources/nine-palaces.md` 看对应脏腑

### Step 5: 综合解读
1. **手型定主性格**
2. **主线分项打分**
3. **九宫位健康检查**
4. **左右对比看流年**
