# palm-reading · 道家手相 / 手诊

> 📚 **前置知识**:`daoist-cosmology-basics`(五行、五指归属)
> 🎓 **来源**:荀太虚《面相八字手相全系统教学》视频转写(2026)

## 🎯 目标 (Goal)

基于用户描述的手掌与手纹特征,给出:
- **手型五行归属**(木/火/土/金/水型手)→ 主性格 + 事业适配
- **五大主线解读**(生命、智慧、感情、命运/事业、婚姻线)
- **九宫位 / 八丘**(对应脏腑与运势)
- **左右手对比**(先天 vs 后天)

## 🧠 核心理念 (Core Concepts)

### 1. 双手 = 先天 + 后天(视频明确反对"男左女右")

> 视频原文:"在大部分人的认知中,看手相是男左女右。**其实这是错误的**。我们把左手和右手分为先天和后天。**左手是你先天的命格出身**,自带的属性和性格。**右手是你后天通过努力和机遇显示的相**,也是你后天成长的一个性格转化。我们要**结合双手分析**才准确。"

> 流年判断:**以 30 岁为分界**(左手主 30 岁前,右手主 30 岁后)。

### 2. 看手相的礼仪

> 视频原文:"不要说我今天去相亲,我就先看看他的手相好不好,看看是不是能带来财运之类的。**这是不礼貌的**。先相处一段时间再观察。"

### 3. 五行手型 = 五种性格映射

视频原文:"手型一共分成了五种,分别是**木形手、火形手、金形手、水形手,以及土形手**。它们也对应了五种不同的性格。"

### 4. 九宫位观健康与运势

> 视频原文:"古人们将手掌分为**九个宫位**,每一个宫位对应人体不同的脏腑器官,可以通过不同宫位的**颜色、纹路、形态**来判断所对应的**健康、财运以及性格**问题。"
>
> "所以在中医里面,也会根据手掌不同的表现状态,来判断你身体哪个地方近期出了问题。"

九个宫位是 **乾、坎、艮、震、巽、离、坤、兑 + 明堂**(右手镜像对称)。

> **总原则**:"外边这**八个宫位要红润饱满**这才好……**中间的位置为明堂,明堂反而要低才好**。" — 就像风水局,周围的山环绕中间的水。

> **三大重点宫位**:**巽宫**(财帛)、**离宫**(官禄声望)、**坤宫**(家庭)。

### 5. 五指对应六亲(不是五行)

> 视频原文:"先说一个最简单的概念,就是**五指和六亲之间的关系**。"

| 手指 | 六亲 | 宫位名 |
|---|---|---|
| **大拇指** | 父母 | — |
| **食指** | 兄弟姐妹 + 朋友 | 兄弟宫 |
| **中指** | **命主本人** | — |
| **无名指** | 配偶 | **夫妻宫** |
| **小指** | 子孙后代 | **子女宫** |

### 6. 禁止单一断事

> 视频原文:"看手相**千万不能单一地看某一个纹路就断事**。看手相就像面对生活的态度一样,是一个**做加减法的过程,必须综合判断**。比如**婚姻线必须结合感情线来看**。**好与不好不是绝对的** — 我认为人的一生**总是福祸相依**。"


## 🚀 使用流程 (Workflow)

### Step 1: 双手采集(必问)
- 左右手分别拍摄 / 描述
- **手型判定**(胖瘦、长短、宽厚)
- **五大主线 形态**(有 + 长度 + 深浅 + 岔纹)
- **九宫位** 饱满度
- **手指长度比例**

### Step 2: 手型五行
按 `resources/five-hand-types.md` 五型对应表归类;多为混合型 → 按百分比拆解主次

### Step 3: 手指与手掌
按 `resources/fingers-and-palm.md` 看指掌比例 + 五指六亲

### Step 4: 主线逐一
按 `resources/four-major-lines.md` 起止 + 形态 + 流年节点 + 健康/性格暗示

### Step 5: 九宫位 + 健康
按 `resources/nine-palaces.md` 看对应脏腑;重点巽/离/坤三宫

### Step 6: 特殊纹路
按 `resources/special-marks.md` 查辅助线与吉凶纹

### Step 7: 综合解读
1. **手型定主性格**
2. **主线分项打分**
3. **九宫位健康检查**
4. **左右对比看流年**
5. **交叉验证**(至少两个特征支持才下结论)
