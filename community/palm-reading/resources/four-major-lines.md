| 线 | 别名 | 起点 | 主事 |
|---|---|---|---|

## 生命线详解

### 测量标准

1. 从大拇指根部 → 小拇指根部画一条直线,这个**交界点代表 30 岁**
2. 从中指画垂直向下的线:**好生命线至少能抛到这条线**(说明身体底子好)
3. 从中指和食指中间画垂直向下的线:**如果连这点都不到** → 从今天起保养身体

### 形态解读

| 形态 | 解读 |
|---|---|
| **长、深、粗、抛得远** | 健康基础好 |
| **延伸至坎宫甚至手腕** | 生命力充沛、活力四射 |
| **短** | 对应年龄段时间身体虚弱 / 病痛(需注意) |
| **笔直朝下** | 身体机能下滑速度非常迅速 |
| **弯曲如弓** | 情商高、懂语言艺术、圆滑,天生的社交高手(代表:曾国藩) |
| **很直** | 个人能力 > 口才、刚直、说话直截了当、雷厉风行 |
| **深** | 做事有冲劲、执行力强 |
| **浅** | 一天到晚没有精神、做事提不起劲 |
| **粗** | 抵抗力强、不易生病 |
| **细** | 身体单薄、轻微刺激就感冒 |
| **长 + 抵达晚年区域** | 晚年身体硬朗 |

### 生命线异常纹理

| 纹理 | 时间点 | 含义 |
|---|---|---|
| **小横纹** | 对应时间点 | 小问题 |
| **岛纹(导纹)** | 对应时间点 | 该年龄生病,**导纹越大影响越大** |
| **锁链纹** | 长期 | 长期慢性病 |
| **交叉纹** | 对应时间点 | 各种异常 |

> ⚠️ **健康相关 → 引导就医**,不建议靠"调理"代替诊断。

## 智慧线

智慧线主**思维、决断**,反映:
- 决策模式
- 思考深度
- 与人沟通方式

## 感情线

(视频文字被切碎,但提"感情线长 → 更易被骗 / 在感情上会遇到更多波折 / 看得太重")

基础规律:
- 感情线**长** → 多情、投入深
- 感情线**过深** → 情绪重,易受伤
- 感情线**清晰不乱** → 情感稳定
- 出现**断裂/岛纹** → 感情相关事件时段

## 命运线 / 事业线

**并非人人所有**。这条线若:
- **长且清晰** → 事业稳定
- **间断** → 事业波动
- **缺失** → 事业少"主轴",更靠应变与机遇

## 婚姻线 / 婚姻稳定线

(视频提"也叫事业线以及婚姻线")

婚姻线看**婚姻/伴侣稳定度**:
- 清晰不交叉 → 稳定
- 多重纹 → 多段感情或不稳定
- 末端分叉 → 中年后关系变化

> ⚠️ 所有婚姻线解读**不替代现实观察**。现实中相处沟通才是关键。
