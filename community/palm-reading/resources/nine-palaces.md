# 九宫位 + 八丘 — 看健康

> 来源:荀太虚视频转写

## 九宫位

视频原文:"手掌分为**九个宫位**,每一个宫位对应人体不同的腹脏器官,可以通过不同宫位的颜色纹路形态,来判断所对应的健康、财运以及性格问题。所以中医里面也会根据手掌不同的表现状态,判断你身体哪个地方近期出了问题。"

> 视频口语转写:"九个宫位分别是**前、侃、更、正、迅、黎、坤、对**(右手镜像对称)"。
>
> **修复为经典名**:巽(东)、离(南)、坤(西南)、震(东)、中(明堂)、兑(西)、乾(西北)、坎(北)、艮(东北)

## 视频判断标准

### 颜色 + 形态
> 视频原文:"外边这八个宫位要**红润饱满**这才好。如果很平甚至是凹陷,那么对应的方面就容易出问题。"

| 状态 | 含义 |
|---|---|
| **红润饱满** | 该方面能量足 |
| **平** | 能量不足 |
| **凹陷** | 该方面有问题 / 当前该脏腑信号弱 |
| **中央明堂** | **低才好**(视频明确) |

### 红润饱满的视觉感
> 视频原文:"最好的手相就是**高低错落有致**,该高的地方高该低的地方低,就像风水一样有山有水。"

## 健康判读细节

> 视频原文:"可以通过不同宫位的颜色纹路形态,来判断所对应的健康、财运以及性格问题。"

### 异常信号

- 某宫位**异常发红** → 该脏腑可能发炎 / 上火
- 某宫位**异常发白** → 该脏腑可能虚寒 / 气血不足
- 某宫位**异常发青 / 黑** → 该脏腑可能瘀滞 / 痛症
- 某宫位**异常凹陷** → 该脏腑长期能量不足

> ⚠️ 这些"看手诊病"**不替代医学诊断**,强烈建议任何持续异常请就医。

## 流年判断

- 看手相是看"近况 + 倾向",**不是预言**
- 配合大运 / 流年 / 八字 → 多维印证
- 双手对比 = 看流年走向(30 岁分界)

## 男左女右 — 不再适用

> 视频修正:"男人看左手女人看右手 — 这是大众印象。视频明确:用 **30 岁分界** 替代性别分界"

现代解读:任何手相分析要**结合双手**,并按 30 岁为分界看先天 vs 后天。
