# face-reading · 道家面相学

> 📚 **前置知识**:`daoist-cosmology-basics`(五行、五官归属)
> 🎓 **来源**:荀太虚《面相八字手相全系统教学》视频前 50 分钟转写

## 🎯 目标 (Goal)

基于用户描述或 AI 识别的面部特征,给出:
- **整体轮廓端正度**(三庭五眼)
- **五官性格倾向**(眉木/眼火/鼻土/口水/耳金)
- **十二宫位解读**(命/财帛/兄弟/田宅/.../疾厄/.../相貌)
- **气色观察**(青/红/黄/白/黑对应脏腑信号)
- **流年提示**(按三庭划分早中晚年运)

## 🧠 核心理念 (Core Concepts)

1. **面相看气,八字看命,手相看变** — 三者各管一面:
   - 面相:当下气质、近期运势、健康状况
   - 八字:先天命格、长期轨迹
   - 手相:后天变化、心境转折

2. **三庭流年** — 整张脸分上/中/下三段,各管年龄阶段:
   - **上庭** = 额头 = **15-30 岁**运势(智慧、情商、家庭出身)
   - **中庭** = 眉→鼻准 = 30-50 岁运势(事业、财帛、姻缘)
   - **下庭** = 鼻准→下巴 = 50 岁之后运势(积蓄、福德、子女)

3. **五官五行** — 五官对应五行与五脏:
   - 眉 = 木(肝);眼 = 火(心);鼻 = 土(脾);嘴 = 水(肾);耳 = 金(肺)
   - 五官**形态异常** → 对应脏腑能量异常 → 性格倾向

4. **耳朵独特性** — 耳管 **1-15 岁**运势 + 反映原始家庭;00 后、10 后出生的小孩普遍耳朵发育好(大而肥)

5. **天庭饱满,地格方圆** — 额头饱满明亮如镜,地阁(下停)方圆厚实,标准相格

6. **男女差异显著** — 三庭高度、五眼宽度、额头高低的标准男女不同

## 🚀 使用流程 (Workflow)

### Step 1: 收集信息(必问)

引导用户描述面部:
- 整体轮廓(三庭比例、五眼比例)
- 印堂/山根/鼻梁/准头 形态
- 双眼形态(卧蚕、眼尾)
- 双眉形态(浓稀、聚散)
- 嘴形、人中深浅
- 耳形(大小、贴脑与否)
- 面色(青/红/黄/白/黑、光泽、暗沉)

### Step 2: 三庭五眼定位

按 `three-courts-and-five-eyes.md` 判定是否端正。

### Step 3: 五官五行归类

按五官形态 → 五行 → 性格倾向,见 `five-features.md`。

### Step 4: 十二宫位解读

按 `twelve-palaces.md` 逐位对应当前用户描述的特征。

### Step 5: 气色辨证

按 `qi-se-color.md`,脸色 + 五脏信号关联(非西医诊断)。

### Step 6: 流年提示

按三停归类:
- 上停异常 → 早年(15-30)注意
- 中停异常 → 中年(30-50)注意
- 下停异常 → 晚年(50+)注意
