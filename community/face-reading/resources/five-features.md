# 五官五行 — 五官对应

> 来源:经典五行归类,叠加荀太虚视频明确提及之处

## 五官五行 + 五脏对应

| 五官 | 五行 | 主脏 | 性格主轴 |
|---|---|---|---|
| **眉** | 木 | 肝 | 怒、决断 |
| **眼** | 火 | 心 | 喜、表达 |
| **鼻** | 土 | 脾 | 思、稳重 |
| **嘴** | 水 | 肾 | 欲、亲和 |
| **耳** | 金 | 肺 | 悲、倾听 |

## 各五官细节(视频中明确提到的形态 → 性格)

### 眉 — 木 / 肝

- **眉骨高的人**:
  - 优点:分析力强、观察力强
  - 缺点:过高 → 走极端、做事一股脑往前冲、不知退、风格强势

### 眼 — 火 / 心

- 视频未细化眼形,经典补充:
  - 凤眼(细长上扬):精明、领导气质
  - 杏眼(圆大):温和、善于社交
  - 三角眼(眼尾下垂):多疑、心思深
  - 眼中带神(光):聪明;眼无神(晦暗):近期不顺

### 鼻 — 土 / 脾 — 财帛宫

> 视频原文:"鼻子是财博宫"

- 鼻梁主 30-50 岁财帛运
- 山根主疾厄/早期立业
- 鼻准(鼻头) = 财帛宫之主体
- 鼻翼(左/右孔) = 金甲、兰台,看库财能否守住

### 嘴 — 水 / 肾

> 视频原文:"舌是商人刃,口是货扶门 — 一张嘴,既能为你招来好运,也能引来祸事"

- 嘴形轮廓:
  - 厚嘴:重情义、亲和
  - 薄嘴:口才好但言多必失
  - 嘴角上翘(微笑唇):乐观
  - 嘴角下垂:多虑、悲观
- 人中深浅反映生殖/精力(经典补充)
- 齿齐洁白 → 肾气足

### 耳 — 金 / 肺 — 主 1-15 岁 + 原始家庭

> 视频明确:"耳朵代表一个人 1 到 15 岁的运势,也反映原始家庭"

**好耳相的标准**:
1. **大**(整体面积)
2. **耳轮大**(外缘圈)
3. **耳垂大**(下部肉)
4. **偏硬**(老人所谓"有骨气",感觉有支撑)
5. **颜色白净**(古语"耳白于面,闻名四方")

**加分/减分**:
- ✅ 大 + 厚 + 挺立 → 聪明、少年运佳
- ❌ 小、薄、贴脑、耸露 → 少年多阻、肾气不足
- 🔸 00 后、10 后出生的小孩**普遍耳朵发育好**(大而肥),反映当代营养/环境改善

## 五行失衡速判

| 现象 | 可能五行 |
|---|---|
| 印堂暗沉/青紫 | 木郁(肝) |
| 眼角红血丝 | 火亢(心) |
| 鼻头赤红/毛孔粗 | 土湿热(脾) |
| 唇色淡/唇干裂 | 水亏(肾) |
| 耳轮色枯 | 金虚(肺) |

> 这些**不是医学诊断**,如持续不适请就医。

## 综合

观察顺序建议:**耳 → 眉 → 眼 → 鼻 → 嘴**(五官中耳管先天,鼻管后天财富,中间五官管性格主轴)。
