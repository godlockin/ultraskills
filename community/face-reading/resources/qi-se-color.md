# 气色辨证 — 面色与五脏信号

> 来源:经典中医色诊 + 荀太虚视频"耳白于面,闻名四方"等提示

## 五色主五脏 + 五情

| 面色 | 主脏 | 主情 | 生理倾向 |
|---|---|---|---|
| **青** | 肝 | 怒 | 痛、寒、血瘀、气滞 |
| **红** | 心 | 喜 | 热、充血、上火 |
| **黄** | 脾 | 思 | 湿、虚、气血不足 |
| **白** | 肺 | 悲 | 寒、血虚、气虚 |
| **黑** | 肾 | 恐 | 痛、肾虚、久病 |

## 各部位气色观察要点

### 印堂

- 印堂最忌:**暗沉、青黑**
- 暗沉发青 → 心事重、肝郁
- 印堂明润、黄中带红 → 气血顺畅
- 「荆棘着印堂,少年走茫茫」— 印堂见竖纹或横纹

### 鼻准(财帛宫)

- 鼻准红如朱砂 → 财到
- 鼻准苍白 → 财气不足
- 鼻准暗沉、斑点 → 守财不稳

### 山根(疾厄宫)

- 山根青筋横生(儿童多见) → 消化不良、易惊
- 山根光泽明润 → 健康
- 山根低塌/断裂 → 体弱

### 耳(整耳)

- 视频:「耳白于面,闻名四方」
- 耳朵红润 → 肾气充足
- 耳朵暗枯 → 肾气不足
- 耳轮色紫 → 气血不畅

### 唇

- 唇色淡白 → 血虚
- 唇色深红 → 内热
- 唇色紫暗 → 血瘀

## 综合判读

健康气色 = **明润含蓄** + **黄中带红**(主色黄为底,微带红润)。

异常情况:
- 任何部位**突然变色**(如常黄突然苍白) → 注意近期健康
- **局部色斑**长期不消退 → 建议就医
- **满面通红**长期不退 → 高血压倾向

> ⚠️ **所有气色判读均不替代医学诊断。** 任何持续面部异常,请咨询专业医师。
