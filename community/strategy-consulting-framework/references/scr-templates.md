# SCR 模板 + 汇报范例

> SCR = Situation/Complication/Resolution。是 McKinsey 汇报的骨架,任何对外汇报/写周报/做提案都可套。

## SCR 通用结构

```
S (Situation)    [客观事实,无情绪]
C (Complication) [矛盾/障碍/新发生]
R (Resolution)   [答案 + 行动]
```

每段 1-3 句话,不超 50 字。

---

## 模板 1 · 对老板汇报

```
S: 上季度用户从 100K 增长到 120K(+20%)
C: 但月活率从 40% 降到 32%,留存问题开始影响增长
R: 建议本月做一次用户访谈 + 修复首月流失原因,
   预计可恢复留存到 36%,新版本 8 月中上线。
```

---

## 模板 2 · 写给客户的方案

```
S: 贵司目前公众号粉丝 50K,但转化率仅 0.5%(行业平均 1.2%)
C: 问题不在流量,而在公众号内容与产品定位不匹配
R: 我们建议内容策略转向 [具体方向],附 30 天落地计划。
   预期 90 天内转化率提升到 1%,粉丝增速维持 5%/月。
```

---

## 模板 3 · 合伙人/投资人提案

```
S: 目前 ARR $200K,自增长 8%/月
C: 增长到下一阶段($500K ARR)需要扩团队 + 加获客预算,
   现金 12 个月内会烧完
R: 申请 $300K pre-seed 跑道,12 个月做到 $500K ARR。
   关键假设:获客 CAC 维持在 < $200,留存 > 80%。
```

---

## 模板 4 · 个人决策(自己用)

```
S: 独立运营 SaaS 1 年,月入 $8K
C: 瓶颈在内容运营,我既不喜欢也不擅长,导致产品迭代被拖
R: 招一个内容兼职($1.5K/月),先 3 个月。
   失败预案:3 个月后内容产出仍 < 4 篇/月,撤资转外包。
```

## 模板 5 · 季度复盘

```
S: 2026 Q1 营收 $80K,目标 $100K,完成 80%
C: 流失同比上升 10pp,新客增长持平,核心矛盾在新客质量下滑
R: Q2 重点调整获客渠道,把 X 渠道从 30% 占比降到 10%,
   期望留存回升至 90%,Q2 末实现 $95K。
```

---

## 模板 6 · 重大投入决策(创作者)

```
S: 现工具链 7 个 SaaS 总成本 $500/月,功能重叠 3 个
C: 重复浪费约 $200/月,但切换需要 2 周迁移成本
R: Q2 内合并到 4 个工具,预计节流 $200/月 + 流程提效 30%。
   切换成本:$0(均支持导出导入)。
```

---

## 模板 7 · 拒绝合作

```
S: 收到 X 公司 联合推广 offer,承诺带来 5K 新用户
C: 但要求我方贴出品牌,且数据真实性未验证
R: 暂不接。建议改成纯流量互换(不挂品牌)+ 验证数据
   后再谈长期合作。
```

## 写好 SCR 的 5 个原则

1. **S 必须客观** — 不要在 S 里写「我觉得」「我们担心」
2. **C 必须具体** — 「转化低」不够,「Q1 转化率从 1.2% 降到 0.5%」才是
3. **R 必须可执行** — 「想办法优化」不算答案,「本月做 X」算
4. **三段长度递减** — S 长(铺陈),C 中(聚焦),R 短(答案)
5. **R 给 1 个动作** — 不超过 1 个本周可做的具体动作,避免「分散注意力」

## 反例:常见的 SCR 错误

### ❌ S 太虚

> S: 我们的产品很受欢迎

✅ 应是:

> S: 上季度月活 50K,NPS 62,付费转化 3%

### ❌ C 没指出矛盾

> C: 但是营收增长缓慢

✅ 应是:

> C: 营收增长 5%,但营销成本上升 30%,CAC 突破 $300

### ❌ R 太空

> R: 我们会持续优化产品

✅ 应是:

> R: 6 月底前上线新版本,目标付费转化 3% → 5%

## SCR vs 金字塔原理的关系

SCR 是金字塔原理的**叙事表达**:
- 金字塔顶端:1 句话结论(答案)
- SCR 是把这条结论**展开成 3 段叙事**

所以两者**不冲突**:
1. 先用 SCR 重组混乱信息
2. 再压成金字塔顶端 1 句话
3. 顶端这句话就是「Answer 预告」
