# Issue Tree 实战示例

> 不同场景下的 issue tree 演示。每个都标了根问题、问题陈述、拆解、关键假设,以及常见错误。

---

## 示例 1 · 增长 2x(经典 McKinsey 案例)

**根问题陈述(SCR)**:
- S:去年收入 $10M,今年初到现在持平
- C:董事会要求 2 年内增长到 $20M,不知道从哪里下手
- Q:如何在 24 个月内把收入翻倍?
- Answer 预告:扩大新客 + 减少流失 + 提高单客价值

**Issue Tree**:
```
收入 × 2
├─ 新客数量 ↑
│  ├─ 拓展新渠道(SEO/付费/异业)
│  ├─ 优化转化漏斗(落地页/注册)
│  └─ 进入新地域/新客群
├─ 流失 ↓
│  ├─ 产品价值未达预期(首月流失主因)
│  ├─ 服务问题(客服/交付)
│  └─ 价格不匹配(被竞品挖走)
└─ 单客价值 ↑
   ├─ Upsell(套餐升级)
   ├─ Cross-sell(相邻产品)
   └─ 价格上调
```

**关键假设**:
- H1:流失率下降 5pp 是最高杠杆(留存比拉新便宜 5-7 倍)
- H2:扩展新渠道 ROI < 老渠道,且需要 6 个月才见效,短期不行
- H3:upsell 适用 30% 老客,平均提价 20%,增收 $1.5M

**常见错误**:
- ❌ 把"收入"拆成"产品/营销/销售"(不 MECE — 营销和销售都拉新)
- ❌ 一上来列 50 个分支,信息过载
- ✅ 按"新客 + 老客 + 单客价值"拆(MECE 经典三块)

## 示例 2 · 要不要进入新市场?(创作者典型)

**根问题陈述**:
- S:我现有的 SaaS 在国内市场月入 $20K
- C:欧美市场 5x 体量,但我没有任何海外经验
- Q:现在应不应该启动海外业务?

**Issue Tree**:
```
是否进入海外
├─ 市场机会
│  ├─ TAM/SAM/SOM 实际多大?
│  ├─ 现有竞品密度和定价?
│  └─ 海外用户付费意愿 vs 国内?
├─ 资源可行性
│  ├─ 翻译/本地化成本?
│  ├─ 获客成本(CAC)对比?
│  └─ 团队语言/时区能力?
├─ 战略一致性
│  ├─ 与现有产品契合度?
│  ├─ 是否分散核心业务精力?
│  └─ 错失成本(再不上还来得及吗)?
└─ 风险与备选
   ├─ 失败最坏结果是什么?
   ├─ 试错成本最低的形态?
   └─ 替代方案(出海合作 / 外包 / 不出海)?
```

**关键假设**:
- H1:海外 CAC 是国内的 2-3 倍但 LTV 高 4-5 倍,长期 ROI 仍然好
- H2:翻译 + 客服 + 获客的总投入需要 $50K 才启动,我现金流能撑
- H3:6 个月内做不出 5 万 MRR 应该撤退

**行动清单(SMART)**:
1. **下周内**:LinkedIn 联系 3 个海外 SaaS 创始人约访谈 — 衡量:约到 ≥ 1 个
2. **2 周内**:针对欧美市场做 1 个本地化页面,投 $500 试水 — 衡量:拿到 10 个免费注册
3. **2 个月内**:复盘是否 ROI > 国内 → 决定继续投入或退出

## 示例 3 · 要不要招第一个人(独立创作者常见)

**根问题陈述**:
- S:独立运营 SaaS 1 年,月入 $8K
- C:感觉瓶颈在自己一个人,想做内容但没时间
- Q:现在应该招第一个人还是再扛半年?

**Issue Tree**:
```
是否招人
├─ 必要性
│  ├─ 哪些事我能做但不愿做(内容运营/客服/获客)?
│  ├─ 哪些事我现在不做但本应做(产品迭代/用户访谈)?
│  └─ 招人能覆盖哪一类?
├─ 财务可行性
│  ├─ 招 1 个初级(兼职)成本?
│  ├─ 招 1 个中级(全职)成本?
│  ├─ 边际收益(他带来的)能覆盖吗?
│  └─ 现金流缓冲够几个月?
├─ 替代方案
│  ├─ 外包/工具替代(AI + 自动化 + 兼职)?
│  ├─ 推迟 6 个月?
│  └─ 找人合伙而非雇佣?
└─ 风险
   ├─ 招错人的代价(文化/时间)?
   ├─ 团队协调成本(沟通/培训)?
   └─ 退出成本?
```

**决策树**:
- 现金流 ≥ 12 个月 + 月入 ≥ $10K → 可考虑招人(中级全职)
- 现金流 6-12 个月 + 月入 $5-10K → 招兼职或外包
- 现金流 < 6 个月 → 不招,先增长

## 拆解通用心法

1. **从用户价值流入手,不是从内部职能入手**(避免"营销/销售/产品"这种不 MECE 的拆法)
2. **第一层不超过 3-4 个分支**(太多就再合并)
3. **每个叶子节点必须可独立分析**(否则不算叶子)
4. **关键假设只看 2-3 个**(不要把所有分支都验证,信息密度低)
5. **决策类型决定拆法**:
   - "做不做" → 战略 vs 财务 vs 风险 vs 替代方案
   - "怎么增长" → 新客 + 老客 + 单客价值
   - "怎么降本" → 固定成本 + 变动成本 + 沉没成本
