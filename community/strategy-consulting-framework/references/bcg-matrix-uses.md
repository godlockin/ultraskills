# BCG 矩阵应用场景

> BCG 矩阵经典是「市场份额 × 市场增长」做 2x2。但本 skill 中**广义的 BCG 模式**:任何「X 维度 × Y 维度」的 2x2 切分,都叫 BCG 思维。

## 经典 BCG(市场份额 × 市场增长)

```
       高增长          低增长
   ┌──────────────┬──────────────┐
⭐ │  Stars       │  Cash Cows   │
   │  (投入扩展) │  (收割现金) │
   ├──────────────┼──────────────┤
❓ │ Question     │  Dogs        │
   │ Marks (赌一把)│ (放弃/剥离) │
   └──────────────┴──────────────┘
   高份额         低份额
```

## 实战变体 1 · 杠杆点优先级(影响力 × 可行性)

> Stage 4 输出「行动清单」前,把候选动作过这个矩阵。

```
        高影响力
   ┌──────────────┬──────────────┐
🟢 │  Do First    │  Plan Well   │
   │  立刻做     │  排好计划做 │
   ├──────────────┼──────────────┤
   │  Quick Wins  │  Fill-ins    │
   │  (低风险快赢) │  (有空再做) │
   └──────────────┴──────────────┘
   高可行性         低可行性
```

**优先级排序**:
1. Do First(高影响力+高可行性)— 立刻做
2. Plan Well(高影响力+低可行性)— 拆步骤排期
3. Quick Wins(低影响力+高可行性)— 见缝插针
4. Fill-ins(低影响力+低可行性)— 砍掉或延后

## 实战变体 2 · 业务组合管理(独立创作者多线业务)

> 当你有 3 个产品线/服务线/内容线,用 BCG 决定资源分配。

| 业务线 | 用户增长 | 收入增长 | 评分 | 决策 |
|---|---|---|---|---|
| A 业务 | 20%/月 | 5%/月 | 🟢 Star | 加大投入 |
| B 业务 | 5%/月 | 10%/月 | 🟢 Cash Cow | 维持,收割现金流 |
| C 业务 | 15%/月 | -2%/月 | ❓ Question Mark | 需复盘价值 |
| D 业务 | -5%/月 | -10%/月 | 🐶 Dog | 砍 |

## 实战变体 4 · 风险评估(危机决策)

> 当面对多个可选方案,用「概率 × 损失」2x2 切分。

| | 低概率 | 高概率 |
|---|---|---|
| **高损失** | 监控 + 准备预案 | 立刻行动 |
| **低损失** | 观望 | 接受(改善是机会) |

---

## 实战变体 5 · 个人精力分配(创作者周计划)

> 一周 40h 精力分配,按「兴趣 × 杠杆」2x2。

| | 高兴趣 | 低兴趣 |
|---|---|---|
| **高杠杆** | 🎯 必须做 | 🤝 找人替我做 |
| **低杠杆** | 🎉 留作奖励 | ❌ 砍掉 |

**实战**:写代码(高杠杆+中兴趣)→ 自己做
**实战**:商务谈判(高杠杆+低兴趣)→ 找人代劳或外包
**实战**:周报(低杠杆+中兴趣)→ 周一周五批量做

## BCG 矩阵使用 5 个误区

1. **维度选择错** — 不一定要"增长×份额",任何 2 个独立维度都可以
2. **强行分类** — 有些项落在边缘,直接归到最近象限
3. **2 维度相关性太高** — 如「市场份额 × 收入」其实一个维度就够了
4. **忽略时间窗口** — BCG 是静态快照,过 6 个月象限可能变
5. **过度精细化** — 不是每件事都需要 BCG,简单决策用 5 分钟思考就够了

## 跟其他工具的协同

| 协同工具 | 用法 |
|---|---|
| **80/20** | BCG 之后用 80/20 找出最大杠杆的具体动作 |
| **Issue Tree** | BCG 之前用 issue tree 拆出维度,再做 2x2 |
| **Hypothesis** | BCG 之后写假设验证(「如果我投 A 业务 30%,其他象限会怎么变?」) |
| **OKR** | BCG 之后把 Star/Cash Cow 转成 O,Question Mark 留作观察 |
| **SMART** | BCG 之后把 Do First 项转成 SMART 行动 |
