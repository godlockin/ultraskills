# 通用Prompt优化模板

直接复制使用，按需填充括号内容。

---

## 🏆 完整版模板（适用于复杂任务）

```markdown
# 角色定义
你是[领域]的专家，拥有[年限]年的[专业方向]经验。
你的专长包括：[技能1]、[技能2]、[技能3]。

# 背景信息
## 项目/任务背景
[描述当前项目或任务的整体背景，让AI理解上下文]

## 当前状态
[描述目前的进展或现状]

## 目标用户/受众
[描述最终产出的目标受众是谁]

# 任务目标
请完成以下任务：
[清晰、具体地描述需要完成的事情]

成功标准：
- [可衡量的成功指标1]
- [可衡量的成功指标2]

# 输入信息
[提供需要处理的原始数据、资料或信息]

# 处理要求
## 必须遵守
- [规则1]
- [规则2]

## 必须避免
- [禁止事项1]
- [禁止事项2]

## 特别注意
- [重点事项1]
- [重点事项2]

# 输出规范
## 格式要求
- 格式：[Markdown/JSON/纯文本/...]
- 语言：[中文/英文/...]
- 长度：[字数限制/段落数]

## 结构模板
[提供期望的输出结构]

# 质量标准
好的输出应该满足：
- [质量标准1]
- [质量标准2]

# 参考示例（可选）
输入：[示例输入]
期望输出：[示例输出]
```

---

## ⚡ 精简版模板（适用于简单任务）

## 🔧 场景专用模板

### 代码生成模板

```markdown
# 任务
实现[功能名称]

# 技术规格
- 语言/框架：[技术栈]
- 版本要求：[版本号]
- 依赖限制：[允许/禁止的库]

# 功能要求
[详细的功能描述]

# 接口定义（如适用）
输入：[参数说明]
输出：[返回值说明]

# 代码质量要求
- [ ] 完整的类型注解
- [ ] 详细的注释/文档
- [ ] 遵循[规范名称]编码规范
- [ ] 错误处理完善
- [ ] 包含单元测试

# 输出
1. 完整可运行的代码
2. 简要使用说明
3. 测试用例
```

### 文档撰写模板

```markdown
# 角色
你是专业的[领域]技术写作专家

# 任务
撰写[文档类型]

# 文档信息
- 主题：[主题]
- 读者：[目标读者描述]
- 用途：[文档用途]

# 内容要求
必须包含：
1. [内容项1]
2. [内容项2]

可选包含：
- [可选内容1]
- [可选内容2]

# 风格要求
- 语气：[正式/轻松/专业]
- 专业术语：[使用/避免/适度]
- 长度：[具体要求]

# 格式规范
[格式具体要求]
```

### 分析评估模板

```markdown
# 角色
你是[领域]的分析专家

# 分析对象
[需要分析的内容/数据]

# 分析维度
从以下角度进行分析：
1. [维度1]：[关注点]
2. [维度2]：[关注点]
3. [维度3]：[关注点]

# 分析深度
- 优先级：[深度分析/快速概览]
- 数据支撑：[需要/不需要]具体数据
- 对比参照：[竞品/历史/行业标准]

# 输出结构
1. 总体评估
2. 各维度详细分析
3. 核心发现（不超过[N]条）
4. 建议行动
```

### 创意生成模板

```markdown
# 创意任务
生成[N]个[创意类型]

# 背景信息
- 品牌/产品：[名称]
- 核心价值：[价值主张]
- 目标受众：[受众描述]

# 创意方向
- 风格倾向：[有趣/严肃/温暖/...]
- 参考案例：[喜欢的案例]
- 避免方向：[不希望的风格]

# 约束条件
- 字数/篇幅：[限制]
- 必含元素：[元素列表]
- 禁用词汇：[词汇列表]

# 输出格式
每个创意包含：
1. 创意名称/标题
2. 核心概念
3. 详细描述
4. 应用场景
```

## 🎯 快速检查清单

使用模板前快速确认：

- [ ] **目标明确**：AI能否理解我要什么？
- [ ] **信息充足**：AI有足够信息完成任务吗？
- [ ] **格式清晰**：我知道想要什么样的输出吗？
- [ ] **约束合理**：限制条件是否必要且可行？
