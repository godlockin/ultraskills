## 五行相生

木 → 火 → 土 → 金 → 水 → 木 ...

- 木生火(柴火燃烧)
- 火生土(灰烬化土)
- 土生金(土中金属)
- 金生水(金属凝露)
- 水生木(雨露润木)

## 五行相克

木 → 土 → 水 → 火 → 金 → 木 ...

- 木克土(树破土)
- 土克水(堤坝止水)
- 水克火(浇水灭火)
- 火克金(熔金)
- 金克木(刀斧伐木)

## 视频关键论断:"我和世界的关系"

> 视频原文:"古人是怎么理解我和世界的关系呢?用十神来总结就是**财官印食比**。这个神不是神灵,而是**我和世界的关系**。更进一步总结就是**比、生、克**三种。"

### 三类关系

| 类 | 关系方向 | 例 |
|---|---|---|
| **比** | 同我 | 兄弟姐妹、同学、同事、朋友、对手、伙伴、感性、自尊心 |
| **生** | 对象生我 | 父母、老师、贵人、道德、资产、健康 |
| **克** | 我克对象 | 财富、妻子(男命)、下属、才艺、子女(女命) |

### 加上对象克我,得十神

| 类 | 同阴阳 | 异阴阳 | 视频提及 |
|---|---|---|---|
| **比** | 比肩 | 劫财 | 兄弟姐妹、对手 |
| **食伤** | 食神 | 伤官 | 下属、才艺、子女(女) |
| **财** | 偏财 | 正财 | 财富、妻子(男) |
| **官杀** | 七杀 | 正官 | 领导、压力、子女(男) |
| **印** | 偏印 | 正印 | 父母、师长、庇护 |

## 五行在四柱中的应用

1. **数五行**: 统计所有 8 字各五行(天干 + 地支藏干)
2. **看月令**: 月支的旺衰权重最高
3. **失衡识别**: 弱、强、受克三种状态
4. **用神确定**: 通关 / 比助 / 调候三种方法
5. **喜神 / 忌神**: 用神同向 = 喜神,反向 = 忌神
