# 阴阳能量 + 阳克阴原则

> 来源:荀太虚视频(明确阴阳能量大小规则)

## 视频核心规则

> 视频原文:"因为**阳性字的能量大于阴性字**,具有深刻流通的主动权。当盘面出现阳性字的时候,首先找阳性字,看看有几个相互是什么关系。比如阴性字能量小,在相生的过程中,不能作为两个阳性字的通道。"

## 三条关键规则

### 1. 阳性字优先
- **阳性字能量 > 阴性字能量**
- 阳性字具有流通主动权
- 排盘时**先找阳性字**

### 2. 阴性字不能作"阳-阳"通道
> 视频原文:"阴性字能量小,在相生的过程中,**不能作为两个阳性字的通道**。"

例子(视频原话):
- 假设原局:子 水 → 卯 木 → 午 火(设想相生)
- 但因为卯木是阴性,**能量有限**
- 实际不是"子水生卯木生午火"
- 而是:**子水克午火**(直接对冲)+ 子水生卯木(生阴)
- 加上两个卯木在 → 午火受伤减轻

### 3. 阳克阴 = 想克就克
> 视频原文:"阳克阴,是想克就克。比如地支子卯有的话,正常是金生水、水生木、木生火连环相生。但**实际上**金生水,水生木,然后**水直接克火**。阳性字要克的五行,如果中间缺少相同阳性字通关,是想克就克。"

### 推论
- **阴字与阴字相克**: 不一定成(互相独立)
- **阳字与阳字相克**: 直接成立(克)
- **阳克阴**: 想克就克

## 实践意义

| 情境 | 处理 |
|---|---|
| 找"通五行的通关用神" | 看是否需要**阳性字** |
| 阴阳不流通 | 找阳性字作主动 |
| 阴字不接续 | 视为"断桥",不引向对方 |

> 视频明确:"这就是天干五合、地支六合,以及阴阳流通规则的基础运用。"

## 配合十天干五合

- 甲己合(化土): 阳阳相合 → **强合**
- 乙庚合(化金): 阴阳相合 → **柔和化金**
- 丙辛合(化水): 阳阴相合 → **和合**
- 丁壬合(化木): 阴阳相合 → **柔和化木**
- 戊癸合(化火): 阴阳相合 → **柔和化火**

> 视频不专门展开化神细节,但**天干五合 + 阴阳流通** 是子平术的核心机制。
