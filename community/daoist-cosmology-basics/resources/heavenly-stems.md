# 天干十天干

> 来源:荀太虚视频转写 + 经典十天干属性表

## 十天干速查

| 天干 | 五行 | 阴阳 | 典型意象 |
|---|---|---|---|
| **甲** | 木 | 阳 | 大树、首领、刚性 |
| **乙** | 木 | 阴 | 藤蔓、柔顺、文艺 |
| **丙** | 火 | 阳 | 太阳、显明、热烈 |
| **丁** | 火 | 阴 | 烛光、内蕴、洞察 |
| **戊** | 土 | 阳 | 山岭、稳定、厚重 |
| **己** | 土 | 阴 | 田地、滋养、承载 |
| **庚** | 火 | 阳 | 刚金、变革、锋利 |
| **辛** | 金 | 阴 | 珠玉、精致、内敛 |
| **壬** | 水 | 阳 | 江海、奔流、雄浑 |
| **癸** | 水 | 阴 | 雨露、滋养、内敛 |

## 视频明确提及的术语

> 视频原文:"天干可以填入 **甲乙丙丁戊己庚辛壬癸** 十个字"

- 视频将"戊己"读作 wù jǐ
- "庚辛"读作 gēng xīn
- "壬癸"读作 rén guǐ

## 天干五合(合化五行关系)

视频原文:"天干五合包括**甲己合、乙庚合、丙辛合、丁壬合、戊癸合**。怎么记好呢?按照甲乙丙丁戊己、庚辛壬癸排序,n 与 n 加 5 的位置的两个字,两两相合。这就是天干五合。"

| 配对 | 化五行 |
|---|---|
| 甲己合 | 合土 |
| 乙庚合 | 合金 |
| 丙辛合 | 合水 |
| 丁壬合 | 合木 |
| 戊癸合 | 合火 |

> 注意:**两字必须相邻且能成合的条件才成立**,日的干永远不参与合。

## 在八字中的应用

- 天干 = **外显部分**: 名气、官位、冲突(容易被人看见)
- 排盘时**先看天干**(因为阳主事)
- 天干五合改变五行力量对比

## 配合地支

天干 + 地支两两配对,形成"六十甲子"(60 组合)。
