# Visual Styles Library

30+ 设计风格方向库，每种风格包含调色板、字体配对、空间节奏、视觉元素、情绪基调。

## Style Categories

### 1. 企业专业 (Corporate Professional)

#### Corporate Clean
**适用场景**: B2B SaaS, 企业服务, 咨询公司  
**色板**: 深蓝 (#003D82) + 灰白 (#F5F7FA) + 橙色强调 (#FF6B35)  
**字体**: Helvetica Neue / Arial (标题) + Open Sans (正文)  
**空间**: 舒展，section 间距 ≥ 80px  
**元素**: 线性图标，简洁图表，专业摄影  
**情绪**: 可信、稳重、专业  

#### Minimalist Pro
**适用场景**: 精品 SaaS, 设计工具, 咨询  
**色板**: 纯黑 (#000) + 纯白 (#FFF) + 单一强调色  
**字体**: Inter / SF Pro (全栈)  
**空间**: 极致留白，section 间距 ≥ 120px  
**元素**: 几何图形，单色图标，留白为主  
**情绪**: 克制、高级、专注  

#### Swiss Style
**适用场景**: 金融科技, 保险, 医疗  
**色板**: 红 (#FF0000) + 黑 (#000) + 白 (#FFF)  
**字体**: Helvetica (标题) + Univers (正文)  
**空间**: 网格系统，严格对齐  
**元素**: 网格布局，无衬线，高对比  
**情绪**: 理性、精确、权威  

---

### 2. 科技现代 (Tech Modern)

#### Brutalist Tech
**适用场景**: DevTool, 开发者产品, 技术博客  
**色板**: 黑 (#0D1117) + 荧光绿 (#39FF14) + 灰 (#8B949E)  
**字体**: Space Grotesk (标题) + Roboto Mono (代码)  
**空间**: 紧凑，边距最小化  
**元素**: 终端风格，等宽字体，ASCII 艺术  
**情绪**: 极客、原始、技术感  

#### Glassmorphism
**适用场景**: AI 产品, Web3, 未来科技  
**色板**: 半透明 (rgba(255,255,255,0.1)) + 渐变边框  
**字体**: Inter (标题 + 正文)  
**空间**: 浮动卡片，Z 轴层次  
**元素**: 模糊背景，霜玻璃效果，柔和阴影  
**情绪**: 未来、轻盈、科幻  

#### Neumorphism
**适用场景**: UI/UX 工具, 设计 App, 创意软件  
**色板**: 中性灰 (#E0E5EC) + 柔和阴影  
**字体**: Inter / Poppins  
**空间**: 卡片突出，软阴影  
**元素**: 凸出/凹陷效果，柔和边缘  
**情绪**: 柔和、触感、现代  

---

### 3. 创意活力 (Creative Vibrant)

#### Playful Bold
**适用场景**: 消费 App, 儿童产品, 娱乐  
**色板**: 多彩 (5+ 饱和色)  
**字体**: Poppins Bold (标题) + Nunito (正文)  
**空间**: 密集，元素丰富  
**元素**: 插画，卡通图标，波浪形  
**情绪**: 活泼、有趣、友好  

#### Gradient Pop
**适用场景**: 社交 App, 音乐平台, 创意工具  
**色板**: 双色渐变 (#FF6B6B → #4ECDC4)  
**字体**: Montserrat (标题) + Inter (正文)  
**空间**: 中等，呼吸感  
**元素**: 渐变背景，流体形状，高光  
**情绪**: 动感、现代、年轻  

#### Neon Vibes
**适用场景**: 游戏, 夜店, 电子音乐  
**色板**: 黑底 (#000) + 荧光色 (#FF00FF, #00FFFF)  
**字体**: Exo 2 (标题) + Rajdhani (正文)  
**空间**: 紧凑，霓虹包围  
**元素**: 发光效果，霓虹边框，赛博元素  
**情绪**: 叛逆、夜晚、电子  

---

### 4. 经典永恒 (Classic Timeless)

#### Serif Elegance
**适用场景**: 奢侈品, 高端品牌, 文化机构  
**色板**: 深棕 (#3E2723) + 米白 (#F5F5DC) + 金色 (#D4AF37)  
**字体**: Playfair Display (标题) + Lora (正文)  
**空间**: 优雅，间距适中  
**元素**: 衬线字体，优雅线条，古典图案  
**情绪**: 优雅、传统、高端  

#### Art Deco
**适用场景**: 酒店, 珠宝, 时尚  
**色板**: 黑金 (#000 + #FFD700) + 翡翠绿 (#50C878)  
**字体**: Didot (标题) + Futura (正文)  
**空间**: 对称，几何  
**元素**: 几何图案，金色装饰，对称布局  
**情绪**: 奢华、装饰、复古  

#### Mid-Century Modern
**适用场景**: 家具, 室内设计, 生活方式  
**色板**: 橙 (#FF6F00) + 绿松石 (#40E0D0) + 木色 (#8B4513)  
**字体**: Futura (标题) + Avenir (正文)  
**空间**: 平衡，功能优先  
**元素**: 有机形状，简洁线条，木质纹理  
**情绪**: 复古、温暖、实用  

---

### 5. 北欧简约 (Scandinavian Minimal)

#### Scandinavian Minimal
**适用场景**: 家居, 可持续品牌, 生活方式  
**色板**: 白 (#FFF) + 灰蓝 (#ECEFF1) + 木色 (#D7CCC8)  
**字体**: Montserrat (标题) + Open Sans (正文)  
**空间**: Lagom (恰到好处)，不过度留白  
**元素**: 简洁图标，自然摄影，木质元素  
**情绪**: 温馨、自然、舒适  

#### Lagom Aesthetic
**适用场景**: 可持续产品, 北欧品牌, 健康  
**色板**: 米白 (#F5F5F0) + 灰绿 (#A8DADC) + 深灰 (#457B9D)  
**字体**: Inter (全栈)  
**空间**: 平衡，既不拥挤也不空旷  
**元素**: 柔和色调，天然材质，简洁形式  
**情绪**: 平衡、可持续、北欧  

#### IKEA Democratic Design
**适用场景**: 大众家居, 实用产品, 功能主义  
**色板**: 蓝 (#0051BA) + 黄 (#FFDB00) + 白 (#FFF)  
**字体**: Noto IKEA (标题 + 正文)  
**空间**: 功能优先，无装饰  
**元素**: 产品摄影，示意图，价格标签  
**情绪**: 民主、实用、亲民

### 6. 信息密集 (Data-Driven)

#### Data Visualization
**适用场景**: Dashboard, 数据报告, BI 工具  
**色板**: 多色 (语义分类) + 中性底  
**字体**: IBM Plex Sans (标题) + Roboto (数据)  
**空间**: 紧凑，信息密度高  
**元素**: 图表，数字突出，色块分区  
**情绪**: 专业、数据导向、清晰  

#### Infographic Dense
**适用场景**: 年度报告, 白皮书, 研究成果  
**色板**: 主题色 (3-5 色) + 灰度辅助  
**字体**: Helvetica (标题) + Arial (正文)  
**空间**: 密集，多栏布局  
**元素**: 图标 + 数字，时间线，流程图  
**情绪**: 权威、详实、专业  

#### Magazine Editorial
**适用场景**: 新闻媒体, 杂志, 长文阅读  
**色板**: 黑 (#000) + 白 (#FFF) + 红色强调 (#E63946)  
**字体**: Georgia (标题) + Merriweather (正文)  
**空间**: 经典栏布局，行间距 1.6+  
**元素**: 大标题，引用块，图文混排  
**情绪**: 传统、可读、编辑质感

### 7. 视觉艺术 (Visual Art)

#### Brutalist Joy
**适用场景**: 艺术展览, 概念设计, 实验项目  
**色板**: 原色 (#FF0000, #0000FF, #FFFF00) + 灰  
**字体**: Arial Bold (标题) + Courier (正文)  
**空间**: 打破常规，不对称  
**元素**: 硬边，混凝土纹理，原始形式  
**情绪**: 冲突、原始、艺术  

#### Chromatic Silence
**适用场景**: 画廊, 摄影, 概念作品  
**色板**: 黑白灰 + 单一彩色点缀  
**字体**: Futura (标题) + Helvetica (正文)  
**空间**: 极简，画廊式留白  
**元素**: 高质量摄影，单色调  
**情绪**: 沉静、艺术、深度  

#### Metabolist Dreams
**适用场景**: 建筑, 未来概念, 有机设计  
**色板**: 渐变 (有机过渡) + 金属灰  
**字体**: Eurostile (标题) + Univers (正文)  
**空间**: 有机流动，模块化  
**元素**: 曲线，模块，生长感  
**情绪**: 未来、有机、流动

## Usage

1. **输入匹配**：基于行业/受众/基调从矩阵查找 TOP 3
2. **加载风格**：读取对应风格的详细定义（色板/字体/元素）
3. **生成代码**：应用到 CSS 变量和组件样式
4. **用户确认**：展示 3 个方向的 Demo 预览，用户选 1

## Adding New Styles

要添加新风格，在本文件对应类别下补充：

```markdown
#### [New Style Name]
**适用场景**: [具体场景]  
**色板**: [主色 + 辅色 + 强调色，带 hex 值]  
**字体**: [标题字体] (标题) + [正文字体] (正文)  
**空间**: [留白程度，section 间距]  
**元素**: [关键视觉元素]  
**情绪**: [3-5 个情绪关键词]  
```

并更新 Style Selection Matrix 添加匹配规则。
