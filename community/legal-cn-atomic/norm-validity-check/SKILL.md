# 法条效力验证 (norm-validity-check)

> 所有法律推理的前提 — 法条必须现行有效。

## 何时触发

- 任何 `syllogistic-reasoning` 之前
- 案件准备阶段的全套法条清单筛查
- 类案研究时核对判决所引法条
- 学术 / 文书写作前核对引用准确性

## 何时不触发

- 法律适用是否合理 → 用 `syllogistic-reasoning`
- 法律价值判断 → 哲学 / 政策分析层面，非效力问题
- 不引用具体法条的纯概念讨论

## 工作流：4 维效力审查

### 维度 1：时间效力（是否仍现行有效）

| 状态 | 含义 | 应对 |
|---|---|---|
| **现行有效** | 文本未被废止 / 修改 / 失效 | 可直接引用 |
| **已被修改** | 现行文本与引用版本不同 | 必须更新为最新文本 |
| **已被废止** | 整体失效 | 不得引用，需找替代法条 |
| **已失效（期满 / 临时性）** | 因时间届满 / 情形消失而失效 | 不得引用 |
| **司法解释已废止 / 失效** | 同上 | 不得引用 |
| **待核查** | 无法确认 | 标注「[待核查]」，暂不引用 |

**核查方式**：
- 数据库：北大法宝 / 威科先行 / 国务院公报 / 最高法公报
- 官方网站：人大网（npc.gov.cn）、国务院网（gov.cn）、最高法官网（court.gov.cn）
- 若无数据库连接 → 标注「**待人工核对**」，不臆测

### 维度 2：空间效力（适用地域范围）

| 情况 | 含义 | 应对 |
|---|---|---|
| **全国有效** | 法律、行政法规、司法解释 | 默认全国适用 |
| **仅特定地区有效** | 地方性法规、地方政府规章 | 标注适用地区 |
| **特定主体有效** | 行业规范、特定身份规范 | 标注适用主体 |
| **跨境 / 国际私法** | 需经冲突规范指引 | 转入国际私法 skill |

⚠️ 地方性法规与地方政府规章**不得作为大前提**适用于外地案件。

### 维度 3：位阶效力（是否与上位法冲突）

中国法效力位阶（从高到低）：

```
1. 宪法
2. 法律（全国人大及其常委会）
3. 行政法规（国务院）
4. 地方性法规（省级人大）/ 部门规章（国务院部委）
5. 地方政府规章（省级政府）
6. 规范性文件（有规范作用但非严格意义"法源"）
```

冲突规则：
- **上位法优于下位法**：下位法与上位法冲突 = 下位法无效（在该冲突点上）
- **新法优于旧法**：同位阶法冲突，新法优于旧法
- **特别法优于一般法**：同位阶法冲突，特别规定优先
- **变通规定 vs 原规定**：经授权的变通规定优先于原规定

**审查要点**：
- 引用 X 法条 → 是否存在同主题的上位法？
- 该上位法是否已覆盖 / 修改 / 替代 X 的内容？
- 是否存在"特别法"对本主题有不同规定？

### 维度 4：形式效力（是否完成生效程序）

| 检查项 | 内容 |
|---|---|
| 是否经法定程序通过 | 全国人大常委会通过？国务院公布？ |
| 是否按期公布 | 是否在《全国人大常委会公报》/《国务院公报》/ 官方网站公布 |
| 施行日期 | 是否到了规定的施行日 |
| 是否被有权机关撤销 | 是否有撤销决定 |

## 常见错误（自查清单）

| 错误模式 | 含义 | 防范 |
|---|---|---|
| **引用已废止法条** | 引用的是已被废止 / 修改前的版本 | 维度 1 强制核查 |
| **地方性法规越界适用** | 把 A 地的地方性法规套到 B 地案件 | 维度 2 强制标注适用地域 |
| **位阶倒挂** | 用下位法反对上位法 | 维度 3 强制位阶审查 |
| **混用新旧版本** | 同时引用同一法条的新旧版本 | 维度 1 注明引用版本日期 |
| **信赖失效司法解释** | 引用已被新法替代的旧司法解释 | 维度 1 区分"司法解释"与"法律" |
| **未注明施行日期** | 引用未生效的法条 | 维度 4 核施行日期 |

## 重要提示

### 关于司法解释的效力

- 最高法 / 最高检的司法解释属于"法律解释"，效力**等同于法律**
- 但当法律修改后，旧司法解释可能**不再适用**——必须核对
- 最高法"指导性案例"具有**事实上的参照效力**，非严格法源

### 关于"指导性案例"与"典型案例"

- **指导性案例**（最高法发布）：各级法院应当参照（《最高法关于案例指导工作的规定》）
- **典型案例**（最高法 / 最高检发布）：仅具有参考 / 宣传作用
- **普通案例**：仅在类案检索中作为参考

### 关于新法 / 旧法的过渡

法律修改后通常有"过渡条款"：
- **溯及既往**：原则上不溯及既往（民商事领域）
- **从旧兼从轻**：刑事领域"有利于被告人"原则
- **特别规定**：部分法律设有特别过渡安排
