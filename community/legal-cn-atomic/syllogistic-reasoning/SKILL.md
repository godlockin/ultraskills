# 法律三段论推理 (syllogistic-reasoning)

> 法律推理的核心方法。形式化、可审查、可反驳。

## 何时触发

- 用户问"为什么构成 X"、"能不能主张 Y"、"是不是违约"、"按法条推一下"
- 已有事实清单（来自 `legal-fact-extraction`）+ 法条引用，需要**形式化推导**
- 审查律师 / AI 给出的法律意见是否逻辑严密

## 何时不触发

- 类推 / 类比推理（用 `analogical-reasoning`）
- 概念解释（用 `legal-concept-clarification`）
- 事实提取（用 `legal-fact-extraction`）
- 案件胜诉率预测（用更高阶 compound skill，须先做完本步骤）

## 工作流：P-F-C 三段论

### 步骤 1：识别 / 构建大前提（P）

**大前提**：具有普遍约束力的法律规范，形式为「若 ... 则 ...」

来源：
- 法律（宪法 → 法律 → 行政法规 → 地方性法规 → 规章）
- 司法解释（最高法 / 最高检）
- 习惯法（极少，仅在民商事领域补缺）

**形式化表达**：
```
P: 若 [构成要件 / 事实条件] 则 [法律后果]
```

**前置验证**（必做）：
- [ ] 法条现行有效？（调 `norm-validity-check`）
- [ ] 法条是否被司法解释细化？
- [ ] 是否存在但书 / 例外条款？
- [ ] 法条是否有兜底条款需要补充？

### 步骤 2：核对小前提（F）

**小前提**：本案具体事实是否满足大前提的构成要件

```
F: 本案中，[具体事实 1] + [具体事实 2] + ... [满足 / 不满足] 大前提 P 的要件
```

**逐要件核对**（避免"打包"判断）：
- 要件 1 → 事实 X 是否满足？
- 要件 2 → 事实 Y 是否满足？
- 要件 3 → 事实 Z 是否满足？
- 但书 / 例外 → 本案是否落入例外情形？

⚠️ **核心原则**：要件未全部满足 = 大前提不适用，不可"凑要件"。

### 步骤 3：推出结论（C）

**结论**：本案应承担 / 获得 / 不应承担 / 不应获得的具体法律后果

```
C: 因此，本案 [法律后果]
```

**结论的形式化**：
- 法律效果的发生（如「成立合同关系」「承担违约责任」「构成侵权」）
- 法律效果的消灭（如「合同解除」「时效届满」「权利消灭」）
- 法律效果的变更（如「合同变更」「情势变更」）

### 步骤 4：检验链完整性

检查整个推理链是否经得起反驳：

- [ ] 大前提是否现行有效？
- [ ] 小前提是否完整覆盖大前提的所有要件？
- [ ] 但书 / 例外条款是否核对？
- [ ] 是否存在「隐藏要件」未列出？
- [ ] 是否有反向解释可能？
- [ ] 是否有相反判例 / 学说？

### 步骤 5：标注推理强度

按推理结论的可信度分三档：

| 强度 | 含义 | 适用 |
|---|---|---|
| **强 (★★★)** | 大前提现行有效 + 要件全部满足 + 无但书适用 | 高确定性 |
| **中 (★★)** | 大前提有效 + 主要要件满足 + 但书存疑 | 需补充事实 |
| **弱 (★)** | 大前提存疑 / 要件不齐 / 但书适用 | 高度不确定 |

## 输出模板

```yaml
三段论推理:
  大前提:
    法条: [具体条文]
    内容: "[法律规范的完整表述]"
    有效性: [已验证 / 待验证]
    但书: [如有]
  
  小前提:
    要件核对:
      - 要件: [要件 1]
        本案事实: [事实描述]
        满足: 是/否/部分
        证据: [如有]
      - 要件: [要件 2]
        本案事实: [事实描述]
        满足: 是/否/部分
        证据: [如有]
      ...
    整体判断: [满足大前提的全部要件 / 部分要件 / 不满足]
  
  结论:
    内容: "[具体法律后果]"
    强度: [★★★/★★/★]
    不确定性来源: [如有]
  
  反驳预演:
    - 可能反驳: [对方可能的反论]
      应对: [本推理如何应对]
    ...
```

## 常见错误（自查清单）

| 错误模式 | 含义 | 防范 |
|---|---|---|
| **要件偷换** | 把大前提的要件 A 偷换为相似概念 B | 逐字核对要件 |
| **事实剪裁** | 只挑支持结论的事实，忽略否定要件的事实 | 列出全部要件 + 全部事实 |
| **但书忽略** | 不检查但书 / 例外条款 | 步骤 4 强制检查 |
| **大前提失效** | 引用已被废止 / 修改的法条 | 必走 `norm-validity-check` |
| **跨法域混用** | 把 A 法域的法条套到 B 法域的案件 | 步骤 1 标注法域 |
| **反向解释缺位** | 没考虑是否有反向解释的可能 | 步骤 4 强制反向推演 |

## 重要限制

### 刑法的特殊规则

- **罪刑法定**：刑法大前提必须**严格按法律条文**适用，禁止类推
- **疑罪从无**：要件存疑时，作出有利于被告人的解释
- **加重 / 减轻 / 从轻 / 免除**情节必须严格按法律规定核对

### 民法的特殊规则

- **意思自治**：合同领域优先尊重当事人约定（约定 > 法定）
- **诚实信用**：兜底条款（民法典第 7 条）
- **举轻明重 / 举重明轻**：可作为辅助推理，但不是大前提本身

### 行政法的特殊规则

- **合法行政**：行政机关必须有大前提（法定职责）才可作出具体行政行为
- **比例原则**：即使大前提成立，也需比例性审查
