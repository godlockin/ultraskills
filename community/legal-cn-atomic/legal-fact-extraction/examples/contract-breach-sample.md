# 示例 1：合同违约案件的事实要素提取

## 原始材料（用户输入）

> 我和张三签了一份房屋租赁合同，约定 2024 年 3 月 1 日起租，月租 8000 元，押一付三。张三从 5 月开始就不付租金了，我催了好几次，他说公司经营困难。我手上有微信聊天记录、转账记录和那份合同。现在我想让他搬走并支付拖欠的租金。

## Skill 输出

```yaml
案件事实要素清单:
  当事人:
    - 主体: 用户（叙述者）
      角色: 出租人（拟主张）
      身份信息: 未提供
    - 主体: 张三
      角色: 承租人（拟主张）
      身份信息: 未提供
  
  时间线:
    - 时间: 2024-03-01（之前）
      主体: 用户 + 张三
      行为: 签订《房屋租赁合同》
      证据: 合同原件（用户陈述）
    - 时间: 2024-03-01
      主体: 用户 + 张三
      行为: 约定起租日、租金 8000/月、押一付三
      证据: 同上合同
    - 时间: 2024-05-01 起
      主体: 张三
      行为: 停止支付租金
      证据: 转账记录（用户陈述）
    - 时间: 2024-05-01 之后某时
      主体: 用户
      行为: 通过微信催讨租金（"好几次"）
      证据: 微信聊天记录（用户陈述）
    - 时间: 2024-05-01 之后某时
      主体: 张三
      行为: 答复"公司经营困难"
      证据: 微信聊天记录（用户陈述）
  
  标的:
    - 类型: 房屋使用权 + 租金支付义务
      内容: 房屋（地址、面积、权属未提供）
      价值: 月租金 8000 元
  
  可能法律关系:
    - 房屋租赁合同关系（民法典第 703 条）
    - 合同违约责任（民法典第 577 条）
  
  证据缺口:
    - [证据缺失] 房屋地址、权属证明（是否用户本人产权 / 有权转租）
    - [证据缺失] 押金支付凭证（"押一付三"是否实际履行）
    - [证据缺失] 张三已支付租金的具体月份、金额
    - [证据缺失] 微信催讨的具体日期与次数
    - [事实空白] 合同是否约定违约金条款、解除条件
    - [事实空白] 合同租期起止日
    - [事实空白] 张三目前是否仍占有房屋
```

## 衔接下游

| 下一步 | 用哪个 skill |
|---|---|
| 解释"押一付三"的法律含义 | `legal-concept-clarification` |
| 把违约事实套入民法典条款做推理 | `syllogistic-reasoning` |
| 验证民法典第 577 条现行有效 | `norm-validity-check` |
| 起草催告函 / 解除合同通知 | 上游 `commercial-legal` plugin |
| 计算拖欠租金金额 | 简单算术（无须 skill） |
