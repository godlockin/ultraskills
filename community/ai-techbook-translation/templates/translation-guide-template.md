## 1. 翻译原则 (3 大目标)

1. **正确性优先**: 公式/术语/数据 100% 准确,不为了"流畅"牺牲"准确"
2. **中文流畅**: 避免翻译腔,用读者熟悉的表达
3. **风格一致**: 整本书像一个人写的

## 2. 4 大铁律 (绝对禁止违反)

### 2.1 公式 100% 保留

```markdown
原文: $f_\theta(x) = Wx + b$
译文: $f_\theta(x) = Wx + b$    # ← 完全一致
```

**禁止**: 修改 `$...$` `$$...$$` 内任何字符(包括空格)。

### 2.2 术语严格一致

- 所有专有名词查 `GLOSSARY.md`
- 同一概念全书中必须用同一译法
- 缩写首次出现时展开: `LLM (大语言模型)`

### 2.3 代码完整

```python
原文:
```python
def foo():
    return 42
```

译文: (代码块原样保留)
```python
def foo():
    return 42
```
```

### 2.4 链接保留

- 所有链接 100% 保留
- 图片路径通常 `../images/...` 不变
- 内部链接跨章跳转保留

## 3. 翻译风格

### 3.1 段落

| 原文 | 推荐 | 避免 |
|------|------|------|
| "we will see" | "我们会看到" | "我们将看到" |
| "Note that" | "注意" / "需要指出" | "请注意" |
| "It is worth noting" | "值得说明" | "值得注意的是" |
| "Let's consider" | "我们考虑" | "让我们考虑" |

### 3.2 句式

- **避免翻译腔**: "这是一个用于 X 的工具" → "这个工具用于 X"
- **避免长定语**: 中文多用"前短后长"
- **拆长句**: 英文长句拆为多个中文短句

### 3.3 标点

| 场景 | 规则 | 例 |
|------|------|-----|
| 中文段落 | 全角标点 | ,。;:!?()""'' |
| 英文/数字旁 | 半角标点 | Git, Python, 2024 |
| 引号 | 中文 `"..."` , 代码 `"..."` | |
| 列表 | 中文 , 结尾; 代码 ; 结尾 | |

### 3.4 数字与单位

- 数字保留原样: `100, 3.14, 1e-10`
- 单位中英对照(首次): `1 GB (1 吉字节)`
- 货币: `$100 (100 美元)`

### 3.5 标题

- H1/H2 双译: `## Vector Spaces (向量空间)`
- H3+ 仅中文: `### 向量子空间`

## 4. 术语处理

### 4.1 已有 GLOSSARY

直接查 `GLOSSARY.md`,按表中译法。

### 4.2 未在 GLOSSARY

1. 查网络资源 (Wikipedia / Google Scholar)
2. 参考相关中文文献
3. 提出候选译法,在 PR 中讨论
4. 加入 GLOSSARY.md 后通知团队

### 4.3 专有名词

- 公司/产品: 保留英文 (OpenAI, Claude, PyTorch)
- 人名: 保留英文 (Yann LeCun, 不译"杨立昆")
- 论文: 保留英文标题

## 6. 自检清单

## 7. 协作流程

```
1. 申领章节 (PR 中 @maintainer)
2. 翻译 (2-3 天)
3. 自检 (半天)
4. 提交 PR (含 GLOSSARY 增量)
5. Reviewer 验收
6. 合并到主分支
```

## 8. 常见错误案例

### ❌ 错误 1: 公式被翻译

```markdown
原文: $x^2 + y^2 = z^2$
错误译文: $x² + y² = z²$     # ← 上标变字符
正确译文: $x^2 + y^2 = z^2$
```

### ❌ 错误 2: 术语不一致

```markdown
Ch03: "梯度下降 (Gradient Descent)"
Ch07: "梯度下降法 (Gradient Descent)"   # ← 译法不一致
```

### ❌ 错误 3: 代码块被改

```markdown
原文: print("Hello")  # 注释
错误译文: print("你好")  # 注释    # ← 改代码
正确译文: print("Hello")  # 注释    # ← 代码块原样保留
```

### ❌ 错误 4: 翻译腔

```markdown
原文: The model learns to predict the next token.
错误译文: 模型学习去预测下一个 token。
正确译文: 模型学会预测下一个 token。
```
