# 理镜 (cn-limirror) — 要件推理镜

> **镜鉴 suite · 第二镜**：让每个法律论证站得住、经得起反驳。

## 与其他"推理"类 skill 的本质区别

| 维度 | 普通 syllogism | 理镜 |
|---|---|---|
| 推理结构 | 单线 P-F-C | **主线 + 反线** 双链结构 |
| 漏洞检测 | 无 | **6 类常见错误** 自动扫描 |
| 强度评分 | 单一置信度 | **4 维度评分**（前提强度/要件覆盖/但书风险/对抗韧性）|
| 类案建议 | 无 | **自动标注** 类案回链需求 + MCP 路径 |
| 来源标注 | 弱 | **3-tier 标注**（法条原文 / 数据库 / 模型知识）|

## 何时触发

- 已有案镜输出（事实清单 + 法律关系）+ famirror 输出（法条现行有效）
- 用户问"按法条推一下"、"能不能主张 X"、"为什么构成"
- 审查他人 / AI 给出的法律意见是否逻辑严密

## 何时不触发

- 仅做概念解释 → 用案镜的概念补充
- 仅做事实提取 → 用案镜
- 类比 / 归纳 / 溯因等非演绎推理（未来扩展 skill）
- 胜诉率预测 → 需更高阶 compound skill

## 工作流：主线 + 反线 双链推理

### 步骤 1：识别 / 构建大前提（P）

**大前提**：具有普遍约束力的法律规范

来源优先级（3-tier 来源标注）：

| Tier | 来源类型 | 引用方式 |
|---|---|---|
| **Tier 1** | 法条原文（人大网 / 国务院公报）| `[法条原文]` |
| **Tier 2** | 数据库检索结果（元典/法宝/威科）| `[数据库: 来源]` |
| **Tier 3** | 模型知识（未经权威数据库确认）| `[模型知识 · 需验证]` |

⚠️ **强约束**：Tier 3 来源必须经 famirror 验证后才能用;否则明示标注「待权威核验」。

**但书 / 例外强制检索**：
- 法律正文中的但书
- 司法解释中的例外
- 特别法的优先条款

### 步骤 2：核对小前提（F）—— 逐要件

**小前提**：本案具体事实是否满足大前提的构成要件

**逐要件核对原则**（避免"打包"判断）：
```
要件 1: [法律规范的要件描述]
  本案事实: [对应事实]
  满足度: [完全满足 / 部分满足 / 不满足 / 待补证]
  证据: [证据来源 Tier]
要件 2: ...
要件 3: ...
但书 / 例外: [本案是否落入例外]
```

⚠️ **核心原则**：要件未全部满足 = 大前提不适用，**不可"凑要件"**。

### 步骤 3：推出结论（C）

**结论**：本案应承担 / 获得 / 不应承担 / 不应获得的具体法律后果

按结论类型分类：
- **法律效果发生**：成立 / 生效 / 取得 / 承担
- **法律效果消灭**：解除 / 撤销 / 失效 / 消灭
- **法律效果变更**：变更 / 调整 / 部分无效
- **程序效果**：立案 / 受理 / 移送 / 中止

### 步骤 4：反方观点预演（关键创新）

**主动**扮演反方，对主线推理发起攻击：

| 反方攻击维度 | 检查项 |
|---|---|
| 大前提攻击 | 法条是否现行有效？是否被修改 / 废止？ |
| 要件攻击 | 是否有要件未被充分论证？ |
| 但书攻击 | 但书 / 例外是否被忽略？ |
| 事实攻击 | 关键事实是否仅有单方陈述？ |
| 证据攻击 | 证据链是否完整？ |
| 程序攻击 | 管辖 / 时效 / 主体是否适格？ |
| 反向解释 | 是否有相反的学说 / 判例？ |

每条反方观点需评估：
- 攻击强度：[致命 / 严重 / 中等 / 轻微 / 无效]
- 应对策略：[反驳证据 / 补强论证 / 转换思路 / 承认部分成立]

### 步骤 5：6 类常见错误自动扫描

| 错误模式 | 含义 | 自动检测逻辑 |
|---|---|---|
| **要件偷换** | 大前提的要件 A 被偷换为相似概念 B | 比对要件字面 |
| **事实剪裁** | 只挑支持结论的事实，忽略否定要件的事实 | 列出全部要件 + 全部事实交叉 |
| **但书忽略** | 不检查但书 / 例外条款 | 强制扫描 |
| **大前提失效** | 引用已被废止 / 修改的法条 | 调 famirror |
| **跨法域混用** | 把 A 法域的法条套到 B 法域的案件 | 标注法域 |
| **反向解释缺位** | 没考虑是否有反向解释的可能 | 步骤 4 强制反向推演 |

### 步骤 6：4 维强度评分

| 维度 | 评分依据 | 权重 |
|---|---|---|
| 大前提强度 | Tier 1/2/3 来源 + famirror 验证结果 | 0.30 |
| 要件覆盖度 | 全部要件的满足情况 | 0.30 |
| 但书风险 | 但书 / 例外是否落入 | 0.20 |
| 对抗韧性 | 反方攻击下的存活能力 | 0.20 |

**总分 = 加权求和**,分档：
- **0.8-1.0**: 强 — 高置信
- **0.6-0.8**: 中 — 需补强
- **0.4-0.6**: 弱 — 风险高
- **<0.4**: 不成立

### 步骤 7：类案回链建议

若主线推理存在**类比漏洞 / 解释空间**,建议走类案检索：

| 触发条件 | 建议动作 |
|---|---|
| 法条新颖（3 年内） | 检索最高法指导性案例 |
| 解释存在分歧 | 检索不同学说的代表案例 |
| 事实特殊 | 检索类似事实的判决 |
| 涉及新业态 | 检索近期典型案例 |

推荐的 MCP 类案源：
- **元典 (yuandian)**：免费 + OAuth，公开判决
- **聚法案例**：覆盖广
- **北大法宝**：权威性强（付费）
- **威科先行**：国际 + 国内

## 特殊领域规则

### 刑法

- **罪刑法定**：严格按条文,**禁止类推**
- **疑罪从无**：要件存疑 → 有利被告解释
- **从重 / 从轻 / 减轻 / 免除**情节严格按法定

### 民法

- **意思自治**：合同领域约定 > 法定
- **诚实信用**：兜底（民法典第 7 条）
- **举轻明重 / 举重明轻**：辅助推理

### 行政法

- **合法行政**：需法定职责
- **比例原则**：即使成立也需比例审查
