# 镜鉴 (jingjian) — 中国法结构化推理 suite

> 4 面镜子,看清每一个法律问题。

## 品牌定位

| 项 | 内容 |
|---|---|
| **品牌名** | 镜鉴 (jingjian) |
| **英文标识** | jingjian |
| **目标** | 把法律工作从"经验直觉"提升为"结构化可审查" |
| **核心价值** | 每个法律论证**站得住 + 经得起反驳 + 可追溯** |
| **适用范围** | 中国大陆法律（民商事 / 刑事 / 行政 / 合规） |
| **基座** | CSlawyer1985/claude-for-legal-ZH（Apache 2.0）+ 公知法学方法论 |
| **协议** | MIT（独立创作,综合自多源公开内容） |

## 4 面镜子

| 镜 | ID | 角色 | 类比 |
|---|---|---|---|
| **案镜** | `cn-anmirror` | 案件分诊 | 中医"望" — 看清病情 |
| **理镜** | `cn-limirror` | 要件推理 | 中医"闻/问" — 推导病因 |
| **法镜** | `cn-famirror` | 规范审查 | 中医"切" — 把脉诊断 |
| **鉴枢** | `cn-jianshu` | 编排入口 | 主治医师 — 综合诊治 |

## 调用顺序（典型）

```
用户任务
  ↓
鉴枢 (路由 + 编排)
  ↓
案镜 (事实地基)
  ↓
法镜 (法条现行有效)
  ↓
理镜 (推理 + 反驳)
  ↓
上游 plugin (实务工作)
  ↓
综合输出
```

## 与 CSlawyer1985 plugins 协同

镜鉴 suite 提供**结构化推理骨架**,CSlawyer1985 plugins 提供**实务工作能力**:

| 镜鉴 (骨架) | CSlawyer1985 (实务) |
|---|---|
| 案镜：事实要素提取 | commercial-legal：合同起草实务 |
| 理镜：三段论推理 | litigation-legal：诉讼策略 + 文书 |
| 法镜：法条效力验证 | privacy-legal：PIPL 合规审计 |
| 鉴枢：编排 | employment-legal：劳动实务处理 |

**关系**：镜鉴先行,plugin 接力。两者协同而非替代。

## 协议与版权声明

### 镜鉴 suite

- **协议**: MIT
- **来源**: ultraskills 独立创作
- **方法论综合自**:
  - 公知法学教材（要素分析方法论 / 三段论 / 法律演绎）
  - 公知立法法
  - 司法考试 / 法考训练方法
  - 法律服务流程最佳实践

### 基座（CSlawyer1985/claude-for-legal-ZH）

- **协议**: Apache 2.0
- **关系**: 作为 submodule 引入（`external/claude-for-legal-ZH/`）
- **使用方式**: 通过 plugin 调度（不复制文本）
- **保留**: 上游版权声明 + license 副本

### 与 THUYRan/Legal-Skills-Chinese 的关系

- **协议**: CC BY-NC-ND 4.0（禁衍生）
- **关系**: **未引入**任何 THUYRan 文本 / SKILL.md
- **借鉴方式**: 仅借鉴"原子推理 + 编排"的概念性思路,具体内容全部独立创作
- **差异**: 镜鉴 suite 的所有 SKILL.md 均为全新撰写,综合自公知方法论

## 重要免责

⚠️ **镜鉴 suite 输出仅为律师审查草稿,不是法律意见,不替代律师。**
- 涉及法条引用必须经权威数据库核验
- 涉及案件预测必须考虑类案 + 当地司法实践
- 涉及实务工作（合同 / 诉状）必须有律师最终审阅
