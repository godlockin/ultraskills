# 法镜 (cn-famirror) — 规范活检镜

> **镜鉴 suite · 第三镜**：在用任何法条之前,先看清它的"生命体征"。

## 与其他"法条审查"类 skill 的本质区别

| 维度 | 普通 validity check | 法镜 |
|---|---|---|
| 效力维度 | 时间 / 位阶 | **6 维**（+修订 + 配套 + 时效 + 引用标准化）|
| 修订追踪 | 无 | **完整修订链** + 节点标注 |
| 司法解释配套 | 手动查 | **自动识别** 配套解释 |
| 时效倒计时 | 无 | **诉讼时效等自动计算** |
| 引用标准化 | 自由格式 | **机器可读标准格式** 输出 |

## 何时触发

- 任何 `limirror` 推理之前 — 验证大前提现行有效
- 案件准备阶段的全套法条清单筛查
- 类案研究时核对判决所引法条
- 学术 / 文书写作前核对引用准确性

## 何时不触发

- 法律适用合理性 → 用 limirror
- 价值判断 → 哲学 / 政策分析
- 不引用具体法条的纯概念讨论

## 工作流：6 维生命体征检查

### 维度 1：时间效力（现行状态）

| 状态 | 含义 | 应对 |
|---|---|---|
| **现行有效** | 文本未被废止 / 修改 / 失效 | 可直接引用 |
| **已被修改** | 现行文本与引用版本不同 | 必须更新为最新文本 |
| **已被废止** | 整体失效 | 不得引用,需找替代法条 |
| **已失效（期满 / 临时性）** | 因时间届满 / 情形消失而失效 | 不得引用 |
| **司法解释已废止 / 失效** | 同上 | 不得引用 |
| **待核查** | 无法确认 | 标注「[待核查]」,暂不引用 |

**核查方式优先级**（3-tier）：
1. **Tier 1**：人大网 / 国务院网 / 最高法官网 / 最高检网
2. **Tier 2**：北大法宝 / 威科先行 / 元典
3. **Tier 3**：模型知识 → 必须标注「[需验证]」

### 维度 2：空间效力（适用地域 / 主体）

| 情况 | 含义 | 应对 |
|---|---|---|
| **全国有效** | 法律 / 行政法规 / 司法解释 | 默认全国适用 |
| **仅特定地区** | 地方性法规 / 地方政府规章 | 标注适用地区 |
| **特定主体** | 行业规范 / 特定身份规范 | 标注适用主体 |
| **跨境 / 国际私法** | 需经冲突规范指引 | 转入国际私法 skill |

⚠️ 地方性法规**不得**作为大前提适用于外地案件。

### 维度 3：位阶效力（冲突扫描）

中国法效力位阶（从高到低）：

```
1. 宪法
2. 法律（全国人大及其常委会）
3. 行政法规（国务院）
4. 地方性法规（省级人大）/ 部门规章（国务院部委）
5. 地方政府规章（省级政府）
6. 规范性文件（有规范作用但非严格意义"法源"）
```

**冲突规则**（位阶扫描自动应用）：

| 规则 | 应用 |
|---|---|
| 上位法优于下位法 | 下位法与上位法冲突 → 下位法在该冲突点无效 |
| 新法优于旧法 | 同位阶法冲突,新法优先 |
| 特别法优于一般法 | 同位阶法冲突,特别规定优先 |
| 变通规定 vs 原规定 | 经授权的变通规定优先 |

### 维度 4：修订链追踪

| 节点 | 含义 |
|---|---|
| **施行日** | 法规生效日 |
| **最近修订** | 距今最近一次修改 |
| **重大修订** | 影响条款内容的修订（与效力位阶 / 适用范围相关）|
| **历史版本** | 各版本文本（用于追踪条文变迁）|

输出形式：
```
法条 X
  原始施行: YYYY-MM-DD（[版本]）
  第 1 次修订: YYYY-MM-DD（[修订要点]）
  第 2 次修订: YYYY-MM-DD（[修订要点]）
  最近重大修订: YYYY-MM-DD
  现行版本: YYYY-MM-DD 施行版
```

### 维度 5：司法解释 + 配套规范识别

**自动识别**与本法条配套的：
- 最高法 / 最高检司法解释
- 国务院实施细则
- 部门规章 / 规范性文件
- 最高法指导性案例

| 配套类型 | 标识 | 必要性 |
|---|---|---|
| 核心解释 | `[司法解释 · 已配套]` | 必查 |
| 推荐案例 | `[指导性案例 · N 件]` | 重要 |
| 实施细则 | `[实施细则]` | 参考 |

### 维度 6：时效倒计时

对涉及时效的法条 / 制度,**计算**时效倒计时：

| 制度 | 时效 | 起始点 |
|---|---|---|
| 普通民事诉讼时效 | 3 年 | 权利人知道或应当知道权利受到损害之日 |
| 特殊民事诉讼时效 | 1 年 / 4 年 / 20 年 | 依具体规定 |
| 刑事追诉时效 | 5/10/15/20 年 / 终身 | 犯罪行为终了之日 |
| 除斥期间 | 1/3/5 年等 | 法律规定 |
| 仲裁时效 | 1 年 | 知道或应当知道权利被侵害之日 |

输出形式：
```
时效计算:
  起算点: [YYYY-MM-DD 或 "待补"]
  时效期间: [X 年]
  时效届满: [YYYY-MM-DD 或 "待补"]
  距今剩余: [X 天 / 已过期 X 天]
  中断 / 中止情形: [如有]
```

## 标准化引用格式

输出**机器可读**的引用规范：

```yaml
标准化引用:
  完整格式: "《[法名]》第 [X] 条 第 [Y] 款（[YYYY-MM-DD 施行版]）"
  简化格式: "《[法名]》第 [X] 条"
  Tier: [Tier 1 / Tier 2 / Tier 3]
  配套必引: [如有]
```

## 常见错误（自查清单）

| 错误模式 | 含义 | 防范 |
|---|---|---|
| 引用已废止法条 | 引用已被废止 / 修改前的版本 | 维度 1 强制核查 |
| 地方性法规越界适用 | 把 A 地的地方性法规套到 B 地案件 | 维度 2 强制标注 |
| 位阶倒挂 | 用下位法反对上位法 | 维度 3 强制位阶审查 |
| 混用新旧版本 | 同时引用同一法条的新旧版本 | 维度 4 注明引用版本日期 |
| 信赖失效司法解释 | 引用已被新法替代的旧司法解释 | 维度 5 区分司法解释与法律 |
| 错过时效 | 未计算诉讼时效 | 维度 6 自动计算 |
| 未注施行日期 | 引用未生效的法条 | 维度 4 核施行日期 |

## 关于指导性案例 / 典型案例

- **指导性案例**（最高法发布）：各级法院**应当参照**（《最高法关于案例指导工作的规定》）
- **典型案例**（最高法 / 最高检发布）：仅**参考 / 宣传**作用
- **普通案例**：仅类案检索参考

## 关于新法 / 旧法过渡

法律修改后的过渡规则：

| 领域 | 规则 |
|---|---|
| 民商事 | 原则上**不溯及既往** |
| 刑事 | **从旧兼从轻**（有利于被告人） |
| 行政 | 一般不溯及,例外从优 |
| 特别规定 | 部分法律设有特别过渡安排 |
