# 5 维度评估 Checklist

> 评估任何内容时,确保 5 个维度都覆盖。**禁止只评估 1-2 个维度就走人**。

---

## 1️⃣ Factual Accuracy Within Domain · 领域内事实准确性

```
□ 该 claim 是否符合 {expert_domain} 当前共识?
□ 是否有过时信息?(注明 vintage)
□ 是否有术语混淆/错误归属?
□ 置信度标注:
   [HIGH] = 同行评议 / 广泛复制 / 业界公认
   [MED]  = 合理但有争议
   [LOW]  = 推测 / 轶事证据
   [N/A]  = 非该专家可判断范围
```

**反例**:
- ❌「这个产品很棒」(无置信度 + 无具体证据)
- ✅「这个产品上线 6 个月,NPS 62,留存 80% [HIGH, 基于公开 dashboard]」

---

## 2️⃣ Practical Applicability & Implementation Feasibility · 实用性与可执行性

```
□ 该建议在现实约束下真能落地?(预算/基础设施/技能/时间)
□ 前置条件是什么?
□ 已知失败模式有哪些?
□ 最小可行版本 vs 完整实现的差距?
```

**反例**:
- ❌「应该用 AI」(没说哪种、什么场景、什么数据)
- ✅「用开源 LLM 微调(具体到 mistral-7b),需要在 RTX 4090 上跑 8 小时,常见失败是数据标注质量低导致 hallucination 增加」

---

## 3️⃣ Hidden Assumptions & Logical Gaps · 隐含假设与逻辑漏洞

```
□ 论点建立在哪些未言明的前提上?
□ 哪些假设在常见现实条件会崩?
□ 范围蔓延 — 这个建议在哪些场景下被过度泛化?
□ 缺哪些变量 / 数据 / 上下文?
```

**反例**:
- ❌「所有人都会用 ChatGPT」(暗藏假设:用户都是科技极客)
- ✅「假设目标用户是 18-35 岁有 IT 基础的城市白领,如果是 50+ 群体这个结论不成立」

---

## 4️⃣ Contrarian / Alternative Perspectives · 反驳与替代视角

```
□ 该领域有谁会反对这个观点?
□ 至少 1 个可信的替代方法是什么?
□ 在什么条件下这个主流观点会失效?
□ 有没有新兴研究/实践挑战这个共识?
```

**反例**:
- ❌「大家都说 X,所以 X 是对的」(诉诸权威)
- ✅「虽然主流共识是 X,但 [Person B, 2024] 的实证研究表明在 [特定场景] 下 Y 更有效」

---

## 5️⃣ Domain-Specific Risks & Opportunities · 领域特定风险与机会

```
□ 哪些是该领域专家才能预见的坑?
□ 哪些高价值机会被遗漏/低估?
□ 该领域特有的监管/伦理/安全问题?
□ 二阶效应是什么?
```

**反例**:
- ❌「直接上线」(无领域风险评估)
- ✅「医疗领域需 FDA 二类器械认证,数据需 HIPAA 合规;否则面临 [具体罚款额]」

---

## 📋 5 维度评估输出模板

```markdown
## [Topic Name] — 5 维度评估

**Expert**: {expert_role}
**Domain**: {expert_domain}

### 1. Factual Accuracy
- Claim: [...] — [HIGH/MED/LOW] — [证据 / vintage]
- Claim: [...] — ...

### 2. Practical Applicability
- [可落地?前置条件?最小版本?]

### 3. Hidden Assumptions
- [列 2-3 个隐含假设 + 何时失效]

### 4. Contrarian View
- [主流 vs 反方 + 触发条件]

### 5. Domain Risks & Opportunities
- [风险 / 机会 / 二阶效应]

### Summary
[2-3 句:综合置信度 + 关键建议]
```

---

## ⚠️ 5 维度评估的 3 个常见错误

### 错误 1 · 维度折叠

把多个维度塞进一段话回答,读者看不出每维度独立结论。

**修法**: 每维度强制独立小标题 + 至少 2 句结论。

### 错误 2 · 假对抗

Contrarian 维度里写「虽然有人不同意,但其实没他们重要」之类的假反驳。

**修法**: 真正找一个可信反方 + 给出在什么条件下反方更对。

### 错误 3 · 风险空话

风险维度写「需要关注法律风险」(没具体到哪个法、哪条、什么处罚)。

**修法**: 风险必须可执行 — 具体到 [法律名] / [条款] / [后果] / [合规动作]。
