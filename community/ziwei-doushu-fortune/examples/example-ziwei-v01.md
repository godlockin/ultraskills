## 关键解读示例

### 角色卡

命宫紫微 = 董事长 / 老大 — 自己是"做决定的人",但需要秘书(天机)、财务(武曲)、人事(太阴)配合。

### 四化(乙年出生)

- 化禄 = 天机 → 秘书得利,你最容易收获在"信息/思考"
- 化权 = 天梁 → 大资本发话,投资人/长辈给你权力
- 化科 = 紫微 → 老大给面子,你最有面子的是"身份/地位"类事件
- 化忌 = 太阴 → 人事部乱套,**家庭关系 / 母亲关系 / 内部协调** 是你最大的代价

### 能量守恒推演

化禄(天机)+ 化忌(太阴)同组:信息越受益,内部协调越混乱。
**应用**:你以为"想清楚就能做",但内部人不配合——**有得必有失**。

### 立太极:夫妻宫立太极

假设夫妻宫主星为天府(虚构):
- 配偶的核心性格 = 天府 = 库星 / 老板星 → **配偶是有资源、稳重的人**
- 配偶的财务态度 = 夫妻宫立太极的第 2 宫 = 假设主星为武曲 → **财务讲究规矩**
- 配偶的家庭背景 = 夫妻宫立太极的第 4 宫 = 假设主星为太阴 → **配偶家庭重视教育**

### 大限三阶段

| 大限 | 年龄段 | 主题 |
|---|---|---|
| 第三大限(25-34 岁) | 学习期 | 紫微化禄,事业有贵人 |
| 第四大限(35-44 岁,当前) | 收成期 | 天梁化权,投资人给权,但要承担代价 |
| 第五大限(45-54 岁) | 传承期 | 紫微化科,名声响亮,但要承受太阴化忌的代价 |

> 原话(L2476-2482):第三、四、五大限是人生高光窗口。

### 流年(2026 丙午年)

- 流年命宫在午宫
- 流年四化:丙干 → 天同化禄 / 天机化权 / 文昌化科 / 廉贞化忌
- **重点看流年化忌在哪个宫** = 廉贞化忌 → **创意受限 / 火属性受克** — 今年不宜开创新项目

## 三件必做 / 三件不做

**必做**:
1. 利用流年天同化禄 → **多陪孩子 / 给员工福利**(小孩星)
2. 利用大限天梁化权 → **承接投资人给的项目**(资本方放权)
3. 利用能量守恒 → **主动付出家庭责任**(化忌在太阴,代价是家庭关系,主动付出而非被动应付)

**不做**:
1. 流年廉贞化忌 → **不开创新项目 / 不做火属性大的事**(创意受限)
2. 大限天梁化权但要承担 → **不接超出能力范围的权力**
3. 能量守恒提醒 → **不只想要"进账"不想"代价"**(化禄进账,化忌必伴随代价)
