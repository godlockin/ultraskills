## 🧠 核心理念 (Core Concepts)

### 1. 紫微斗数 = 三元素系统

> UP 主原话(L105-115):「这个术法本身只有三种东西,就是宫、星、化,这三个元素组成了我们正常看到的这张命盘。」

```
宫 = 房间(空间位置,12 个固定宫位)
星 = 住客(角色特性,14 颗主星各司其职)
化 = 剧情(天干能量变化,禄权科忌的能量守恒)
```

| 元素 | 比喻 | 本质 |
|---|---|---|
| **宫** | 公司有多少层楼 / 多少个部门 | 12 个固定宫位(命/兄弟/夫妻/子女/疾厄/财帛/官禄/田宅/交友/父母/迁移/福德) |
| **星** | 每个部门的主管 | 14 颗主星(紫微/天府/天机/太阴/贪狼/巨门/廉贞/天相/天梁/七杀/天同/武曲/太阳/破军) |
| **化** | 公司每年的氛围 / 老板心情 | 十组天干 × 化禄/化权/化科/化忌 = 40 种能量配置 |

### 5. 大限 + 流年 = 时空穿梭

> UP 主原话(L2490-2516):「大限的视角是具象化的,相当于鸟瞰图...这相当于我们有了穿梭时空的能力。你可以定格任意时间点,紫微斗数也是这样,都是无数个定格的画面组合在一起,形成我们现在看到的这张命盘。」

- **大限规则**:十年一格,共 12 个大限;阳男阴女顺转,阴男阳女逆转(L2443-2447)
- **流年规则**:所有人在同一流年的命宫位置相同(L173-185)
- **核心提示**:第三、四、五大限是高光时刻窗口(L2476-2482)

## 🚀 使用流程 (Workflow)

整个流程被组织为「**三元素定盘 → 立太极展开 → 四化引动 → 大限流年 → 输出**」五步。

### Step 1 · 三元素定盘(接受输入 → 输出三元素)

接受输入:
- 阳历(公历)生日 + 时辰 → 推算四柱,转紫微命盘(需专业排盘软件计算"几局")
- 农历生日 + 时辰 → 推算四柱,转紫微命盘
- 已排好的紫微命盘 → 直接使用

⚠️ **v0.1.0 局限**:**精确排盘需要专业软件**(几局/起运岁数/宫位排列);本 skill 假设用户已有命盘,或使用通胜万年历自行排盘。

### Step 2 · 看主星与宫位

- 找到命宫 → 看命宫主星 → 这是"我"的角色
- 顺时针看其他 11 宫 → 看各宫主星 → 这是"我和世界的关系"
- 重点看三方四正:**命宫 + 对宫 + 命宫左右各第四宫**(命/官/财/迁移)

### Step 3 · 起四化(看当年引动)

- 看出生年天干 → 查四化表 → 定下"原局四化"(基础格局)
- 看流年年干 → 查四化表 → 定下"流年四化"(当年能量)
- 关键原则:**有收获必有付出**(能量守恒)

### Step 4 · 立太极展开

- 命宫立太极 → 看基础人生格局
- 夫妻宫立太极 → 看配偶细节
- 官禄宫立太极 → 看事业发展
- 田宅宫立太极 → 看家产/风水
- 父母宫立太极 → 看父系家族

### Step 5 · 输出论命 + 误区自检

调用 `templates/ziwei-report.md` 模板输出。**v0.1.0 模板 13 段**,包含:
- 三元素总览
- 14 主星角色卡
- 12 宫位速览
- 四化能量配置
- 立太极展开(选 2-3 个最重要的太极)
- 大限节奏
- 流年关键节点
- 误区自检(紫微版)
