# bazi-fortune · 四柱八字排盘与命运分析

> 📚 **前置知识**:`daoist-cosmology-basics`(术语、天干地支、五行基线)
> 🎓 **来源**:荀太虚《面相八字手相全系统教学》+《滴天髓》讲解+《阴阳五行认知框架》视频转写(2026)

## 🎯 目标 (Goal)

从 8 字(年柱 + 月柱 + 日柱 + 时柱)推导命主:
- 性格倾向(十神 + 日主旺衰)
- 事业走向(官杀 + 食伤 + 用神)
- 财运高低(财星位置 + 大运流年触发)
- 姻缘配偶(用神互补 + 桃花星)
- 健康风险(五行缺位 → 对应脏腑)
- **当前季节节奏(顺势四问,看是否在错季做事)**
- **干支双层(天干外显 / 地支内核是否一致)**

## 🧠 核心理念 (Core Concepts)

### 1. 我和世界的关系 = 八字核心

> 视频原文:"古人是怎么理解我和世界的关系呢。用十神来总结,就是**财官印食比**。这个神不是神灵,而是我和世界的关系。更进一步总结就是**比、生、克**三种。"

| 关系 | 符号 | 具体含义 | 十神 |
|---|---|---|---|
| **同我** | 比 | 同辈、平等、对手 | **比肩**(同阴阳)、**劫财**(异阴阳) |
| **生我** | 印 | 父母、贵人、庇护 | **正印**(异阴阳)、**偏印**(同阴阳) |
| **我生** | 食伤 | 才艺、下属、表达、子女(女) | **食神**(同阴阳)、**伤官**(异阴阳) |
| **我克** | 财 | 财富、男配偶(男命)、妻 | **正财**(异阴阳)、**偏财**(同阴阳) |
| **克我** | 官杀 | 领导、法规、压力、子女(男) | **正官**(异阴阳)、**七杀/偏官**(同阴阳) |

> 关系在**八字原局 + 大运流年**中配合即可推论性格与事件。

### 2. 命运格局 = 56.16 万种模型

视频原文:"按照初一数学老师教的概率学知识,八字理论把人的命运分成了至少 **56.16 万**个模型。再加上男女大运走向不同,这个结果还要再乘以二,就有 **112.32 万**个模型。"

> 相比十二星座 / 十六型人格,**八字的样本空间大得多**。

### 3. 三种"我"的明确

- **日主 / 日干 / 日元**:出生那一天的天干(八字第六个字 — 上排正中)
- 这是"我"在八字中的"位"

### 4. 阴阳五行认知底座(来自《阴阳五行认知框架》)

- **五行是类象思维**:描述关系、状态、变化方向,不是五种物质或道德判断
- **十二长生是能量周期**:生/长/盛/衰/亡/再生循环,非线性;「绝」意味新生可能
- **八字是日主与环境关系的解释系统**:不能只看中间八个字
- **四柱三层类象**:时间阶段 + 重要关系/场域 + 身体部位
- **十神制化是关键**:把失衡风险转为可用能力,不贴道德标签

### 5. 能量守恒原则(2026-08-27 紫微视频反向增强)

> 来自荀太虚【零基础】传授紫微斗数(L2316-2323):「四化是天干的自然能量变化,是能量守恒的,有收获就一定 有付出。」

**核心命题**:八字论命同样遵守能量守恒——**有"得"必有"失",有"忌"必有"禄"**。

**应用场景**:
| 场景 | 能量守恒提醒 |
|---|---|
| 用神得力(印星当令) | 必有印克伤官(才华受压) |
| 财星透干(有进账) | 必有身弱扛不住(健康/精力透支) |
| 官杀有力(事业有成) | 必有官克身(压力巨大、官非) |
| 食伤生财(技术变现) | 必有食伤克官(职场关系紧张) |

> **避免陷阱**:不要追求"全得"格局——任何"得"的极端都伴随"失"的极端。**改命的本质是接受代价,选择代价最小的方向**。

## 🚀 使用流程 (Workflow)

整个流程被重新组织为「**四柱同参 → 用神动态 → 大运顺势 → 干支双层 → 误区自检 → 输出**」六步,旧版拆分的"再用 12 个资源文件"统一收敛在这里。

### Step 1 · 排盘(接受输入 → 输出四柱)

接受输入:
- 阳历(公历)生日 + 时辰 → 推算四柱
- 农历生日 + 时辰 → 直接对应天干地支
- 4 对天干地支字符 → 直接使用

输出 4×2 网格,同时**直接区分天干/地支**:

```
[年柱]   [月柱]   [日柱]   [时柱]
年干    月干    日干 ← "我"   时干    ← 上排(天干) 外显:名气、官位、冲突
年支    月支    日支    时支    ← 下排(地支) 内在:真实性格、财富
```

- 天干:柱外在,易被他人看到(外貌、言行、事业、名声)
- 地支:柱内在,不易被发现(性格、心思、家庭、根基、欲望)
- 财在天干 = 衣锦还乡;财在地支 = 留得住

### Step 2 · 定日主 + 起十神

- 找到第六个字(日干)→ 这是"我"
- 其他七字按"与日主阴阳五行关系"分类到十神
- 用神不是算出来的标签,是要找的「让全局平衡流通」的五行

### Step 3 · 五行强弱 + 用神(三层动态)

数四柱五行频次 + 月令旺衰权重 → 找最旺/最弱五行。

**最旺 = 天赋所在;最弱 = 短板所在**(用于 Step 5 干支双层之后的「识人/择业」):

| 五行最旺 | 天赋倾向 | 适配行业 | 短板提醒 |
|---|---|---|---|
| 木 | 创意、写作、演讲、教育、设计 | 文化、教育、媒体、设计、互联网 | 容易三分热度,做事不踏实 |
| 火 | 领导、管理、销售、公关、表演 | 餐饮、娱乐、能源、教育、管理 | 容易冲动,感情用事 |
| 土 | 管理、财务、行政、后勤、服务 | 房地产、建筑、金融、行政 | 容易死板,墨守成规 |
| 金 | 技术、科研、法律、金融、医疗 | 金融、法律、医疗、科技、制造 | 容易保守,缺乏创意 |
| 水 | 策划、营销、贸易、物流、旅游 | 贸易、物流、旅游、金融、策划 | 容易拖延,缺乏行动力 |

> 用神不是"补某一行"的标签,而是「让全局平衡流通」的五行——可能是泄、可能是制,要看当前格局。

**核心:用神是动态的,不是锁定的终身标签**。要回答三层:

| 层级 | 内容 | 何时参考 |
|---|---|---|
| **原局用神** | 让原局五行平衡流通的五行 | 长期人格底色 |
| **大运用神** | 当前十年大运下,需要补或泄的五行 | 整个大运期间(十年) |
| **流年用神** | 当年流年引动后的实际用神 | 当年事件 |

> 走水运时水已经很旺,原局"补木"在大运期间实际要"泄水",流年再来丙火则用神又变。**用神永远要回答"在当前时点"**。

### Step 4 · 看大运(顺势法则)

十年大运类比为四季,**核心不是"流年吉凶",而是"当前是否在顺季节做事"**。

| 大运季节 | 行动建议 | 典型风险 |
|---|---|---|
| 生运(春) | 播种期:多学习、多积累、多尝试、多交朋友 | 急于赚钱、急于求成 |
| 旺运(夏) | 生长期:大胆去闯、抓机会、扩事业 | 贪图享乐、放纵过度 |
| 衰运(秋) | 收获期:把成果变现、落袋为安 | 盲目扩张、盲目投资 |
| 死运(冬) | 储藏期:低调内敛、养精蓄锐、学习提升 | 强行折腾、创业、跳槽 |

> 顺则吉,逆则凶。**改运的核心不是改名/风水,而是改行为去顺应当前季节**。
>
> 男阳女阴顺排,男阴女阳逆排;九子离火大运 (2024-2043) "外实内虚",社会现象需警惕。

### Step 5 · 干支双层(看人也看自己)

解盘必须**干支同参**,单看天干 = 只看面具。

| 维度 | 天干 | 地支 |
|---|---|---|
| 可见性 | 外显、易被他人看到 | 内在、不易被发现 |
| 对应 | 外貌、言行、事业、名声、第一印象 | 性格、心思、家庭、根基、欲望恐惧 |

典型反例:
- 天干甲木刚正 + 地支有金 → 外在阳刚只是外壳,内心脆弱敏感
- 天干丙火热情 + 地支子水 → 外在开朗只是面具,内心孤独冷漠

### Step 6 · 输出论命 + 误区自检

调用 `templates/bazi-report.md` 模板输出。新版模板固定包含:

```
## 顺势四问
- 当前大运季节: {春/夏/秋/冬}
- 五行最旺/最弱: {天赋} / {短板}
- 用神动态: 原局 X → 当前大运 Y → 流年 Z
- 顺/逆季节: {顺/逆}

## 干支双层
- 天干外显: {特质}
- 地支内在: {真相}

## 误区自检(必须全通过)
- 宿命论 → 已避免(强调"运由人作")
- 死格局 → 已避免(整局综合,不是单格局定论)
- 神煞万能 → 已避免(神煞仅作辅参)
- 用神唯一 → 已避免(三层动态)
- 外求改命 → 已避免(改心 > 改姓/风水/物)
```

## 🛡 模板生成永久约束(来自用户洞察 + 营销 review,2026-08-27)

> 这 6 条 review 后的固化约束,**作为所有八字/命理类 skill 的通用输出约定**;其他玄学 skill 可借鉴。

### 约束 1:首屏必有钩子

**问题**:模板第一节是排盘表格,普通用户 3 秒看不到"哇",直接劝退。
**解法**:
- lite 版:第 0 段「30 秒导读」——基于命局 + 当前大运,用 1 句大白话回答"你是谁 + 今年该做什么"
- pro 版:第 0 段「三方专家快读卡」——心理学家/职业规划师/中医师各 3 行摘要,先给 9 行可立刻用的判断

**范例(lite)**:
> 一句话定论:"你是个想得多做得慢的人,木旺水弱,天生的研究/顾问底子。"
> 今年最关键的一事:"把手上的方法论收成可复用资产,别再开新坑。"

**范例(pro)**:
> 👨‍⚕️ 心理学家:性格画像 + 依恋类型 + 亲密关系核心议题(各 1 行)
> 💼 职业规划师:短/中/长期方向(各 1 行)
> 🌿 中医师:体质类型 + 日常调养 + 节气养生(各 1 行)

### 约束 2:金句卡必填

**问题**:满篇表格 + 列表,**没有可截图的金句**,用户不会主动分享。
**解法**:干支双层段末追加 `> 📌` 引用块,1 句可截图金句(≤ 30 字)。
**范例**:
> 📌 金句卡:"外表柔软,内心排山倒海——你才是那个默默做事的人。"

**金句要求**:
- 必须基于实际命局结构,**不空泛**
- 必须"懂我"——比用户对自己还理解
- 必须可独立分享——脱离上下文也成立

### 约束 3:末尾升级预览(付费触发器)

**问题**:lite 用户读完觉得"够了",pro 付费动力不足。
**解法**:lite 末尾展示 pro 才有的 3 件宝(多跳分析 / 风险矩阵 / 三方附议)的**真实片段**,让用户尝到 pro 才有的甜头。
**反模式**:**只显示"行数更多"** → 用户会觉得"更长就是更多废话",不付费。
**正模式**:让用户看到 lite **没挖出的关键洞察**(如"婚姻宫连续暗损"这种 lite 看不到的风险)。

### 约束 4:emoji 替编号

**问题**:① ② ③ ④ 对非专家用户无感知区分。
**解法**:
- 🔥 强信号(机会)
- 🌱 高潜力(机会)
- ⚠️ 高危(风险)
- ❄️ 假信号(风险)

### 约束 5:行动前置

**问题**:三件必做 / 三件不做 / 修心一句话是客户最该看到的,但被压在第 11/20 段。
**解法**:行动钩子的**压缩版本**前移到第 0 段首屏;**完整版本**保留在末尾作为"详细执行清单"。

### 约束 6:真实 vs 虚构边界

**问题**:真实案例落入 examples/ 会泄露用户隐私。
**解法**:
- examples/ 下**一律虚构**
- 真实案例必须脱敏(改名 / 改时间 / 改地点)后**标注 `[脱敏]` 后缀**
- 高敏字段(真太阳时、出生地)即便虚构也不必完全真实——**保留结构,弱化数字**

### 跨 skill 适用清单

> 这 6 条约束**不仅适用于八字**,同样适用于:
> - 面相(`face-reading`)— 首屏钩子可改为"你脸上的第一特征 / 别人怎么看你"
> - 手相(`palm-reading`)— 首屏钩子可改为"你的手掌主线 / 你的'运气开关'"
> - 风水(`feng-shui`)— 首屏钩子可改为"你家户型第一眼 / 哪里最该改"
> - 其他玄学/命理类 skill 输出报告模板

**通用原则**:**首屏给结论,后段给论据**——用户没有耐心读完 500 行才看到答案。
