# bazi-fortune · 四柱八字排盘与命运分析

> 📚 **前置知识**:`daoist-cosmology-basics`(术语、天干地支、五行基线)
> 🎓 **来源**:荀太虚《面相八字手相全系统教学》视频转写(2026)

## 🎯 目标 (Goal)

从 8 字(年柱 + 月柱 + 日柱 + 时柱)推导命主:
- 性格倾向(十神 + 日主旺衰)
- 事业走向(官杀 + 食伤 + 用神)
- 财运高低(财星位置 + 大运流年触发)
- 姻缘配偶(用神互补 + 桃花星)
- 健康风险(五行缺位 → 对应脏腑)

## 🧠 核心理念 (Core Concepts)

### 1. 我和世界的关系 = 八字核心

> 视频原文:"古人是怎么理解我和世界的关系呢。用十神来总结,就是**财官印食比**。这个神不是神灵,而是我和世界的关系。更进一步总结就是**比、生、克**三种。"

| 关系 | 符号 | 具体含义 | 十神 |
|---|---|---|---|
| **同我** | 比 | 同辈、平等、对手 | **比肩**(同阴阳)、**劫财**(异阴阳) |
| **生我** | 印 | 父母、贵人、庇护 | **正印**(异阴阳)、**偏印**(同阴阳) |
| **我生** | 食伤 | 才艺、下属、表达、子女(女) | **食神**(同阴阳)、**伤官**(异阴阳) |
| **我克** | 财 | 财富、男配偶(男命)、妻 | **正财**(异阴阳)、**偏财**(同阴阳) |
| **克我** | 官杀 | 领导、法规、压力、子女(男) | **正官**(异阴阳)、**七杀/偏官**(同阴阳) |

> 关系在**八字原局 + 大运流年**中配合即可推论性格与事件。

### 2. 命运格局 = 56.16 万种模型

视频原文:"按照初一数学老师教的概率学知识,八字理论把人的命运分成了至少 **56.16 万**个模型。再加上男女大运走向不同,这个结果还要再乘以二,就有 **112.32 万**个模型。"

> 相比十二星座 / 十六型人格,**八字的样本空间大得多**。

### 3. 三种"我"的明确

- **日主 / 日干 / 日元**:出生那一天的天干(八字第六个字 — 上排正中)
- 这是"我"在八字中的"位"

### 4. 八字的物理构成

四根竖向字柱:

```
[年柱]  [月柱]  [日柱]  [时柱]
年干   月干    日干    时干   ← 上排(天干) 外显:名气、官位、冲突
年支   月支    日支    时支   ← 下排(地支) 内在:真实性格、财富
```

- **天干**:柱外在,易被他人看到(名气、官位、冲突)
- **地支**:柱内在,不易被发现(真实性格、留得住的财)
- **财在地支** = 留得住(类似"闷声发大财")
- **财在天干** = 衣锦还乡、人尽皆知

### 5. 排盘操作

接受输入:
- 阳历(公历)生日 + 时辰 → 推算四柱
- 农历生日 + 时辰 → 直接对应天干地支
- 4 对天干地支字符 → 直接使用

输出 4×2 网格:
```
年柱:戊子
月柱:甲寅
日柱:壬午  ← 日主
时柱:庚戌
```

### 6. 大运流年

- **大运**:每 10 年一轮,男阳女阴顺排,男阴女阳逆排
- **流年**:逐年触发(60 甲子一轮)
- **九子离火大运** (2024-2043): 视频特别提醒"外实内虚",社会现象需警惕
- 视频示例:戊寅运 + 急卯运 → 命主性格、清高、上进、好强、学业运旺但压力大

## 🚀 使用流程 (Workflow)

### Step 1: 排盘
接受 8 字或生辰 → 排出四柱

### Step 2: 定日主
找到第六个字(年干月干**日干**时干) → "我"

### Step 3: 起十神
其他七字按"与日主阴阳五行关系"分类到十神

### Step 4: 看五行强弱 + 用神
数四柱五行出现频次 + 月令旺衰权重 → 找最弱五行 → 用神

> 用神示例(视频案例):
> - 日主受克(原局**庚克时干**已) — 需补
> - 卯运来了 → 卯木比肩(同类) = 通关用神
> - 结论:清高好强、上进、学业有利、压力大、注意健康 + 平辈人际关系带来机遇

### Step 5: 看大运 + 流年
按十神在原局中的关系,推断当前/未来 10 年/逐年触发的事件倾向

### Step 6: 输出论命报告
调用 `templates/bazi-report.md` 模板,填入性格 / 事业 / 财运 / 姻缘 / 健康 / 大运关键节点
