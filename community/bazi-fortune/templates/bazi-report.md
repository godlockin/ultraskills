# 八字 · 论命报告模板(主模板 v2.0)

> 用于"用户没说具体要 lite 还是 pro,默认输出"的中档交付。
> **目标 180-220 行**——介于 lite(150)和 pro(200-300)之间。
> 当用户输入模糊("看看"、"给我算算"、"大概说说")时,默认走主模板。
> 升级到 pro 触发词:`pro` / `完整版` / `详细版` / `付费版` / `深度咨询` / `我要全部`
> 降级到 lite 触发词:`lite` / `简单版` / `免费版` / `短一点`

## 主模板 v2.0 生成规则

### 必填段(10 段 + 附录)

| 段 | 关键产出 | 行数下限 |
|---|---|---|
| 0 30 秒导读 | 首屏金句 + 3 条 + 金句卡 + 一句话 | 10 |
| 一 命盘 + 命眼 | 排盘 + 命眼 1 段 | 10 |
| 二 十神/五行/用神 | 1 表 + 1 段 | 8 |
| 三 顺势五问 + 暗箭 | 5 问 + 暗箭表 + 引动年 | 12 |
| 四 6 视角性格 | 6 行表 + 1 段收束 | 12 |
| 五 事业 | 节奏表 + 2 原则 + 紫微 | 18 |
| 六 财运 | 1 段 + 1 表 + 紫微 | 10 |
| 七 姻缘 | 年龄判断 + 议题 + 紫微 | 12 |
| 八 健康 | 1 表 + 3 时间窗 + 3 动作 | 16 |
| 九 行动 | 2 必做 + 1 不做 + 修心 | 8 |
| 附 关键日 | 本月 + 下月 + 重点提醒 | 8 |
| **总计** | | **180-220** |

### 主模板 vs lite vs pro 差异

| 维度 | lite | **主模板** | pro |
|---|---|---|---|
| 行数 | 150 | **180-220** | 200-300 |
| 段数 | 11 | **10+附录** | 11+附录 |
| 性格视角 | 5 视角 | **6 视角(含紫微)** | 6 视角 |
| 紫微融入 | 无 | **3 处(事业/财运/姻缘)** | 3 处 |
| 行动清单 | 无 | **2 必做 + 1 不做方向**(精简版)| 3 必做 + 1 不做 + 修心(详细)|
| 流月 | 无 | **无,只附本月 + 下月关键日** | 附本月 + 下月 + 流月 |
| 关键日细节 | 无 | **每月 1 个** | 每月 3 个 |

### 输出硬约束

1. **首屏金句与标题同源**
2. **不允许任何大白话段落标识符**(0 处元废话)
3. **紫微 3 处融入都用"八字看不到 X,紫微给 Y"句式**
4. **行动只给"方向",不列清单**——主模板的定位是"中档交付",**不让用户觉得"够用了",但比 lite 多给关键信息**
5. **关键日每月 1 个**(本月 + 下月共 2 个)— 比 pro 少 1/3
6. **整份报告必须包含 3 句金句**(首屏/章节/修心)

| 默认 / 模糊 | **主模板**(本文件) |
| "看看大概" / "几分钟" / "简单" | lite |
| "详细" / "完整" / "付费" | pro |
| "中档" / "标准" | 主模板 |
