# 用神 — 确定与平衡

> 来源:荀太虚视频 + 经典八字学

## 什么叫"用神"

视频原文(案例):"卯木可以说是地支的**通关用神**。"

> 用神 = 命局中**最需要的补益 / 平衡**的那个五行。

## 三种用神法

### 1. 通关用神
当两种五行相克时,中间加一种使关系变成"连续相生":
- 金克木 → 用 **水**(金生水、水生木)
- 火克金 → 用 **土**(火生土、土生金)
- 木克土 → 用 **火**(木生火、火生土)
- 水克火 → 用 **木**(水生木、木生火)
- 土克水 → 用 **金**(土生金、金生水)

### 2. 比助用神
当五行弱极(无根无生),用同类**帮身**:
- 水弱 → 甲乙木生水(印) 或 壬癸水比肩帮身

### 3. 调候用神
特殊格局的调节,需结合月令(出生月地支的旺衰)看:
- 夏天生人太热 → 用水调候
- 冬天生人太寒 → 用火调候

## 用神判定步骤

1. **排盘** → 找日主五行
2. **数五行**:统计所有 8 字各五行(天干 + 地支藏干)
3. **看月令**:月支的旺衰权重最高
4. **失衡识别**:
   - 弱:找**比助/印**为用神
   - 强:找**克/泄/耗**为用神
   - 受克过重:找**通关**为用神
5. **喜神/忌神**:
   - 用神相同五行 = 喜神(锦上添花)
   - 用神相克的五行 = 忌神(减损)
