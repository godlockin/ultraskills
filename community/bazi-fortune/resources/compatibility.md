# 合婚 — 八字配对

> 来源:荀太虚视频未深入合婚专题,以下为经典八字合婚原则 + 视频原则

## 视频对"何时谈合婚"的提醒

视频原文:"不要说我今天去相亲,我就先看看他的手相好不好,看看是不是能带来财运之类的。**这是不礼貌的**。先相处一段时间再观察。"

> **态度上**:不要在初识/相亲阶段就去看对方手相/八字。这既有**礼貌问题**,也容易**因小失大**(错过真心对你好的)。

## 经典合婚原则

### 1. 年支生肖
- **三合**(申子辰、亥卯未、寅午戌、巳酉丑):最合
- **六合**(子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合):次合
- **六冲**(子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲):慎选
- **三刑**(子卯刑、寅巳申刑、丑戌未刑、辰午酉亥自刑):慎选

### 2. 用神互补
两个人**八字用神互补**,形成系统性平衡:
- 一方喜金,另一方忌金 → 相处间互相调节
- 一方缺木,另一方多木 → 互相补

### 3. 日主关系
- **日干合**(甲己合、乙庚合、丙辛合、丁壬合、戊癸合):有缘
- **日支关系**:与年支同上述合冲刑

### 4. 八字格局类型
- 食神格 vs 伤官格:多口舌
- 正印格 vs 偏印格:理解差异大
- 大运同步性:同样时期走好运 → 相处顺

## 操作流程

1. 双方分别排出四柱
2. 检查:年支关系 → 用神互补 → 日干关系 → 大运同步
3. **不重绝对结论**,重"趋势"
4. 给**建议**而非"判决"

## 视频隐含态度

> "手相学的知识点很多。中国拥有 14 亿人口,这意味着有 28 亿只不同的手纹。" — 暗示**多样性无穷无尽**,不要给绝对结论。

合婚同理:**没有 100% 合 / 不合**,只在"相对倾向"。
