# 配偶星 + 夫妻宫 — 视频原文精读

> 来源:荀太虚《【零基础】八字中的婚姻_桃花_感情_夫妻_离婚_合婚_正缘》视频转写(2026-05-12)

## 视频核心口诀

视频原文:"看感情、看婚姻,**第一个,一看心,二看公,三看强弱与极凶**。"

1. **看心**(配偶星)
2. **看宫**(夫妻宫 = 日支)
3. **看强弱与极凶**

## 一、配偶星(夫妻星)

### 视频明示性别星

- **男命**:
  - **正财** = 妻(正室)
  - **偏财** = 妾、情人、小三小四
  - 若**八字无正财**,则偏财就是妻
- **女命**:
  - **正官** = 老公(古代称"官人")
  - **七杀(偏官)** = 情人
  - 若**八字无正官**,则七杀就是老公

### 配偶星多的含义

视频原文:"有好几个正官、七杀,那么我们这个一般就叫做**官杀混杂**。代表命主的男性缘/异性缘是比较好的。一般来说,夫妻星多的情感一般都是不缺的,或者说有好几段感情。那么没有夫妻星的情感,一般会差一些。"

| 配偶星状态 | 含义 |
|---|---|
| **多**(官杀混杂 or 偏财多)| 异性缘好,感情多段 |
| **少 / 缺** | 情感少、来得慢 |
| **缺一星,以异性星替补** | 不一定,看具体盘 |

### 配偶星位置

配偶星可以落在 4 柱 8 字任一位置 — 视频未严格说"必须年月 vs 日时",但**日支(夫妻宫)里看到配偶星最佳**(见下)。

## 二、夫妻宫(日支)

### 视频原文

> "八字之中是分不同宫位的,比如父母、兄弟、夫妻、子女等等。那么夫妻宫在哪里?**在日支地支的位置**。年/月/日/时四柱,日柱代表自己,在自己底下的就是自己的另外一半,所以这是夫妻宫。"

### 夫妻宫里的十神(视频例子)

| 夫妻宫里的十神 | 含义 |
|---|---|
| **正财 / 偏财**(男)| 心宫同位 → **感情顺利、夫妻恩爱** |
| **正印 / 偏印**(男)| 印在双亲关系 = 母亲 → **婆媳矛盾概率**(看喜忌)|
| **食神 / 伤官** | 食伤生财 → 疼老婆、爱老婆、为老婆付出 |
| **食神 vs 伤官 差别** | 食神:温和、百依百顺、讲道理;**伤官:刀子嘴豆腐心**,嘴爱抱怨但实际很疼 |
| **官杀**(对女命而言)| 妻管严,一家之主母老虎;官杀为忌时尤其 |
| **比肩 / 劫财** | **不太好** — 男大男子主义、脾气差,甚有家暴倾向 |
| **女命做官杀** | 心宫同位 + 有点望夫之意;但**最好官杀只出现一位**,否则流年大运容易官杀混杂(老公情人打架)|
| **女命做食伤** | 食伤克官杀 → 爱念叨自己男朋友 |
| **女命做比劫** | 容易女强男弱、大女子主义 |
| **女命做印** | 官印相生 → 老公对自己好,获得老公帮助 |

### 喜忌概念

视频提示:"具体的表现还要看整个八字的喜忌。但本质是一样的,有的会表现出来,有的则不会表现出来。"

- **喜**(用神):十神所主的事物被命局需要 → 得吉
- **忌**(忌神):十神所主的事物不被需要 → 失衡暴露

## 三、结合"心"+"宫"判读流年

视频原文:"什么时候是婚灾的应期呢?就是在流年大运,碰到有相同的字去激活他的时候。"

例:
> 男命夫妻宫有财,但原局中卯戌相冲。卯冲了夫妻宫里的财。
> 去年(癸卯年)卯被激活 → 卯 = 偏财 = 妾 = 情人,冲到夫妻宫 → **鸠占鹊巢** → 婚姻被冲,小三找上门。

## 四、视频"和冲"速查

视频原文:"和者欲冲,冲者欲和"

- **原局夫妻宫有合的** → 遇流年大运被冲时 → **应婚期**
- **原局夫妻宫有冲的** → 遇流年大运被合走时 → **应婚期**

例:
> 夫妻宫戌被合(卯戌合),2023 癸卯年来冲 → 应婚期。

## 实操提示

1. **必问用户性别** — 否则配偶星判定失方向
2. **排盘后** 看 4 柱 8 字里正财 vs 偏财(男)、正官 vs 七杀(女)的数量
3. **看日支** 看夫妻宫里十神,再与喜忌对比
4. **流年匹配** 看是否激活冲/合
5. **综合三方**:心 / 宫 / 流年触发
