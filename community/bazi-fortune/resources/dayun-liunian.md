# 大运流年 — 时间维度

> 来源:荀太虚视频(九子离火大运专讲)+ 经典大运推算法

## 大运基础

每 10 年一轮,**男阳女阴顺排,男阴女阳逆排**:
- 阳年(年干甲丙戊庚壬)男命 + 阴年女命 → 顺行大运
- 阴年男命 + 阳年女命 → 逆行大运

> 起运时:顺行看出生后第一个节气到出生时差;逆行看出生时到前一个节气差。

## 视频强调的"九子离火大运"(2024-2043)

视频原文:"现在正值**九子离火大运**。离火主宰的时代里,表面的光鲜亮丽,可能掩盖了内在的空虚或不足。在这种外显的繁华背后,可能隐藏着各种陷阱和欺骗。因为离火的内在属性是**外实内虚**,社会上可能出现更多表面光鲜,实则虚假的现象。**小人得志,表面的光彩掩盖了真实的阴暗**,这些都是我们需要警惕的。"

### 九紫离火运特征速记

| 现象 | 性质 |
|---|---|
| 光鲜亮丽 | 外显 |
| 内在空虚 | 实相 |
| 骗局骗局增加 | 客观 |
| 小人得志 | 趋势 |
| 表光彩掩盖黑暗 | 警示 |

> ⚠️ **任何关于社会层"大运"的描述都是趋势论,不是宿命论。** 个人决策仍基于事实。

## 流年

- 每年一运,60 甲子轮回(天干 10 × 地支 12 - 4 重叠 = 60)
- 与原局 + 大运共同作用,触发特定十神关系

## 用神(通关神)

- 当日主受克(官杀太重),需"通关"五行解救
- 例:**金克木** → **水通关**(金生水、水生木)
- 也可"比肩同类"作为部分缓解

## 视频原例:戊寅运 / 急卯运案例分析

```text
日主:壬水(命主)
原局:庚金七杀克身(压力大、上进受阻)
大运 1:戊寅运
  - 戊土在天干 = 偏财(我克)
  - 寅木在地支,藏甲丙戊 → 甲木食神(我生)
  → 命主财运开始上升,但土克水的官杀加深
  → 学业/事业冲突明显
大运 2:急卯运
  - 卯木比肩(同我同类)
  - 缓解原局金克水的官杀问题
  - 通关用神 → 卯木站位
  → 命主:清高、好强、上进、学业运好
  → 但压力大,需加强身体锻炼
  → 平辈人际(同窗、朋友、伴侣初识)带来机遇
```

## 推算与解读流程

1. 用户给出生辰 → 排出四柱
2. 定日主 + 看原局强弱
3. 找喜用神(通关 / 比助)
4. 起大运 → 看未来 10 年倾向
5. 流年入宫 → 看逐年触发
6. 综合 → 输出"建议关注"+"建议警惕"两类

## 注意

- 大运是大方向,**不是命运决定**;社会与个人努力仍起作用
- 同一大运,流年不同 → 吉凶侧重不同
- "参考"语气永远优先,不要"预测"语气
