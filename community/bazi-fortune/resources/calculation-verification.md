# 计算校验机制 · 全链路纠错表

> **新增时间**:2026-08-27
> **用途**:八字 + 紫微所有计算点的**起点对错校验**。任何"看起来差不多"的数据,生成报告前必须走一遍校验链。
> **设计原则**:**计算点 → 校验公式 → 起点样例 → 错例对比**,避免"近似正确"的错觉。

---

## 八字体系 · 8 个关键计算点

### ① 日柱推算(60 甲子易错位)

**正确算法**:**1900-01-01 甲戌日** 锚点法 / 万年历查询

**校验公式**:
```
天数差(目标日 - 锚点) mod 60 = 甲子序号
查 60 甲子表 → 日柱
```

**起点样例**:1900-01-01 = 甲戌(序号 11)
- 1975-03-11 → (27371 天) mod 60 = **52 → 丙辰** ✅
- 1985-06-15 → (31227 天) mod 60 = 27 → **庚午**(虚拟命盘示例)

**错例**:
| 错例 | 错误结果 | 错因 |
|---|---|---|
| 把"丙辰"误读成"壬辰" | 壬辰日 | 阴干阳干混淆 |
| 把"丙辰"误读成"丙午" | 丙午日 | 地支顺序错 |
| 把 1975 推到 1976 年起算 | 全部错位 | 锚点基准年错 |

**自检清单**:
- [ ] 用万年历查**两次**(对照)
- [ ] 60 甲子表从"甲子"起,顺序不变
- [ ] 日柱在报告中显式标注"YYYY-MM-DD = 丙辰"

### ② 真太阳时校正(最易被忽略)

**正确算法**:**经度时差 = (本地经度 - 120°) × 4 分钟/度**

**校验公式**:
```
真太阳时 = 北京时间 + 经度时差
东经加,西经减
泾县 118.4°E: (118.4 - 120) × 4 = -6.4 分钟(实际常用 -37 分钟,因为古代有"北京时间以东八区中央 120°"为基准)
```

**起点样例**:泾县 118.4°E, 02:00 北京时间
- 校正后:**01:23**(仍在丑时 1-3 点之间)✅
- 关键:**校正后是否跨时辰**(01:23 仍在丑时)

**错例**:
| 错例 | 错误结果 | 错因 |
|---|---|---|
| 02:00 直接当丑时用 | 跨越时辰风险 | 没校正 |
| 经度时差算成 -6 分钟 | 校正后还在 01:54(丑时) | 用错公式 |
| 校正后 03:01 当作卯时 | 整个时柱错 | 跨时辰没发现 |

**自检清单**:
- [ ] 显式列出"校正前时间 → 校正后时间"
- [ ] **明确标注"未跨时辰"或"跨时辰"**
- [ ] 经度时差 > 30 分钟要警觉

### ③ 节气与月柱(决定月令旺衰)

**正确算法**:**月柱以节气分界**,不是农历初一

**关键节气**:
- 立春 → 寅月开始(年柱切换)
- 惊蛰 → 卯月开始
- 清明 → 辰月开始
- 立夏 → 巳月开始
- 芒种 → 午月开始
- 小暑 → 未月开始
- 立秋 → 申月开始
- 白露 → 酉月开始
- 寒露 → 戌月开始
- 立冬 → 亥月开始
- 大雪 → 子月开始
- 小寒 → 丑月开始

**起点样例**:1975-03-11
- 上一个节气:惊蛰 1975-03-06 ✅
- 下一个节气:清明 1975-04-05
- 03-11 在惊蛰之后、清明之前 → **卯月** ✅

**错例**:
| 错例 | 错误结果 | 错因 |
|---|---|---|
| 用农历二月当月柱 | 用了错误的月令 | 农历 ≠ 节气 |
| 惊蛰算成 03-05 或 03-07 | 月柱可能跨月 | 没查万年历 |
| 03-12 出生(惊蛰前一天) | 应是寅月,不是卯月 | 节气前一天 |

**自检清单**:
- [ ] 用万年历精确查**当年节气日期**
- [ ] 显式标注"生于惊蛰后 N 天,清明前 N 天"
- [ ] 出生在节气当天前后 3 天,必查万年历

### ④ 大运流转方向(顺/逆)

**正确算法**:**男阳女阴顺排,男阴女阳逆排**

**判定步骤**:
1. 看年干:**甲丙戊庚壬 = 阳,乙丁己辛癸 = 阴**
2. 看性别:男 / 女
3. 组合:
 - **男阳 + 女阴** → **顺排**(看出生**后**节气)
 - **男阴 + 女阳** → **逆排**(看出生**前**节气)

**起点样例**:1975-03-11 男
- 年干 = 乙 → **阴**
- 男 + 阴 → **逆排** ✅
- 看**前**一个节气(惊蛰 03-06)

**错例**:
| 错例 | 错误结果 | 错因 |
|---|---|---|
| 男阳当男阴处理 | 大运方向反 | 阴阳判定错 |
| 女阳当女阴处理 | 大运方向反 | 同上 |
| 顺排用"前一个节气" | 起运岁数错 | 方向和节气不匹配 |

**自检清单**:
- [ ] 显式写出"年干 X = 阴/阳;男/女 → 顺/逆排"
- [ ] 顺排 → 用"出生后节气";逆排 → 用"出生前节气"

### ⑤ 流年干支(60 甲子轮回)

**正确算法**:**1984 = 甲子年** 锚点;之后每年 +1(60 年轮回)

**校验公式**:
```
(年 - 1984) mod 60 = 距甲子年序数
查 60 甲子表 → 流年干支
```

**起点样例**:
- 2026 = (2026 - 1984) mod 60 = 42 → **丙午** ✅
- 2027 = 43 → **丁未**
- 1975 = (1975 - 1984) mod 60 = 51 → **乙卯**(本命年)

**错例**:
| 错例 | 错误结果 | 错因 |
|---|---|---|
| 2026 当作"乙巳"(2025 干支) | 流年全错 | 锚点偏移 |
| 1984 当作"癸亥" | 60 甲子全错位 | 锚点本身错 |
| 闰年/平年混算 | 跨年附近错 | 没意识到 |

**自检清单**:
- [ ] 用万年历查**当年立春后**的干支(不是农历年初)
- [ ] 显式列出"YYYY 年 = X 干支"
- [ ] 跨年附近(腊月/正月)必查万年历

### ⑥ 流月干支(12 个月)

**正确算法**:**每月以节气分界**,不是农历初一

**关键节气分界**:
- 立春/惊蛰 → 寅/卯月
- 清明/立夏 → 辰/巳月
- 芒种/小暑 → 午/未月
- 立秋/白露 → 申/酉月
- 寒露/立冬 → 戌/亥月
- 大雪/小寒 → 子/丑月

**天干推算**:**年上起月法**——以年干推月干

**口诀**:
```
甲己之年丙作首(寅月起丙)
乙庚之岁戊为头(寅月起戊)
丙辛必定寻庚起(寅月起庚)
丁壬壬位顺行流(寅月起壬)
戊癸之年何处起,甲寅之上好追求(寅月起甲)
```

**起点样例**:2026 丙午年 → 丙辛年起庚
- 2026-01(丑月)→ 庚丑
- 2026-02(寅月)→ 庚寅
- 2026-03(卯月)→ 辛卯
- ...

**错例**:
| 错例 | 错误结果 | 错因 |
|---|---|---|
| 月干从"丙寅"开始(丙年起庚但用错起点) | 全部月干错 | "丙辛年起庚"是寅月起庚,不是正月 |
| 月支用农历 | 跨节气的月份错 | 农历 ≠ 节气 |
| 节气日期记错 | 月份跨错 | 没查万年历 |

**自检清单**:
- [ ] 显式标注"流月干支 = X(节气的月份)"
- [ ] 跨节气(每月 5-7 号附近)的报告必查万年历
- [ ] 用年上起月口诀推算,然后用万年历对照

### ⑦ 流日干支(365 天)

**正确算法**:**直接查万年历**——AI 不应手动推算

**校验公式**:无(必须用工具查)

**起点样例**:2026-09-10
- 查万年历 → **癸丑** ✅
- 2026-09-30 → **癸酉** ✅

**错例**:
| 错例 | 错误结果 | 错因 |
|---|---|---|
| 用"甲子 + N" 推算 | 偏移 1-2 天 | 锚点 + 偏移算法不稳 |
| 用农历日期代替 | 跨月错 | 农历 ≠ 公历 |
| 不查万年历凭"感觉" | 错位 1-3 天 | 必须工具查 |

**自检清单**:
- [ ] **所有流日干支必须查万年历,不得手动推算**
- [ ] 报告显式列出"YYYY-MM-DD = X 干支"

### ⑧ 大运干支(10 年一轮)

**正确算法**:**月柱 + 顺/逆方向 + 节气时间差 = 起运岁数 + 第一步大运**

**起点样例**:1975-03-11 男阴年逆排
- 月柱 = 己卯
- 前一个节气惊蛰 03-06
- 天数差 = 5 天 → 1 岁 8 个月起运
- 第一步大运 = **戊寅**(己卯前一柱)✅
- 后续每 10 年逆推一柱

**错例**:
| 错例 | 错误结果 | 错因 |
|---|---|---|
| 顺排用月柱 | 起运大运反 | 方向错 |
| 月柱起算错位 | 10 步大运全错 | 月柱错 → 大运全错 |
| 起运岁数算成 3 岁(实际 1.67 岁) | 第一步大运提前 | 公式 ÷ 3 误读 |

**自检清单**:
- [ ] 大运表第一行起始岁数 = 起运岁数
- [ ] 大运方向与阴阳判定一致
- [ ] 月柱与第一步大运的关系符合顺/逆规律

## 紫微斗数体系 · 5 个关键计算点

### ① 几局(最关键)

**正确算法**:**出生月份 × 2 + 出生时辰 × 2 + 日期** → mod 4(无固定公式,因流派而异)

**实战策略**:⚠️ **紫微排盘必须用专业软件/在线排盘**(安星法流派众多,AI 无法精确推算)

**校验公式**:**永远不要凭"经验"推几局**——用在线排盘(求前尘、问真八字等)对照

**起点样例**:1985-06-15 14:30
- 必须用软件推:假设为 **水二局**
- 第一大限起运岁数 = 2 岁(几局决定起运)

**错例**:
| 错例 | 错误结果 | 错因 |
|---|---|---|
| 凭"水命"猜几局 | 命宫位置错 | 几局与生辰相关 |
| 跳过这一步直接给结果 | 整个排盘错 | 没建立基础 |

**自检清单**:
- [ ] **必须用排盘软件/在线工具确认几局**
- [ ] 起运岁数 = 几局数值
- [ ] **不确定时,在报告中标注"v0.1.0 暂用假设数据,建议专业软件复核"**

### ② 命宫所在宫位

**正确算法**:**生月 + 生时** → 查命宫起法表

**实战策略**:与几局一样,**必须用排盘软件**

**自检清单**:
- [ ] 命宫位置由软件推算,不在报告中"凭印象"标注
- [ ] 14 主星按命宫所在位置依次排列

### ③ 大限流转方向

**正确算法**:**阳男阴女顺转,阴男阳女逆转**(10 年一宫)

**起点样例**:1985-06-15 男(假设乙丑年阴年男)
- 阴男 → **逆转**
- 每 10 年逆推一宫

**错例**:
| 错例 | 错误结果 | 错因 |
|---|---|---|
| 阳男用逆转 | 12 大限全错 | 阴阳判定错 |
| 顺转数错 | 大限窗口错 | 流转方向与步数不一致 |

**自检清单**:
- [ ] 显式写出"X 男/女 + 阳/阴年 → 顺/逆转"
- [ ] 第三/四/五大限是高光窗口(参考紫微视频)

### ④ 流年命宫

**正确算法**:**流年地支即流年命宫所在位置**(所有人同步)

**起点样例**:
- 2025 乙巳蛇年 → 巳宫
- 2026 丙午马年 → **午宫**(所有人命宫都转到午宫)

**自检清单**:
- [ ] 每年流年命宫同步(不像大限按个人流转)
- [ ] 2026 = 午宫,2027 = 未宫,...

### ⑤ 四化(天干 → 4 颗主星)

**正确算法**:**查十天干四化表**(口诀)

**校验公式**:无——必须记口诀

**口诀**:
```
甲 廉破武阳(甲年廉贞化禄、破军化权、武曲化科、太阳化忌)
乙 机梁紫阴
丙 同机昌廉
丁 阴同机门
戊 贪阴弼机
己 武贪梁曲
庚 阳武阴同
辛 门阳曲昌
壬 梁紫辅武
癸 破门阴贪
```

**起点样例**:1985 乙丑年 → 乙干四化
- 化禄 = 天机
- 化权 = 天梁
- 化科 = 紫微
- 化忌 = 太阴

**错例**:
| 错例 | 错误结果 | 错因 |
|---|---|---|
| 把"甲 廉破武阳"记成"甲 廉阳破武" | 化权/化科错位 | 口诀顺序错 |
| 用错年份的天干 | 整个四化错 | 流年天干错 |

**自检清单**:
- [ ] 用口诀推一次,然后查标准表对照
- [ ] 戊干/庚干/壬干 UP 主口误时,以标准表为准(已在 ziwei SKILL 标注)
- [ ] 报告显式列出"X 干 → 化禄 X / 化权 X / 化科 X / 化忌 X"

## 通用起点对错自检流程

### 输出前必走 5 步

```
[1] 原始输入(用户给的生辰)
[2] 计算过程(显式列出,带公式)
[3] 样例对照(用已知案例或简单算验证)
[4] 错例警觉(主动想"我可能错在哪里")
[5] 自检清单(逐项勾选)
```

### 报告必须包含

任何计算点的输出,都必须带:
1. **原始输入** + **算法**(让人能复核)
2. **样例对照**(用简单案例验证算法对)
3. **不确定项标注**("需专业软件复核")

### 不可省略的"起点对"标记

- 八字:四柱 → 至少 1 个柱由万年历直查(其他可推)
- 紫微:命宫位置 / 几局 → 必须由软件给出
- 真太阳时:经度时差 → 必须显式列出
- 节气分界:跨节气前后 3 天 → 必须查万年历
