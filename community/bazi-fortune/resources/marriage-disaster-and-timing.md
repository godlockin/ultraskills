# 婚灾 + 婚期 — 视频原文精读

> 来源:荀太虚《八字婚姻/桃花》视频转写(2026-05-12)

## 视频核心口诀

> **"男婚怕冲,女婚怕合"**

| 性别 | 原局形式 | 婚灾倾向 |
|---|---|---|
| **男** | 夫妻宫有**冲** | 易有婚灾 |
| **女** | 夫妻宫有**合** | 易有婚灾 |

## 一、男命怕冲(夫妻宫被冲)

### 视频具体案例

> 命主夫妻宫里有财。
> 原局**卯戌相冲**。
> 去年(癸卯年)卯被激活 → 卯 = **偏财** = 妾 = 情人 → 冲到夫妻宫 → **鸠占鹊巢** → 婚姻被冲击,小三找上门。

### 婚灾应期

视频原文:"什么时候是婚灾的应期呢?就是在流年大运,碰到有相同的字去激活他的时候。"

> 即:**流年/大运 的字 = 冲局中的某字** → 被激活 → 触发婚灾。

## 二、女命怕合(夫妻宫被合走)

### 视频具体案例

> 女命夫妻宫是**酉**。
> 原局**酉戌合金**。
> 命主女性,原局金印旺 → **清高自以为是,想得太多,内耗** → 最终不和离婚。
>
> 视频原话:"仇友合金合的是印,她的这个局印太旺了,印旺身也旺,人就比较清高,自以为是,想得太多,淤堵内耗,最终导致不和离婚。"

### 嵌套逻辑

- **酉戌合金** = 印太旺
- **印旺 + 身旺** = 清高+自以为是+内耗
- **印过旺为忌** → 不善言辞、不沟通 → 离婚

## 三、应期口诀:"和者欲冲,冲者欲和"

视频原文:"和者欲冲,冲者欲和。什么意思呢?原局里面夫妻宫有合的,碰到流年大运被冲的时候,就能结婚;原局里面夫妻宫有冲的,遇到把他合走的,则就能结婚。"

| 原局 | 应期 | 例 |
|---|---|---|
| **夫妻宫有合** | 流年/大运来冲 → **应婚期** | 卯戌合 → 癸卯年来 → 卯冲戌(也冲辰/酉)→ 婚姻契机 |
| **夫妻宫有冲** | 流年/大运来合 → **应婚期** | 卯戌冲 → 辰/酉来合 → 婚姻契机 |

> 注意:**戌被冲** 是好事,而**卯来冲戌** 与原局的卯合向冲是冲突,但**反方向冲**(冲戌所涉之合)就成了。

## 四、视频给的婚期示例

> 例八字:原局有**酉戌合金**(夫妻宫有合)
> 2023 **癸卯年** 卯来,卯冲戌 → **应婚期**

> 关键词:**流年冲的对象 = 原局合的对象** 才有效。

## 五、避免误区

- 不要**只看冲合**判断婚灾/婚期,还要看**喜忌**
- **喜用神一致** → 更可能顺;**喜忌相反** → 多波折
- 流年触发是**关键**,但**八字本质**仍是基础

## 实操流程

1. 排盘 → 定日支(夫妻宫)
2. 看夫妻宫里十神 + 与原局支的冲合
3. 看该冲合是喜是忌
4. 用流年/大运:若该字被冲/被合,**应期到**
5. 结合配偶星强弱(数量、位置)、喜忌

## 给客户的话

> 不要把婚期推到一个"绝对日期",**应期是"窗口期"** — 几年内的概率明显升高,而非精确日期。
>
> 视频态度:**结合当下行为(主动拓展社交、调整心态),才是催动缘分的关键**。
