## 一、三种实用算法

> "这里要引入一套算法。和小伙伴耳熟能详的**刑冲破害会**不同,在实践中用得比较多的是以下三种。"(L2317-L2319)

### 算法 1:合 > 生 > 克

> "第一是看**字和字之间的合、生、克结果**。其中**合大于生,生大于克**。**有合要先论合**。这个合指的是**天干五合**和**地支六合**。"(L2320-L2324)

**执行顺序**:
1. 先找有没有**合** → 有合先处理合
2. 再看**生**
3. 最后看**克**

### 算法 2:阳性字有主动权

> "第二是看字的**阴阳关系**。因为**阳性字的能量大于阴性字**,具有**生克流通的主动权**。当盘面出现阳性字的时候,**首先找阳性字**,看看有几个、相互是什么关系。"(L2326-L2331)

#### 规则 2a:阴性字不能作为两个阳性字的通道

> "比如**阴性字能量小,在相生的过程中不能作为两个阳性字的通道**。"(L2332-L2333)

**示例:卯子卯午**(L2334-L2340)
```
❌ 错误理解:子水生卯木生午火(把卯木当通道)
✅ 正确判断:子水克午火 + 子水生双卯木

理由:卯木是阴性字,能传递的能量很有限
补充:不过因为有两个卯木在,午火受伤减轻
```

#### 规则 2b:阳克阴是"想克就克"

> "二是**阳克阴是想克就克**。"(L2341)

**示例:地支子巳卯酉**(L2342-L2348)
```
❌ 错误理解:酉金生子水生卯木生巳火
✅ 正确判断:酉金生子水生卯木,然后子水克巳火

原则:阳性字要克的五行,如果中间缺少相生的阳性字通关,
      就是"想克就克"
```

#### 规则 2c:两个阴性字之间可以互相独立

**示例:戌卯子未**(L2349-L2355)
```
1. 戌卯两字相邻,首先被合
2. 未土是阴性字,克不动子水
3. 子水也克不了未土
→ 两者之间互相独立

这个时候就看外来的大运、流年、流月和原局形成什么样的组合关系
```

## 二、天干五合

> "天干五合包括**甲己合、乙庚合、丙辛合、丁壬合、戊癸合**。怎么记好呢?按照**甲乙丙丁戊己庚辛壬癸**排序,**N 与 N+5 的位置**的两个字两两相合,这就是天干五合。"(L2359-L2365)

| 序位 | 组合 |
|---|---|
| 1 + 6 | 甲己合 |
| 2 + 7 | 乙庚合 |
| 3 + 8 | 丙辛合 |
| 4 + 9 | 丁壬合 |
| 5 + 10 | 戊癸合 |

## 三、地支六合

> "地支六合指的是**子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合**。我们用**十二宫位图**来理解和记忆:排在**左下角第一位的是寅**,也是农历中的**正月**;排在最后的是**丑**,是农历中的**腊月**。**十二宫位图中横着的两个地支相合**,就是地支六合。"(L2366-L2374)

| 组合 |
|---|
| 子丑合 |
| 寅亥合 |
| 卯戌合 |
| 辰酉合 |
| 巳申合 |
| 午未合 |

## 四、合的两条硬约束

> "在原局中,**合的前提是两字必须相邻**。其中**日主永远不参与合的作用**,它左右的两个字如果能合,可以直接合。"(L2375-L2378)

1. **必须相邻** — 不相邻不论合
2. **日主不参与合** — 但日主左右两字可越过日主相合

## 五、完整推演示例:小明八字

原局:**乙亥、庚辰、乙酉、辛巳**(乙木日主)

### 天干层(L2379-L2401)

```
1. 年干乙木 合 月干庚金       ← 先论合
2. 剩下时干辛金 克 日主乙木
→ 天干状态:日主受克(官克身)
```

**关键解读 — 日主受克不等于差**:

> "古书对日主受克的描述通常是**比较凶险**,而**日主受克在现代社会并不一定说有多差**。特别是**高考的学生、体制内的干部、学校里的教职员工**等等,在日主受克的情况下**反而更容易发挥正向作用**。"(L2384-L2388)

> "一方面是这几类状态下,**人本身就接受了很多来自官星的压制**,比如考试、领导、规则,这些都是克我的事物和关系。另一方面是**物竞天择**,人在持续性的压制下,要么**破而后立,战胜压力越战越勇**;要么**放弃自我,完全从官顺势而为,做个服从性强的副手,跟对老大也能生存得很好**。"(L2389-L2398)

> "日主受克一般常见外在表现是**清高、上进、好胜心强**,也**比较容易内耗抑郁**。"(L2399-L2401)

### 地支层(L2402-L2410)

```
1. 辰土 合 酉金               ← 先论合
2. 剩下亥水 克 巳火
→ 地支状态:印克食伤
```

> "这种**原局性的合**一般代表**相关能量缺失**,或者是**本人对该十神代表的事物和关系要求比较高**。"(L2403-L2404)

> "印克食伤这类人在**年少时是比较听话、守规矩**的人,缺点是**应变能力较差**,免不了**当面吃亏、背后生闷气**的情况。"(L2407-L2410)

## 六、⚠️ 反格局论:身强身弱意义不大

> "有人这时候可能会问:**不看身强身弱吗?或者这是什么格局?** 其实**不论身强身弱还是格局,在实践中意义并不大**。因为**一个八字的原局仅仅只能作为参考,更要看每个八字搭配的运势好不好**。"(L2412-L2418)

> "就好像一辆汽车静静地停放在人生赛道的起点,它的**性能和状态只停留在纸面**。最终的赛跑成绩**既取决于驾驶员的操纵,更依赖于赛道的环境变化**。**车好路不好,再好的性能也发挥不出来;路好车不好,再差的车至少也能平稳地跑完全程**。"(L2419-L2426)

> "一个人**原局身强,不代表一辈子身强**,也**没有什么所谓身强就担财、身弱就不担财的道理**。"(L2427-L2429)

### 批判:格局通胀

> "很多人潜意识里难免会有**个人主义或者英雄情结**,希望自己的八字**越稀有越厉害就越好**。以至于**很多用心不良的命理师为了讨人开心,降低了取格的标准,甚至人为地加了很多新格局,弄得不伦不类**。这些都是很多人刚开始接触八字时**最容易陷入的几个误区**。"(L2430-L2436)

### 为什么古今权重不同

> "古人发明八字的年代,**生活的环境变化慢**,社会没有出现指数发展的现象,还因为**封建时代阶级严重固化**,一个人的**家庭背景对人的命运影响很大**。在这个背景下,**重视原局是没错的**。"(L2437-L2442)

> "而**现代社会发展快,大运流年的权重就比古代要高很多了**。因此我们现代人在研究八字的时候,一定要在**理解本质的同时做到与时俱进,合理地推陈出新,切记不能生搬硬套**。"(L2443-L2447)

> **这是本 skill 应当继承的核心方法论**:原局定底色,大运定成败。不要迷信格局标签。

## 七、原局 × 运势的四种组合

> "归根结底,八字的好坏无非是看**原局和运势的综合作用**。"(L2448)

| 原局 | 运势 | 结论 |
|---|---|---|
| 有问题 | 好(脱困) | "这个八字**就算不错**"(L2449-L2451) |
| 挺好 | 很普通 | "优势发挥不出来,这样的八字**就不太理想**"(L2452-L2454) |

> "有句诗说得恰如其分:**时来天地皆同力,运去英雄不自由**。把运势的重要性讲得很透彻。"(L2455-L2458)

### 运势不止是个人的

> "这里所谓的运势,**除了指每个八字的运势,还包括命主所处环境的运势、命主父母的运势、国家的运势**等等。东汉思想家**王充**在他的著作**《论衡》**中曾指出'**国命胜人命**'的这个论点。用现代的话来说,就是**站在风口上,哪怕是猪都能飞**。"(L2459-L2465)

## 八、受克状态 = 病 / 磨练 / 挑战

> "已知小明的原局状态是**天干日主受克、地支印克食伤,都是受克状态**。我们可以把**受克状态理解为是一种病,或者是一种磨练、一种挑战**。面对这种开局,小明的**人生起始坐标点是处在人生坐标轴靠下的位置**。"(L2468-L2475)

**两种走向**(L2476-L2487):

| 运势方向 | 判断 |
|---|---|
| **加重**原局受克 / 制造新受克,且持续较长 | "他的八字**挑战比较多**,需要当事人更有针对性地趋利避害" |
| **缓解**原局状态,甚至**从相克变成相生** | "**起点越低,反弹起来的高度会越高**……人生旅途还是很有希望的" |

> "以上只是一个很宽泛的概念。在实际过程中,**人生的轨迹不总是单一的模式**,有的路线单一,有的路线多变,这就需要**具体问题具体分析**,也是**考验命理师经验和水平**的地方。"(L2488-L2493)
