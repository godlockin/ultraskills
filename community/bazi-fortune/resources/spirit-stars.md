# 神煞 — 八字的特殊记号

> 来源:荀太虚视频未深入神煞专题,以下为经典表 + 简要视频提及的"禄神"等用词

## 常见神煞(基于经典)

| 神煞 | 主事 | 简述 |
|---|---|---|
| **天乙贵人** | 贵人运 | 命中最有力的吉星,主逢凶化吉 |
| **太极贵人** | 学识、修行 | 主聪明好学 |
| **文昌贵人** | 学业、考试 | 主考试顺 |
| **驿马** | 出行、调动 | 主迁移、变运 |
| **桃花**(咸池)| 姻缘、魅力 | 主异性缘 |
| **华盖** | 艺术、宗教 | 主孤高、艺术气质 |
| **将星** | 领导、权位 | 主权威 |
| **金舆** | 财富、车马 | 主财 |
| **禄神** | 财富、稳定 | 主福禄 |

## 视频提及(细节)

视频未对神煞深入展开,但提到 "禄神"、"禄" 等概念作为财星相关。

> **具体神煞的星盘计算按"以日干查其他七字"为准**, 现代工具可自动计算。

## 使用建议

- 神煞仅作**辅助参考**,主轴看十神 + 用神 + 大运
- 桃花 / 驿马可参考,但**不主导结论**
- 视频未深入之处,以**经典表**为基础,**不要硬造细节**
