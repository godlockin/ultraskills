> **来源**:荀太虚【零基础】传授紫微斗数(L2316-2323 + L1607-1635),YouTube ID `_aOD6roA_EY`(2026-04-19)
> **用途**:为 `bazi-fortune` skill 提供"能量守恒"框架的反向增强——任何八字论命必须意识到**有得必有失**。

## 一、核心命题

UP 主讲紫微斗数四化时给出的最核心原创观点:

> 「四化是天干的自然能量变化,是能量守恒的,有收获就一定 有付出。」—— L2316-2323

> 「如果你想让一个小火苗发光发热,是不是自然就不能在阳光下面、不能在一堆大火旁边。」—— L1607-1635

**应用到八字**:十神之间的生克制化也遵守同样的守恒——**任何"得"的极致,都伴随"失"的代价**。

## 二、十神能量守恒映射表

| 偏强十神 | 必伴随的代价 | 实战提醒 |
|---|---|---|
| **印星过旺**(4 个印) | 印克伤官 → 才华被压制 | **学习能力强但表达不出**;改命点:学会拒绝、学会表达 |
| **财星过旺**(财多身弱) | 身扛不住财 → 健康透支 | **进账越多身体越垮**;改命点:先养身,再求财 |
| **官杀过旺**(克身太重) | 官克身 → 压力 / 官非 | **事业越大人越累**;改命点:接受压力,主动减负 |
| **食伤过旺**(反传统) | 食伤克官 → 职场关系紧 | **有才华但难在大公司立足**;改命点:创业或顾问型 IP |
| **比劫过旺**(印比成群) | 比劫夺财 → 钱留不住 | **人缘好但财务紧张**;改命点:合伙必签协议 |

## 三、能量守恒与顺势四问的整合

`bazi-fortune` 现有顺势四问:

| 问 | 内容 |
|---|---|
| ① 当前大运季节? | 春/夏/秋/冬 |
| ② 五行最旺/最弱? | 旺 X / 弱 Y |
| ③ 用神三层? | 原局 X → 大运 Y → 流年 Z |
| ④ 顺季节做事 vs 逆季节硬扛? | 顺/逆 |

**整合后的第五问(2026-08-27 升级)**:

| ⑤ 当前格局的能量守恒点? | 旺 X 的代价是什么? |
|---|---|

**应用范例**:
- 大运是"秋"→ 收成期 → 但秋的代价是"金克木"→ **家庭关系紧张**(印星受克)
- 大运是"夏"→ 生长期 → 但夏的代价是"火多木焚"→ **过度消耗精力**

## 四、能量守恒与改命方向

**原 UP 主对"能量守恒"的实战应用**(L1607-1635 解释甲干廉贞化禄 + 太阳化忌):

> 「廉贞是阴火,就是小火;太阳是阳火,代表阳光、光明、大火。如果你想让一个小火苗发光发热,是不是自然就不能在阳光下面,不能在一堆大火旁边。」

**应用到八字改命**:
- 不追求"全得"格局
- 接受"得必有失",选择**代价最小的方向**
- 改命 = **主动选择代价**,而非消除代价

## 五、能量守恒自检清单

每次八字论命后,自检 5 个问题:

- [ ] 这个格局的"得"是什么?(印旺得学识、官旺得事业、财旺得进账...)
- [ ] 这个格局的"失"是什么?(印旺失表达、官旺失自由、财旺失健康...)
- [ ] 命主是否已经意识到这个"失"?
- [ ] 如果命主想最小化"失",应该怎么调整行为?
- [ ] 大运 / 流年是否会改变"得"和"失"的配置?
