# Awwwards 设计鉴赏案例

## 案例 1: Deadstock Coffeee

**URL**: https://deadstockcoffee.com/

### 设计风格
Pattern 5: Streetwear/Hype Drop

### 色彩系统
- 主色: #0a0a0f (深黑, 占比 70%)
- 辅助色: #1a1a1a (次级区块, 占比 25%)
- 点缀色: #FF6B00 (活力橙, 占比 5%)

### 设计亮点
1. **运动潮牌 × 精品咖啡文化融合** — 火焰图标统一视觉语言
2. **粗体大写无衬线标题** — 品牌感强，视觉冲击大
3. **Hero 首屏大图主导** — 产品卡片网格展示
4. **购物车滑入通知** — 实时交互反馈
5. **Hover 状态** — 按钮颜色变化引导行动

### 可借鉴点
- 跨界品牌融合时，找共同视觉元素（火焰 = 热情 + 咖啡烘焙）
- 限量发售页面用深黑 + 亮色强调紧迫感
- 动效用于强化品牌调性（滑入通知而非弹窗）

### 风险点
- 过度依赖暗色可能降低可读性
- 大字体需配合足够留白

## 案例 2: Get Blue

**URL**: https://www.getblue.com/

### 设计风格
Pattern 2: Split-Screen Portfolio + Pattern 4: Wellness Brand

### 色彩系统
- 主色: #0a1825 (深海军蓝, 占比 70%)
- 辅助色: #f5f5f0 (米白, 占比 25%)
- 点缀色: #00b4d8 (电光蓝, 占比 5%)

### 设计亮点
1. **生活方式摄影销售愿景** — 图片与品牌理念结合
2. **Split-Screen 分屏设计** — 文字与图片交替左右排列
3. **滚动触发图片滑入** — 实时时钟展示增加互动感
4. **对比表格彰显数据** — 信任建立
5. **Sticky 导航** — 长滚动页面保持导航可见

### 可借鉴点
- 健康/生活方式品牌用 Split-Screen 展示产品使用场景
- 对比表格用数据建立信任
- 实时时钟/数据展示增加科技感

### 风险点
- 大量图片需优化加载性能
- Split-Screen 移动端需适配为纵向布局

## 案例 3: Cooldock

**URL**: https://dock.cool

### 设计风格
Pattern 1: Premium Dark Launch Landing

### 色彩系统
- 主色: #0a0a0f (深黑, 占比 70%)
- 辅助色: #141418 (次级区块, 占比 25%)
- 点缀色: #FF6B00 (橙色紧迫感) + 蓝紫渐变 (占比 5%)

### 设计亮点
1. **Apple 风格极简 Dark Mode** — 沉浸式体验
2. **信任信号前置** — 隐私优先/本地优先
3. **48-64px 粗体 Hero** — 清晰层级
4. **三列功能卡片** — Bento Grid 雏形
5. **Widget 实时预览条** — 产品功能可视化

### 可借鉴点
- SaaS 产品用 Dark Mode 传递技术专业感
- 信任信号（隐私/本地优先）作为差异化卖点
- Hero CTA 点击区域 > 周围元素 40%

### 风险点
- 暗色模式下对比度需严格控制 (WCAG ≥4.5:1)
- 深色设计需同时考虑浅色模式适配

## 案例 4: AI in Design Report 2026

**URL**: https://stateofaidesign.com/

### 设计风格
Pattern 3: Editorial Long-Scroll

### 设计亮点
1. **大号章节编号** — 01, 02, 03... 视觉锚点
2. **长文案 + 高质量配图** — 杂志编辑风
3. **统计数字大字体展示** — 数据可视化
4. **引用区块突出** — 观点提炼
5. **订阅 CTA** — 底部转化

### 可借鉴点
- 内容密集型网站用 Editorial Layout
- 章节编号作为导航锚点
- 大字体数字作为视觉焦点

### 风险点
- 长滚动需良好的加载性能
- 移动端阅读体验需单独优化
