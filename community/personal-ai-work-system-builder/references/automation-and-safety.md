# 自动化与安全

## 自动化成熟度 (5 状态)

| 状态 | 含义 | 升级到该状态的硬条件 |
|---|---|---|
| 手动 | AI 仅提供说明或模板,动作由人完成 | 无 |
| AI辅助 | AI 分析或生成草稿,人完成系统操作 | 草稿已被用户实际采用 ≥1 次 |
| 半自动 | AI 完成大部分步骤,在关键节点等待确认 | 端到端跑通 ≥1 次 + 人审节点已定义 |
| 全自动 | 已连接、已测试、可在规则内完成执行和回写 | **4 条全满足**:真实连接 / 已测试(≤7 天内 PASS) / 异常可停止 / 结果回写 |
| 规划中 | 只有设计,没有完成连接或验证 | — |

**状态降级规则**:标注"全自动"但最后测试超过 7 天未验证 → 自动降级为"半自动"。超过 30 天 → 降为"规划中"。

## 候选评分

对**频率、规则稳定性、输入标准化、结果可验收性、出错可恢复性、节省时间/业务价值**各评 1—5 分;**风险**另评 1—5 分。

**推荐公式**:

```
推荐分 = 频率 + 规则稳定性 + 输入标准化 + 结果可验收 + 出错可恢复 + 业务价值 − 风险 × 2

≥ 20  优先自动化(本周做)
15-19 值得做(30 天内)
10-14 先做半自动
< 10  暂不自动化,保持人工
风险 = 5  无论总分多少,先做半自动 + 人审
```

评分结果记入 `AUTOMATION-REGISTRY.md` 对应行,便于后续复核为何选了这条。

## 🔒 授权门协议 (Authorization Gate Protocol)

**用户的口头授权不等于人审。** "我授权你自动做所有事" 不构成对具体某次动作的确认。

### 高风险动作清单

付款 / 退款 / 转账 / 审批 / 删除数据 / 权限变更 / 对外发送承诺 / 批量客户触达 / 员工评价录用解雇 / 法律医疗财务判断 / 数据源冲突未定口径。

### 执行前必须走的确认流程

对上述任一动作,执行前输出:

```
RISK-ALERT
动作:<具体动作,如"向 32 位客户发送续约提醒">
对象:<收件人/账号/数据范围>
影响:<不可逆吗?涉及金额?涉及多少人?>
回滚:<能否撤销,如何撤销>
确认请回复:GO-YES-<本次编号>
```

**未收到与编号完全匹配的确认码 → 不执行。** 用户回复"可以""好的""你做吧"均不算确认。

### 三条硬约束(缺一不可执行)

1. **一次性确认码** — 每次动作单独确认,不可批量预授权
2. **阈值** — 金额上限 / 收件人数量上限 / 删除条数上限,超限强制人审
3. **白名单** — 收件人、账号、API endpoint 必须在预先登记的白名单内

## 🚨 升级转交矩阵

以下情况**不要自己设计方案**,直接指出该找谁:

| 触发情况 | 转交给 | 理由 |
|---|---|---|
| 付款 / 退款 / 财务流程设计 | 财务 + 法务 | 内控与双签要求,个人无权设定 |
| 解雇 / 薪酬 / 员工评价自动化 | HR + 劳动法专业人士 | 劳动法风险,AI 决策不可作为依据 |
| 客户数据出境 / 隐私合规 | 合规 / DPO / 法务 | PIPL 出境需法定条件,见 [数据分级](data-classification.md) |
| 跨部门数据打通 / 系统权限申请 | IT 治理 | 个人无权变更组织级权限 |
| 数据源冲突且业务方各执一词 | 业务 owner + IT | 需权威裁定唯一口径,不由 AI 选 |
| 医疗 / 法律 / 税务实质判断 | 对应执业人士 | 无执业资格,不得给出结论 |
| 用户处于危机状态(情绪/法律纠纷) | 停止系统设计,建议专业支持 | 不是本 skill 的适用场景 |

## 通常必须保留的人审节点

- 付款、退款、审批、删除、权限变更
- 对外发送承诺、批量客户触达
- 员工评价、录用、解雇和敏感管理决策
- 法律、医疗、财务等高风险判断
- 数据源冲突或无法确认唯一口径

人审应发生在**最终外部动作前**,而不是等出错后补救。

## 端到端验收

- [ ] 使用真实或脱敏后的代表性输入
- [ ] 数据源、权限、主责和停止条件明确
- [ ] 关键外部动作有人审(走授权门协议)
- [ ] 交付物真实可用
- [ ] 结果写入指定资产库
- [ ] 至少完成一次端到端测试,记录测试日期
- [ ] 异常路径至少测试一次(输入缺失/API 失败/权限不足)
- [ ] 回滚路径已验证
- [ ] 状态被如实标注

> "给出操作步骤"不是自动化;"点击按钮只显示流程图"也不是自动化;"跑过一次脚本"不等于全自动。
