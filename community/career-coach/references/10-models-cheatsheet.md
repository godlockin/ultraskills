# 10 思维模型速查表 (Quick Reference Cheatsheet)

> 给 career-coach 主体的具体执行手册。每个模型一条「情境 → 步骤 → 关键句式」三元组。

---

## 1. GROW 模型(Goal / Reality / Options / Will)

**适用**:目标模糊;用户开口就是「我想…但不知道怎么做」。

**步骤**(强制顺序):

1. **Goal** — 用 Clean Language 锁定目标词原话。
   - 「你说 [职业上有突破],具体到 [突破] 那会是什么样的?」 / 「你理想中 [突破] 后的一周和你现在的一周,最不同的一点是什么?」
2. **Reality** — 仅问现状,选项暂不出。
   - 「现在到这一步之间,卡你最久的是什么?」 / 「支持你走到现在这一步的有什么?」
3. **Options** — 把选项挂在现实之后。
   - 「如果不是因为某条路一定不能走,你都能想出哪些选项?给三个最离谱的也可以。」
   - 「如果把不可能性的那一面暂时拿掉,你最想试试的是哪一个?」
4. **Will** — 收敛到动作+时间+衡量。
   - 「挑一个,你打算 [这周/下次] 怎么试第一步?具体动作是什么?做完成功的标准是什么?」

**禁忌**:Goal 还没清晰就开始铺 Options — 选项建立在沙上。

## 2. Logical Levels (Dilts 逻辑层次)

**适用**:用户说「我老是这样」「我就是…」一类反复模式。

**结构**(自下而上):

```
精神 (Spirit)        我与世界的关系 / 贡献
  身份 (Identity)     我是谁 / 一个什么样的人
    信念/价值观 (Beliefs)   什么重要 / 为什么
      能力 (Capability)    我能什么 / 不会什么
        行为 (Behavior)     我做什么 / 不做什么
          环境 (Environment)  在哪 / 跟谁 / 用什么
```

**下三层(环境/行为/能力)→ 「怎么做」**;**上三层(信念/身份/精神)→ 「为什么/我是谁」**。

**对话路径**(强制:从下往上挖,而不是从上往下空喊):

1. 先在**行为层**落地:「最近一周你在做这件事最不/最多的具体动作是什么?」
2. → 上**能力**层:「做出这些动作,你需要哪些能力?哪些已经有了,哪些还差?」
3. → 上**信念**层:「如果让你用一个词形容你做这件事的根本原因,是哪个词?」
4. → 上**身份**层:「如果这件事做到了,你成为的那个人,跟现在的你最大的不同是什么?」

**关键句式**: 「你为什么在意这件事? — 这背后你相信什么? — 这让你是谁? — 这份信念支撑你想给这个世界带来什么?」

**禁忌**:直接问「你的身份是什么」— 太抽象会被怼。必须从行为逐步向上。

## 3. ORID 焦点对话

**适用**:复盘、对齐、剥洋葱;用户已经讲了很多事实但还没出决定。

**结构**:

```
Objective    客观事实       我们看到了/听到了什么
Reflective   情绪/反应      这让我感到 / 我印象最深的是
Interpretive 意义/理解      这说明什么 / 这对我意味着什么
Decisional   决定/行动      下一步我做什么 / 何时做
```

**对话节奏**:

1. **Reflective 必有** — 哪怕跳一步也要有:「这事让你最 X 的那个瞬间是什么?」
2. **Interpretive 不许说「应该怎样」** — 只能问:「这事说明/意味着什么?」
3. **Decisional 必须三件套**:动作 + 时间 + 衡量 — 否则不算落地。

**典型追问**:
- 「你刚才描述了三件事,哪一件让你印象最深?」 → Reflective
- 「如果你把它当同事描述你失败的故事,他/她会怎么解读?」 → Interpretive 的心理位移变体
- 「那么下一步,我们做哪个最小的一步?什么时候做?做成什么样就算成了?」 → Decisional

## 4. Wheel of Life (平衡轮)

**适用**:用户说「什么都不对」「看全局」「整体失重」— 单点聊不动,需要先看整体不均衡。

**步骤**:

1. 设定**核心维度**:典型 8 维 (职业 / 财务 / 健康 / 关系 / 家庭 / 学习 / 兴趣 / 精神)。可裁成 6 维。
2. 让用户给每维 1-10 分(只看当下,不许考虑应该)。
3. **画 8 边形**(可口头描述):「你看哪一瓣最大、哪一瓣最小?」
4. **先把最小那一瓣挑出来深聊**(而不是分头补救)。

**典型追问**:
- 「你说职业 6、健康 3、关系 7,这三块里,提升哪一块对其他两块带动最大?」
- 「假设 3 个月后你想让某一块 +2 分,你会做哪个具体动作?」

**禁忌**:列完整 8 维分数但不深入任何一块 — 那叫 assessment 不叫 coaching。

## 5. SBI / SBI-I 结构化反馈(合并了旧版 BIE 与 SBI)

> **v2.0 修正**: 老版把 BIE(Behavior-Impact-Effect)当独立模型讲,但业界权威模型是 CCL 的 **SBI**(Situation-Behavior-Impact),把 Impact 和 Effect 强拆两层没有权威源。这里合并。

**适用**:用户要表达对他人(老板/同事/下属)的具体反馈但只会「我对你有意见」。

**核心结构 SBI**(Situation-Behavior-Impact,来源: CCL Center for Creative Leadership):

```
S  Situation   当时的具体情境(时间/地点/在场人)
B  Behavior    具体可观察的行为或语言(逐字/逐动作)
I  Impact      对事/人/团队产生的效果
```

**升级版 SBI-I**(加意图澄清)或 **CORE**(Context-Observation-Result-nExt step,来源: Kim Scott《Radical Candor》):

```
S/C  Context/Situation   情境
B/O  Behavior/Observation 行为(具体到句)
I/R  Impact/Result       影响
+     Intent/Ask/nExt     替代行为 / 你期待怎么做 / 下一步
```

**对话生产**:

1. 「你想反馈的那件事,具体看到/听到对方做的哪一句话/一个动作?」 — B
2. 「这一下当时对你/对你要做的事产生什么效果?」 — I
3. 「如果这种效果长期 3-6 个月不改变,最后会变成什么?」 — E

**典型纯化版表达**:
「我看到你 [B 具体一句话],这让我 [I 感受/影响],长期这样我会 [E 团队/我的后果]。我希望看到的是 [替代行为],你看这样行吗?」

## 6. Empowering Questions (赋能式提问)

**适用**:兜底;或不知道用啥时。

**4 个特征**(每一个问题尽量满足更多):

- **开放式**:不以 yes/no 结尾
- **假设性**:「假设…会…」
- **未来导向**:「3 个月后…」
- **资源导向**:「过去类似的事你怎么扛过来的?」

**模板库**(可背诵):

- 「你最想要的是什么?」
- 「这件事对你的意义是什么?」
- 「对你身边谁来说,这事的意义最大?为什么?」
- 「如果你已经做到了,你会看到自己什么不一样?」
- 「你平时最自信的那一面,在这种情境下能用上吗?」
- 「如果知道一定不会失败,你会做什么?」
- 「如果只能做一件事,你会选哪个?」
- 「过去类似的事,你最后怎么处理的?当时帮你的是什么?」

**禁区**: 不能用「为什么」开头太多次 — 隐含指责。改写为「是什么让你…」「你当初是怎么想到…」。

## 7. Clean Language (David Grove) · 12 句经典问

**适用**:用户说出抽象词(被看见、价值、卡住、出路、平衡);或想让对方感到被听见。

**Symbolic Modelling 12 句**(Penny Tompkins & James Lawley 标准):

1. 「你说的 [原话 X], 那会是什么样的?」
2. 「关于 [X],还有别的吗?」— **Grove 最常用的一句**
3. 「[X] 是什么样的 [X]?」— 探索内在隐喻
4. 「[X] 在哪里?」— 探索空间位置
5. 「如果 [X] 真的发生了,你会看到 / 听到 / 感受到什么?」
6. 「[X] 之前发生了什么?」
7. 「[X] 之后又会发生什么?」
8. 「是什么让你想到 [X] 这个词?」
9. 「[X] 跟 [Y] 有什么关系?」(两者都是对方原话)
10. 「[X] 想要发生什么?」— 目标导向清洁句
11. 「你需要 [X] 的时候,你会做什么?」
12. 「[X] 是什么阻止了你?」— **仅在用户已表达「卡住/有阻力」时用**,不是默认追问

**兜底 3 句**(不会用啥时轮转): #1、#2、#8。

**为什么有效**:把对方原话接过来再走一次,不像「教练化解释」,是被听见+被引导的双向动作。

**禁区**:
- 不要把对方原话改成你自创术语
- **同一抽象词追问 ≤ 2 次** — 第 3 次一定切模型(否则变审讯)
- Clean Language 对**童年创伤/复杂创伤来访者**可能触发解离,遇到时切成资源型问题

## 8. Perspective Shift (心理位移)

> **v2.0 修正**: 老版把 2nd person 写反了 — 金树人《心理位移日记》标准三步「我 → 你 → 他 → 我」,2nd 是用「你」称呼自己(自我对话),不是让别人建议我。

**适用**:用户明知道答案但自我卷死;需要跳出第一人称。

**3 视角**(标准):

```
1st person    我     「我该怎么办?」— 陷入其中的第一人称
2nd person    你     (把自己当对话对象)「你现在感觉怎么样?你到底在怕什么?」
3rd person    他/她  (第三方视角看自己)「这个 30 岁的产品经理,4 年没换赛道,他真正在意的是什么?」
```

**使用前提**(全部满足才用,避免触发创伤):
- 用户不在临床红旗状态
- 用户没有主动提到童年/家庭创伤
- 当前状态是「激活有序」或「失活有序」

**对话步骤**:

1. 先让用户说 1st person(主语「我」):「你想要什么?」
2. 切换到 3rd person 时给充分过渡:「如果今天是你的好朋友小 A 跟你说完全一样的事,你作为坐在他对面那个他最信任的人,你会怎么回他?」
3. 让用户自己用「我」回「我」时,会发现他已经从外部看到了自己 — 通常方案就出来了。

**变体**:
- 「未来的你(50 岁)看到今天的你,会说什么?」
- 「你最讨厌的那个同事看到这场景,会说什么?」 — 反向变体,适合用户对他人方案过度依赖时。

## 9. CBT ABC 模型(替代重叠的 SBI 独立位)

> **v2.0**: 老版 #5(BIE) 与 #9(SBI 升级版)高度重叠,合并到 #5 SBI。第 9 位补 CBT ABC 模型 — 处理「知道该做但做不到」的非理性信念。

**适用**:用户卡住不动 + 存在明显认知歪曲(「我一定/必须/应该 X」/「如果 X 就完蛋了」)。

**结构 ABC**:

```
A  Adversity/Activating   触发事件(客观发生了什么)
B  Belief                 你对它的信念/解释(常带扭曲)
C  Consequence            信念带来的情绪与行为
```

**教练路径**:

1. 「刚才你说的 [具体事],最让你受影响的是哪一句/哪一个瞬间?」— A
2. 「你当时心里冒出的第一句话是什么?」— B (关键: 让用户说出原话,不评判)
3. 「那句话让你 [情绪]/做了 [行为]?」— C
4. **不做认知重构**(那是治疗师工作) — 只问 「这句话如果换成对你更好的一句,会是什么?」

**边界**: 教练不修改用户的核心信念,只帮用户**看见**信念存在。深层认知歪曲 → 转介 CBT 治疗师。

## 10. State Management (教练之窗 + 状态觉察)

**适用**:**首要**(Step 0 第一次就要做,但每轮都要重新读)。

**模型**:激活-失活 × 有序-失序 → 4 象限。

```
                 有序            失序
        +----------------+----------------+
 激活   |  激活有序      |  激活失序      |
        |  (理想)        |  (焦虑/愤怒)   |
        +----------------+----------------+
 失活   |  失活有序      |  失活失序      |
        |  (过度理性)    |  (麻木/崩溃)   |
        +----------------+----------------+
```

**调态动作表**:

| 状态 | 一句话调态 |
|---|---|
| 激活有序 | 直接进模型,不用调 |
| 激活失序(焦虑/愤怒) | 拉回身体:「你现在身体哪里最紧? 吸气 4 秒、停 4 秒、吐 4 秒,做完告诉我。」;然后做 Reflective:「最让你感到不安的是哪一点?」 |
| 失活有序(过度理性/分析瘫痪) | 主动给情绪出口:「分析完了,你身体的感受是什么?」 / 「这些方案你听起来是不是没什么冲动?那是什么感觉?」 |
| 失活失序(麻木/低落) | 先承认痛苦:「听着你这么说,我知道你最近挺累的。今天不一定要解决什么,我们能不能聊一件事最小、今天就能动的?」 |

**绝对转介信号**(立刻温柔停止对话):

- 提到自伤、自杀想法
- 持续两周以上失眠/情绪低落/兴趣丧失
- 任何具体的精神科药物咨询
- 暴力倾向/伤害他人

**Trigger 话术**:
> 「我担心你的状态超过了我们这个对话能承接的边界,我真心建议你联系 [当地心理援助热线 / 专业咨询师 / EAP]。如果需要的话我可以帮你列个清单,但具体评估让我们交给专业的。」

## 模型混搭禁忌 & 节奏口诀

- **混搭顺序**:1 模型做深 > 2 模型并行 > 3 个以上必乱
- **节奏口诀**:「状态先读、一句原话、一个问题、一段共识、一个动作」
- **兜底句**:不会用啥模型时,问一句:「你说的 [原话 3-5 字],那会是什么样的?」 — 这句用 Clean Language 兜底 80% 场景。
