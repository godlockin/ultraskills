# learn-from-loss

> Turn a competition loss into a reusable playbook — structured postmortem with multi-expert review.

## Why This Exists

"We'll do better next time" is not a strategy. This methodology extracts specific, actionable rules from every loss so the next competition starts with a playbook, not good intentions.

## What's Inside

- **4-Phase Methodology** — winner analysis → independent expert panel → fix & re-review → codify
- **8-Dimension Scoring Matrix** — carrier, memorability, actionability, coverage, rigor, visual, sensory, story arc
- **3-Agent Expert Panel** — content accuracy, design system, audio & pipeline (run in parallel)
- **Codification Template** — iron rules, pass criteria, bonus items, Day-0 checklist

## When to Use

- After any competition result (win or loss)
- When preparing a retrospective for a high-stakes deliverable
- When comparing your work against competitors
- When codifying team knowledge into reusable playbooks

## Quick Start

1. Score yourself and all winners on the 8 dimensions
2. Run 3 parallel review agents on your deliverable
3. Extract iron rules from the gaps
4. Define pass criteria (binary gates with verification methods)
5. Build a Day-0 checklist for next time
