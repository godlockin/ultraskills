## 一、八卦的起源 (0:48:53)

> **视频原话**: "八卦诞生于远古时代,距今至少有六千年历史。由于时间过于久远,许多细节已经难以考证。"

**起源的三大说法**:

| 说法 | 内容 |
|---|---|
| **生殖崇拜** | 阴阳爻代表男女 |
| **结绳记事** | 模仿结绳记事 |
| **原始的分类方法**(流传最广) | 伏羲氏创立 |

> 伏羲氏采取"**近取诸身,远取诸物**"的方法,通过分析已知事物的内在关系,既统一认知又从已知推演未知。

> 八个卦象相当于挂了八个巨大无比的箩筐,把万事万物根据不同的形象、特征、属性、功能分成八个大类。

## 二、八卦的生成过程 (0:50:17)

> 《易经·系辞》:**"易有太极,是生两仪,两仪生四象,四象生八卦。"**

```
太极(混沌) → 阴阳两仪 → 四象 → 八卦
```

- **阳爻**:一根横线(─)
- **阴爻**:横线断开(— —)
- **三爻卦重叠三次 = 八卦**(也叫**八经卦**)

> 这个过程相当于现代物理学所说的**宇宙大爆炸**:从混沌(无时间无空间) → 天地分离 → 不断分裂 → 万事万物。

> 符合道家:**道生一,一生二,二生三,三生万物**。"三"是虚数,代表"多",所以三爻卦涵盖天地人三才。

> **视频原话**: "八卦系统是中国古人通过对事物的分类来突破认知局限的工具,第一次利用抽象的符号描述了宇宙乃至万物的生成过程。"

## 三、八卦的基本特征 (0:51:30)

> 卦象只是某些共性特征的模糊集合。**不能给任何一个卦象做确切的定义**。

### 乾(qián)— 天 ⭐

| 维度 | 内容 |
|---|---|
| **卦象** | 三爻全阳 |
| **基本象** | 天 |
| **核心特征** | 一个事物**最为关键、最为核心**的部分 |
| **象征** | 自然界的规律、人体的头、社会的"一国之君"、家庭的"一家之主" |
| **人伦** | **父亲** |

> 视频原话:"有时候人们会称呼自己的领导为头,就是因为领导和头都是同一卦象的内容。"

> **小八卦**:为何乾卦代表父亲而非母亲?伏羲氏之前是母系社会;伏羲氏建立父系社会后,固定父亲血缘关系 → 把父亲放到乾卦重要位置。

### 兑(duì)— 泽

| 维度 | 内容 |
|---|---|
| **卦象** | 上一爻阴,下两爻阳 |
| **基本象** | 沼泽地的泽 |
| **象征** | **开口的事物**(杯子、嘴巴);沟通、愉悦快乐 |
| **负面** | 缺口 = 不完美、破损、口舌 |
| **人伦** | 少女 |

### 离(lí)— 火

| 维度 | 内容 |
|---|---|
| **卦象** | 上下两阳爻,中间一阴爻(离中虚) |
| **基本象** | 火 |
| **特征** | **外阳内阴**(像火焰外焰温度高,内焰温度低) |
| **象征** | 乌龟/虾等带壳软体动物;古代盔甲;一切视觉美丽漂亮的东西 |
| **人伦** | 中女 |

### 震(zhèn)— 雷

| 维度 | 内容 |
|---|---|
| **卦象** | 上两阴爻,下一阳爻 |
| **基本象** | 打雷的雷 |
| **特征** | 上不动下动,像地震 |
| **象征** | 生命力、行动力;种子在泥土下生长;人的双脚移动 |
| **人伦** | 长男 |

### 巽(xùn)— 风

| 维度 | 内容 |
|---|---|
| **卦象** | 上两阳爻,下一阴爻 |
| **基本象** | 风 |
| **特征** | 下方不动上方动;风无影无形、无孔不入 |
| **象征** | 信息的传播效应 |
| **人伦** | 长女 |

### 坎(kǎn)— 水

| 维度 | 内容 |
|---|---|
| **卦象** | 上下两阴爻,中间一阳爻 |
| **基本象** | 水 |
| **特征** | 两边阴爻不动像河岸,中间阳爻动像流水 |
| **象征** | 河流;旋转 90°就是"水"字原型;危险(难以逾越的鸿沟叫"一道坎") |
| **延伸** | 轮船/汽车等交通工具 |
| **人伦** | 中男 |

### 艮(gèn)— 山

| 维度 | 内容 |
|---|---|
| **卦象** | 上一阳爻,下两阴爻 |
| **基本象** | 高山 |
| **特征** | 阴爻代表大地,上阳爻表示凸起的山峰;**象征阻碍** |
| **象征** | 山高路远;"关一山就是这个原因";门(阻隔室内外);狗(阻止陌生人靠近) |
| **人伦** | 少男 |

### 坤(kūn)— 地

| 维度 | 内容 |
|---|---|
| **卦象** | 三爻全阴 |
| **基本象** | 大地 |
| **特征** | 犹如完全不动的大地;**有分散和众多的意思** |
| **人伦** | 母亲 |

## 六、先天八卦 vs 后天八卦 ⭐⭐⭐ (0:58:04)

### 先天八卦(伏羲八卦)

> 来源《易经·说卦传》:"天地定位,山泽通气,雷风相搏,水火不相射,八卦相错。"

| 特征 | 说明 |
|---|---|
| **表达** | 宇宙最初的样子 |
| **结构** | 上方天(乾),下方地(坤);左边离卦(太阳升起),右边坎卦(月亮升起) |
| **视角** | **竖起来观察世界** |
| **内容** | **只论阴阳,不论五行** |
| **排列** | 按乾一、兑二、离三、震四、巽五、坎六、艮七、坤八的顺序呈 S 型 |
| **特点** | 相互对立的两个卦象刚好一阴一阳,先天数相加等于 9 |
| **讲究** | **阴阳对待**,动态平衡 |
| **使用** | 实际应用很少(先天为体) |

### 后天八卦(文王八卦)

> 来源《易经·说卦》:"帝出乎震,齐乎巽,相见乎离,致役乎坤,说言乎兑,战乎乾,劳乎坎,成言乎艮。"

| 特征 | 说明 |
|---|---|
| **内容** | 包含阴阳 + **五行** + **时间** + **空间** |
| **视角** | **平行于地面的视角**观察四面八方 |
| **讲究** | 五行能量的流通 |
| **使用** | **大量使用**(后天为用) |

### 八卦方位 vs 通用地图方位 (1:01:22)

> 很多学员会问为什么八卦图跟现在通用的地图方位不一致。

- **八卦图**:**上南下北**(坐北朝南视角)
- **通用地图**:上北下南
- 两者是**180°倒转**,其实**并不矛盾,只是观察视角的不同**
- 皇帝自古坐北朝南,所以图纸以皇帝视角绘制:前方南方 → 离卦

> **视频原话**: "这些所有的追求,最终围绕着一个关键的东西,那就是**健康**。没有健康,一切都化为乌有。"

**为什么东方代表事业?**
- 东方震卦是春天的树木 → 事业是生根发芽不断发展的

**为什么西方代表财富?**
- 西方兑卦是秋天的果实 → 财富需要收获和积累
- 很多城市的财神庙建在**西方或西北方**
- 家里财神应放在**西方或西北方**
