## 二、四灵兽格局的判断标准 ⭐⭐⭐ (2:23:46)

> **视频原话**: "四灵兽格局也就成了风水学的一个重要的应用模块。"

### 核心判断标准 — 四不可失

| 标准 | 含义 |
|---|---|
| **不可缺失** | 四方不可有空,缺一即破 |
| **不可逼压** | 周围建筑/山体不能过高压迫,否则出不孝子孙 |
| **环抱有情** | 四方环绕朝向主体,形成"山环水抱" |
| **龙虎平衡** | 左青龙 vs 右白虎要平衡(青龙宜稍高) |

> **视频原话**(0:29:21): "**宁可青龙高万丈,不可白虎高一寸**。"

### 各方位具体要求

**青龙(左)**:
- 宜**高耸、环抱**
- 青龙宜高于白虎(阳贵)

**白虎(右)**:
- 宜**低伏、不可压青龙**
- 白虎高于青龙 = 阴气过重

**朱雀(前)**:
- 宜**开阔、明堂**
- 前方要宽敞,有明堂聚气

**玄武(后)**:
- 宜**靠山、稳定**
- 后方要有支撑

## 五、罗盘基础 (2:39:33) ⭐

> 罗盘是**地理师的尺子**,三盘合一,综合性强。

### 罗盘的三种主要类型

| 类型 | 用途 |
|---|---|
| **三元盘** | 天盘 — 用于三元(天元、地元、人元) |
| **三合盘** | 人盘 — 用于三合(龙穴砂水向) |
| **综合盘** | 地盘 — 综合多种 |

### 罗盘的核心功能

- **定向**:测量建筑物的方位
- **立向**:确定主体建筑的朝向
- **消砂纳水**:判断周围砂水格局
- **飞星**:九宫飞星计算流年飞星

## 六、罗盘的使用原则 ⭐⭐⭐ (2:46:03)

> **视频原话**: "**可以在人常待的位置获取纳气**。"

### 大太极 vs 小太极

**大太极**:整栋建筑的中心(房子平面几何中心)
**小太极**:房间的中心(单个房间的几何中心)

> 不同太极下,罗盘测量的方位不同。

### 测量的关键位置

| 位置 | 测量目的 |
|---|---|
| **床的正中央** | 房间太极点 → 判断摆设物品是否合适 |
| **煤气灶台** | 健康相关 → 测量灶台纳气 |
| **神像** | 象征主人自己 → 测量神像纳气 |
| **书桌/办公桌** | 事业相关 → 测量办公纳气 |

### 罗盘测量的注意事项

> 视频原话:"我们要离这个灶台稍微远一点,因为它有一些**金属的成分**,可能会对我们的罗盘产生干扰。"

1. **避开金属干扰**:远离金属物体(灶台、金属家具等)
2. **避开木质干扰小**:木制品(如柜子)对罗盘准确性影响不大
3. **校准水平仪**:使用前先校准水平
4. **指针重叠**:等指针稳定重叠后再读取

## 七、罗盘测量实操案例 (2:51:32)

### 卧室案例

> "床的正中央下罗盘 → 房间太极点 → 根据卦位判断摆放物品是否合适。"

**示例判断**:
- **乾卦位**有灯 → 灯对乾位不利
- 同一位置有水晶球 → 水晶球对乾位有帮助
- **兑卦位**有镜子 → 镜子在兑位没有太大问题
- **震卦位**没有挂电视机 → 没有太大问题
- 假如震卦位挂了电视机 → 就不太好了

### 厨房案例

> "煤气灶台关系到一家人的健康,所以也要在这里下罗盘,对灶台的纳气进行测量。"

**示例判断**:
- 窗口纳的是**坎卦位**的气 + 窗口纳**艮卦位**的气 + 内气纳**震卦位**的气
- 结论:**纳的气比较杂**
- 应避免坎卦位的气,改收艮卦位的气

### 神像案例

> "神像代表主人自己,它的位置也是我们着重的考量。"

**示例**:
- 做有向卯的朝向
- 外气纳**东北方艮卦**的气 + 内气纳**南方离卦**的气

## 八、罗盘抗风水的方法(总结)

> **视频原话**: "这就是罗盘看风水的方法。"

**核心步骤**:
1. **定太极点**(大太极 / 小太极)
2. **校准水平仪**
3. **下罗盘**,等待指针重叠
4. **读取卦位**(避开金属干扰)
5. **分析纳气**(外气 + 内气)
6. **判断吉凶**
