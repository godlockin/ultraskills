## 一、五大常见外煞 ⭐⭐⭐

### 1. 路冲 (3:03:15)

**定义**:周围有直路正对或斜对主体建筑,道路产生的气流对主体建筑产生冲击。

**杀伤力**:
- 轻则口角是非、破财
- 重则**手术、车祸、血光之灾**,甚至**性命之忧**

**杀伤力判断参数**:
| 条件 | 影响 |
|---|---|
| 冲射道路**越长** | 影响**越大** |
| 冲射道路**越直** | 影响**越大** |
| 冲射道路**越窄** | 影响**越大**(所有气流集中压缩在一点) |
| 道路宽度 > 主体建筑面宽 | 不算路冲,反而可看作宽广明堂 |
| 道路旁有建筑物/行道树/绿化带 | 路冲**更强**(气流被收束) |
| 道路两边空旷 | 路冲**减弱**(气流被风吹散) |
| 车辆行驶**越快** | 路冲**越大** |
| 道路有**斜坡** | 路冲**更大**(坡度越大,杀伤力越大) |
| **正冲** > 斜冲 | 冲击力更大 |

**真实案例**(3:03:36):
- 一栋别墅刚好建在小区的出入口,正对大门的第一栋
- 对面正对一条好长的巷子
- **前后换了十任主人,没有一家居住时间超过一年**
- 装修很豪华但都很快卖掉了

**化解方法**:
- ⚠️ **住宅遇到路冲 → 别想着化解,赶紧搬走**(住家犯路冲凶多吉少)
- 商业用房带路冲:处理得当也许还能赚钱
  - 看路冲从哪个方位冲过来
  - **西方/西北方/东北方/正南方(旺气方)**:路冲可勉强用
  - **北方/东方/东南方/西南方(衰气方)**:凶上加凶,不能再用

**六种化解方法**(徐老师音频节目):
1. **转移法**:能转移就转移
2. **遮挡法**:用物品遮挡(一排树、竹林、水池、墙)
   - 注意气墙与主体建筑要保持距离(紧贴无效)
   - 民间用"**泰山石敢当**"化解
3. **卸力法**:退让空间(明堂越大越能卸力)
4. **缓冲法**:内部设大堂(酒店大堂)
5. **辅助法**:背后玄武方有结实建筑 + 左右有龙虎沙
6. **转化法**:把煞气转化为吉气

> 视频原话:"好像面对一个高速飞过来的棒球,只要我们戴上厚厚的手套,就可以轻松地接住它,**把煞气转化成为我所用的吉气,生意可能还不错呢**。"

**路冲影响的楼层**:
> "道路与河流形成的路冲反弓等外煞,**对三层楼以下的居住者影响巨大,但是对三层楼以上的居住者,影响就越来越小**。"

### 2. 反弓煞 (3:07:55)

**定义**:道路或河流**反背**于主体建筑而去,像一张弓对着主体建筑。

**不好的三大原因**:
1. **反背是无情的形态**(山飞水走)— 有凶的感应
2. **反弓让明堂空间变小**,纳气能力变弱
3. **自然灾害经验**:古代洪水泛滥时,河堤缺口多在弯曲顶端(河水冲刷外弯);现代车辆失控也多在弯道顶端

**对应凶煞**:
- 家中:**人心涣散**
- 企业:**留不住员工**、**被盗窃诈骗损失钱财**
- 严重:**意外血光之灾**

**化解**:跟路冲差不多 → 走、挡、退 / 用凹形与凸反弓相合 / 河道加盖板

### 3. 剪刀煞 (3:09:28)

**定义**:两条路斜着交叉,形成 Y 字形或 X 形交叉口,呈锐角(<90°),形状像张开的剪刀口。主体建筑处在刀口的三角形区域。

**杀伤力**:
- 剪刀煞 = **路冲 + 三角火形**的能量
- 口角是非,桃色意外
- 严重:**血光意外 + 火灾**

**真实案例**(3:09:56):
- 一朋友小区内两条道路在住宅前方交汇,合成一条大路通向小区外部
- 犯了剪刀煞
- 刚买新车没几天 → 把一个老头撞进了医院,赔了不少钱
- 房屋前方是**下坡路** → 他撞别人
- 假如是**上坡路** → 可能别人撞他

### 4. 壁刀煞 (3:10:33)

**定义**:主体建筑物被周围建筑物的**山墙面**切到,像被刀砍到一样。

> ⚠️ 注意区别:**壁刀煞 = 墙壁直直冲过来**,**尖角煞 = 45° 墙角冲过来**(两种不同的外煞)。

**原理**:空气流动遇到阻碍,改变方向之后产生冲击力。**室内也会壁刀煞**(墙体拐角冲射)。

**杀伤力**:
- 轻则口舌争斗、官非破财、肌肉疼痛/萎缩
- 重则手术开刀、意外车祸

**真实案例**(3:11:23):
- 某施工现场的板房对面有一座新建的板房
- 对面板房建成后,一位工程师在办公室门口突然身体打颤摔倒在地
- 佩戴的眼镜破碎后把脸扎了一个大口子,缝了好多针
- 原因:对面板房**山墙**刚好切到我方建筑物中心靠左一点位置
- → 左脸受伤,与推断完全一致

**杀伤力判断参数**:
| 条件 | 影响 |
|---|---|
| 距离壁刀**越近** | 影响**越大** |
| 距离 **30m 以内** | **特别严重** |
| 距离 **> 100m** | 几乎**无影响** |
| 壁刀**长度越长**(山墙越宽) | 影响越大 |
| 壁刀后方有其他建筑物挡住 | 凶性**减弱** |

**选择方法**:
- 选择建筑布局排列整齐的小区
- 如果建筑物之间没对齐、山墙面错开 → 容易产生壁刀煞

**化解**:
- 改门改窗(壁刀劈门窗比劈墙壁更严重)
- 正对壁刀的窗户关上
- 人不处在正对壁刀的位置
- 放一颗较大的鹅卵石

### 5. 天斩煞 (3:13:54)

**定义**:两个建筑物之间形成的又窄又长的缝隙,如果主体建筑面对这样的缝隙就是犯了天斩煞。

**原理**:两边建筑挤压中间空气,使其流动速度变快,产生一个非常强烈的气流。

**相当于**:传统风水的**凹风**,现代城市中的**高楼风**。

**杀伤力**:
- 破坏力非常可怕,可理解为**两个壁刀煞一起砍过来**,有时还带一个路冲
- 居住者性情**暴躁、情绪不稳定**
- 身体上:**不孕不育、损人丁**

**杀伤力判断**:
| 条件 | 影响 |
|---|---|
| 距离**越近** | 杀伤力**越大** |
| 天斩缝**越小** | 杀伤力**越大** |
| 天斩自身建筑**越高** | 力量**越大** |
| 天斩缝**后有其他房子阻拦** | 杀伤力**减弱** |
| 距离 > 天斩建筑高度 2 倍以上 | 负面影响**可忽略** |
| 两栋楼之间夹角 > 45° | 不算天斩煞 |

**化解**:
> "像天斩煞这种比较严重的外煞,**我们就不要想着去化解了,因为没有办法可以完全避免凶祸的发生,还是赶紧撤离吧**。"

### 6. 其他外煞 (3:15:36)

> "外煞的类型很多,大大小小的各种外煞可能有几十种。比如说还有**四余煞**,就是环境中出现的一些多余的小东西。"

> "其实很多的外煞都是前面提到的这几种主要外煞的组合与变形而已。"

## 二、外煞的应事推断 (3:15:59)

> **视频原话**: "对于风水的判断,除了吉凶定性之外,还必须做到**应事**。**应人、应期,三点定量**的推断,把环境中的时间、人物和事件的信息给挖掘出来。"

> "风水外煞所带来的负面影响**并不是随时随地发生的,也不是对任何人都产生同样的影响**。"

### 应事(什么事)推断

| 外煞位置 | 可能的事件 |
|---|---|
| 路冲在**东方震卦** | **车祸、人员伤亡** |
| 路冲在**东南巽卦** | **桃色事件、自杀** |
| 路冲在**北方坎卦** | **小人暗算、口舌官非** |
| 路冲在**正南方离卦** | 心脏、眼目相关 |
| 外煞在**震卦** | 肝脏手术 |
| 外煞在**艮卦** | 胃部手术 |

**结合四灵兽**:
- **朱雀方(前)**外煞 → 受伤部位在**前面**(脸部),事情在**外部**,他人伤害
- **玄武方(后)**外煞 → 受伤部位在**背面**(脊椎),事情在**内部**,自己原因

### 应人(谁)推断

**第一种方法 — 粗略**(四灵兽阴阳):
- 左边 = 男性,右边 = 女性
- 后边 = 男性,前边 = 女性

**第二种方法 — 八卦宫位**:
- 外煞在**兑卦位** → 受伤害的是**少女**
- 外煞在**坤卦位** → 受伤害的是**老母亲**
- 其他卦位以此类推

**第三种方法 — 八卦 + 六亲 + 排行 综合**(最准确):

**示例**:建筑物正前方有外煞,在南方离卦位
- 前方代表**女性**
- 前方是六亲中的**子孙位** → 伤到家中的**晚辈**
- 正前方排行的人物是**老二**
- 离卦对应的人物是**中女**
- 综合推断:**最容易受伤害的是家中的二女儿**

**特殊应人**:从事不同行业的人面对相同外煞,吉凶不同
- 医院医生 / 美容院美发师:职业本身要见血光、动刀,**剪刀煞对他们是正常现象**,反而生意更好
- 但流年年期一到,也会发凶

### 应期(时间)推断 ⭐⭐⭐

> "要判断应期,也就是吉凶发生的时间,我们就需要用到后天八卦图。**根据外煞所在的二十四山的地支方位,我们就可以判断在哪一年会发生凶险**。"

**地支对应年份(生肖)**:
- 外煞所在地支的**本字**年份(冲射到的地支)
- 外煞所在地支的**对冲**地支年份(六冲)

**示例**:
- **申位有路冲** → 猴年(申年)容易发生凶险
- 申的对冲 = **寅**(虎年),寅参(虎)申冲 → 虎年同样容易发生凶险
- 路冲在北方**子位** → 鼠年(子年)容易发生凶事,2008 年子年可能发生过意外
- 假如路冲一直在,未来 2032 年鼠年(子年)类似意外还会如期而至
- 子对冲 = **午**(马年),马年也有相当大概率发生意外

**应人延伸到生肖**:
- 如果家中对应有**属鼠、属马**的人 → 这两个生肖人发生凶险的概率比他人高

**应期延伸到时辰**:
| 壁刀出现在地支 | 凶险时间 |
|---|---|
| **卯、辰** | **上午** |
| **巳、午** | **中午或下午** |
| **申、酉** | **下午** |
| **亥、子** | **夜晚** |
