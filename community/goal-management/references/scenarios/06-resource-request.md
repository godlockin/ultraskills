# 场景 06 · 资源申请(向领导要人/要钱/要时间)

## 触发

- 项目需要加资源
- 现有资源不够
- 想争取预算
- 需要跨部门借调
- 需要老板支持

---

## 4 类资源申请

| 资源类型 | 申请对象 | 关键 | 难度 |
|---|---|---|---|
| **加 1 人** | 领导 / HR | 算 ROI | 中 |
| **加预算** | 领导 / 财务 | 算回报 | 中高 |
| **加时间** | 客户 / 领导 | 解释影响 | 低 |
| **跨部门借调** | 兄弟部门 / 领导 | 找双赢 | 高 |

---

## 5 步申请流程

### Step 1 · 算清楚"为什么要"

**不清晰就开口 = 被秒拒**。

**必带 3 件**:
1. **现状**:现在有什么,缺什么
2. **影响**:不补的话,后果是什么(具体数字)
3. **方案**:要多少,投入产出怎么算

### Step 2 · 算投入产出(ROI)

#### 加人 ROI 计算

```
投入:
  - 人力成本: [X] 万/月
  - 培训成本: [Y] 万(一次性)
  - 管理成本: [Z] 万/月(占用管理时间)
  - 总投入 = X+Y+Z

产出:
  - 直接产出: [指标] 增量
    - 例:BD 月新增客户 +10,客单价 5 万,毛利 30%
    - 月增营收 = 10 × 5 × 0.3 = 15 万
  - 间接产出: [指标] 改善
    - 例:客户响应时间从 4h 降到 1h,流失率 -2pp
    - 年增收:留存客户 × 客单价 × 2% = 200 万

投资回收期:
  - 月增产出 15 万 → 1.3 月回本
  - 推荐!
```

#### 加预算 ROI

```
投入: 加 X 万预算投 SEM/SEO/活动

预期产出:
  - 流量 +Y%
  - 转化率 [Z]%
  - 客单价 [W]
  - 预期新增订单 = 流量 × 转化率 / 客单价

ROI = 预期产出 / 预算投入
    - 行业基准:SEM 1:3-1:5,内容 1:5-1:10
    - 低于基准 = 优化后再说

回收期: 加预算当月回本 = 优秀
```

---

### Step 3 · ART 三角沟通

**不要直接说"我需要"**:

```
❌ "老板,我需要加 1 个人"(被拒率高)

✅ "老板,这个项目有 3 种方案:
   - 方案 A: 加 1 人,达成 [目标],投入 [X 万/月]
   - 方案 B: 现有团队,达成 [降级目标]
   - 方案 C: 延后 [Y 天],达成 [目标]
   
   我建议方案 A。理由是 [关键 ROI]"
```

---

### Step 4 · 准备反对意见 Q&A

**提前想老板会问什么**:

| 老板可能的问题 | 你的回答 |
|---|---|
| "能不能不加人,加班搞定?" | "我们已测算,加班只能补 20%,且不可持续。" |
| "现有团队不能承担吗?" | "现有团队已满负荷 [X] %,无法再承担。" |
| "为什么要花这笔钱?" | "ROI 是 1:5,3 个月回本。" |
| "为什么是现在?" | "错过 [时间窗口 X],损失 [Y 机会]。" |
| "能先小步试吗?" | "可以,先试 [X] 万,1 月后看数据决定是否追加。" |
| "其他部门能支援吗?" | "已沟通过 [X 部门],他们 70% 满负荷,可借调 20% 时间。" |

---

### Step 5 · 留痕 + 后续追踪

**沟通后 24h 内邮件确认**:

> "[会议] 资源申请确认:
> 1. 申请事项: 加 1 名 BD
> 2. 投入: [X] 万/月
> 3. 决策: [领导同意 / 暂缓 / 拒绝 / 修改方案]
> 4. 后续: [Y] 前提交 [详细计划]
> 5. 效果评估: [Z] 月后复盘"

**资源到位后**:
- 立即建立追踪指标
- 月度汇报使用情况
- 季度评估投入产出

## 跨部门借调协议

### 关键困难

- 兄弟部门往往不愿意放人(人手也紧)
- 必须找到**双赢点**

### 双赢策略

```
你的需求: 借调 X 部门 Y 人 2 周

X 部门的痛点:
  - A: 人手紧
  - B: 团队技术成长慢
  - C: 缺业务视角

你的 offer:
  - 短期: 帮他们顶 1 周的活(互换)
  - 中期: 帮他们做 1 个项目(让他们有亮点)
  - 长期: 共享成果(联合署名/联合 KPI)
```

### 沟通模板

> "[X 部门领导],我有个项目想请你支援 [Y] 人 [Z] 周。我知道你部门也紧,所以我准备:
> - [offer 1]: 我们部门 [某人] 去你部门顶 [任务]
> - [offer 2]: 项目产出联合署名,你部门也能上 KPI
> - [offer 3]: 借调结束后 [某人] 把你部门 [某流程] 优化一遍
>
> 整体看是双赢。能否聊 15 分钟对齐一下?"

## 资源被拒怎么办?

### 4 个台阶

```
台阶 1 · 找数据
  - 重新算 ROI,可能之前算错了

台阶 2 · 找替代方案
  - 不要人,要工具(自动化)
  - 不要钱,要合作伙伴(分成模式)
  - 不要钱,要时间(延后但保留目标)

台阶 3 · 找第三方支持
  - 找更高层领导
  - 找跨部门盟友
  - 找外部资源(外包/咨询)

台阶 4 · 接受现实 + 调整目标
  - 资源不够 = 目标要降
  - ART 三角显化:动 A 还是动 T
```

## 输出范式

### 资源申请方案

```markdown
## 资源申请 · [事项]

### 背景
- 当前项目: ...
- 现状: [现在有什么,缺什么]
- 影响: 不补的话,后果 = [具体损失]

### 申请内容
- [人 / 钱 / 时间 / 借调]
- 数量: ...
- 时长: ...

### 投入产出分析
- 投入: [X]
- 预期产出: [Y]
- ROI: [Y/X]
- 回收期: [Z 月]

### ART 三角方案
- 方案 A(推荐): 加资源,达成 [原目标]
- 方案 B: 不加资源,达成 [降级目标]
- 方案 C: 不加资源,延后 [Y 时间]

### 预期反对意见 Q&A
[提前想老板会问的 3-5 个问题]

### 后续追踪
- [日期]: 资源到位
- [日期]: 第一次效果评估
- [日期]: 1 月复盘
```

## 反模式

| ❌ 反模式 | 修正 |
|---|---|
| 不算 ROI 就开口 | 必算 ROI |
| 直接说"我要 X" | 必给 3 方案 |
| 没准备 Q&A | 提前想老板问题 |
| 没后续追踪 | 必留痕 + 追踪 |
| 资源被拒就放弃 | 找替代方案 |
