# 场景 04 · 周/月/季度会议

## 触发

- 周会怎么开
- 月会怎么汇报
- 季度会议怎么高效
- 跨团队会议怎么主持

---

## 周会协议

### 周会四件套(45-60min)

| 段 | 时长 | 内容 |
|---|---|---|
| 1 | 5min | 上周遗留事项过一遍 |
| 2 | 25min | 本周进度 + 风险 + 资源(每人 3-5min) |
| 3 | 15min | 跨团队依赖协调 |
| 4 | 10min | 下周计划 + OKR 进度 |

### 周会议程模板

```markdown
## 周会 · [日期] · [时长]

### 上周遗留
- [ ] [遗留事项 1]: [状态]
- [ ] [遗留事项 2]: [状态]

### 本周进度
[每人 3-5min 报告]
- 张三:本周完成 [X],下周做 [Y],风险 [Z]
- 李四:...

### 风险与依赖
- [风险 1]: 影响 [KR],需要 [谁] 支持
- [依赖]: [X 部门] 需要 [周三] 给 [Y]

### 下周计划
- 关键动作 1
- 关键动作 2

### 下周会议时间
[确认下次周会时间]
```

### 周会 5 大陷阱

| ❌ 反模式 | 修正 |
|---|---|
| 变 1h+ 长会 | 严格 45min |
| 没人准备 | 必发议程 + 提前 1h 提醒 |
| 只报进度不报风险 | 风险前置是周会核心 |
| 老板一言堂 | 让团队自己暴露问题 |
| 没结论 | 每议题必出"下一步" |

## 月会协议

### 月会 vs 周会区别

| | 周会 | 月会 |
|---|---|---|
| 频率 | 每周 | 每月 |
| 关注 | 进度 + 风险 | 目标达成 + 调整 |
| 参与 | 团队 | 部门/跨部门 |
| 时长 | 45-60min | 2-3h |
| 输出 | 下周计划 | 月度报告 + 下月 OKR 调整 |

### 月会议程模板

```markdown
## 月会 · [月份] · [日期] · [时长: 2h]

### 上月目标达成情况
[月度 KPI 表 — 红黄绿三色]

### 重点 OKR 进度
[每个 OKR 当前完成度]

### 重大风险与决策
- [风险 1]: 影响 [OKR],建议 [决策]
- [决策 1]: [需领导裁决]

### 跨部门协调
- [协调事项 1]: [当前状态 + 需支持]
- [协调事项 2]: [...]

### 下月 OKR 调整
- 调整 1: [为什么 + 改成什么]
- 调整 2: [...]

### 资源需求
- 人: [加 X 人 / 借调 Y]
- 钱: [加 Z 预算]
- 协作: [需 X 部门支持 Y]
```

## 主持 5 大原则

### 原则 1 · 议程驱动

> 议程必提前发,**议程外的话题进 parking lot**(留到下次)

### 原则 2 · 时间切割

> 每段时长写进议程,**超时立即停**(移到 parking lot 或下次)

### 原则 3 · 决策与讨论分离

> **会上讨论,会后决策**(除非小决策当场定)

**反模式**: 讨论 1h,决策模糊,下周再讨论 — 永远没结果

### 原则 4 · 风险前置

> 周/月会议必有"风险与依赖"环节

### 原则 5 · 必出 3 件

> 每次会议必出:
> 1. 决策清单
> 2. 行动清单(谁 + 何时 + 做什么)
> 3. 风险清单

## 输出范式

### 周会议程(提前 24h 发)

```markdown
## 周会 · [日期] · [地点] · 45min

### 议程
1. 上周遗留 (5min)
2. 本周进度 (25min)
3. 风险与依赖 (10min)
4. 下周计划 (5min)

### 提前准备
- [每人] 准备本周进度 3 句话(进度/风险/下周)
```

### 周会纪要(24h 内发)

```markdown
## 周会纪要 · [日期]

### 决策
1. [决策 1]
2. [决策 2]

### 行动
- [ ] [谁] 在 [何时] 做 [什么]

### 风险
1. [风险 1] + 应对

### 下次会议
[日期]
```

## 反模式清单

| ❌ 反模式 | 修正 |
|---|---|
| 议程都不发 | 必发 |
| 没有 parking lot | 必有 |
| 超时不停 | 严格停 |
| 风险没人说 | 强制每人报 |
| 没决策没行动 | 必出 3 件 |
| 老板占 80% 时间 | 控制老板发言 |
