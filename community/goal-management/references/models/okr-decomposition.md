# OKR 拆解 · 完整说明

## 一句话核心

> **Objectives + Key Results** — O 定方向,KR 量化结果,层层对齐。

---

## O vs KR 区别

| | Objective 目标 | Key Results 关键结果 |
|---|---|---|
| **是什么** | 定性方向(我要去哪儿) | 量化结果(怎么算到了) |
| **特点** | 有野心、模糊、激励 | 可量化、有时限、可验证 |
| **数量** | 1 个 O | 3-5 个 KR |
| **例子** | "打造华南区最有影响力的 SaaS 品牌" | KR1: 6 个月内付费用户从 1k → 5k / KR2: NPS 从 35 → 50 / KR3: 媒体提及从 50 篇/月 → 200 篇/月 |

---

## 3 层 OKR 嵌套

```
公司 OKR
    │
    ├── 部门 OKR(对齐公司,加本部门特色)
    │
    └── 个人 OKR(对齐部门,加个人成长)
```

**对齐规则**:
- **下层 70% 服务上层 + 30% 自有** — 完全对齐失去活力,完全不相关失去战略
- **公开透明** — 全员可见,横向拉通
- **季度评估** — 不年终打分

---

## OKR 拆解流程

```
1. 先定 O(方向性,1 句话)
     ↓
2. 列 5-10 个潜在 KR(发散,不评判)
     ↓
3. 用 SMART 筛 3-5 个(必出物:量化+时限+可验证)
     ↓
4. 用 80/20 找关键 3 个 — 太多 KR 反而失焦
     ↓
5. 给每个 KR 配 Initiative(主动动作,1-3 个)
     ↓
6. 风险评估 — 每个 KR 找 1 个最大风险 + 预案
```

## 季度化 OKR 范式

### 案例 · 年目标 → 季度拆分

```
公司年度 O: "成为华南区 SaaS 第一"
年 KR:
  - 付费用户 1k → 10k(增长 10x)
  - NPS 35 → 60

Q1 OKR:
  O: 完成 MVP 验证 + 启动付费转化
  KR1: 完成 200 个种子用户(试用 30 天以上)
  KR2: 付费转化率 2%(免费→付费)
  KR3: 留存率 60%(30 日)

Q2 OKR(假设 Q1 OK):
  O: 加速增长 + 优化获客成本
  KR1: 付费用户 200 → 1k
  KR2: CAC < 500 元
  KR3: 月留存 70%

Q3 OKR:
  O: 拓展新渠道 + 准备规模化
  KR1: 付费用户 1k → 4k
  KR2: 新增 2 个渠道(占比 30%)
  KR3: 团队扩到 20 人

Q4 OKR:
  O: 实现盈亏平衡 + 区域第一
  KR1: 付费用户 4k → 10k
  KR2: 月营收 200 万
  KR3: 华南市场份额第一(Gartner 报告)
```

## OKR vs KPI 区别

| | OKR | KPI |
|---|---|---|
| **本质** | 挑战型(0.6-0.7 完成算成功) | 承诺型(必须达成) |
| **频度** | 季度 | 月度/周度 |
| **失败容许** | 鼓励失败中学习 | 不容许失败 |
| **适用** | 增长、创新、突破 | 运营、合规、交付 |
| **数量** | 1O + 3-5 KR | 5-10 个 |

**混用范式**:
- 销售团队 — KPI(销售额) + OKR(新渠道增长)
- 运营团队 — KPI(DAU/留存) + OKR(新玩法创新)
- 研发团队 — KPI(交付率/质量) + OKR(技术突破)

---

## OKR 评分制度

| 得分 | 含义 | 后续 |
|---|---|---|
| 0.0-0.3 | 严重未达成 | 复盘原因,可能目标失真 |
| 0.4-0.6 | 部分达成 | OK,挑战型正常 |
| 0.7-0.9 | 大部分达成 | 标准成功 |
| 1.0 | 100% 达成 | **目标可能太简单** — 下季度加码 |
| > 1.0 | 超额 | 优秀,但下季度要更激进 |
