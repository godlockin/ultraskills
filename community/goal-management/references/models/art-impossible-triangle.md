# ART 不可能三角 · 完整说明 ⭐

## 一句话核心

> **A(目标)/ R(资源)/ T(时间) — 三者必舍一**。任何和领导谈资源/时间/目标的调整,必须显化三角,逼领导二选一。

---

## 为什么"不可能三角"存在?

```
        目标(A)
         /\
        /  \
       /    \
      /      \
     /________\
   资源(R)   时间(T)
```

**本质**: 固定 2 个,第 3 个必然让步。

- **目标 + 资源固定** → 时间必须延长
- **目标 + 时间固定** → 资源必须追加
- **资源 + 时间固定** → 目标必须下调

没有"既要又要还要"。**任何"我都要"的方案 = 失败方案的种子**。

---

## 3 套标准方案

### 情景 1 · 目标不动

```
   A: [原始目标,不变]
   R: [追加资源,人/钱/协作]
   T: [维持原时间]
```

**适用**: 战略目标硬性,不能动(老板的老板要看)

**代价**:
- 资源加倍(从团队外调人 / 加预算 / 跨部门借力)
- 团队过载风险(必须考虑可持续性)

**沟通话术**:
> "目标 [X] 我们接受,但需要 [具体资源: 加 2 人 / 加 30 万预算 / 借调 X 部门 1 人 2 周] 才能在 [时间] 完成。请确认能否支持。"

---

### 情景 2 · 资源不动

```
   A: [保持主目标,缩小范围 / 降级]
   R: [维持现有,不加人]
   T: [维持原时间]
```

**适用**: 资源已紧绷(团队满负荷 / 预算冻结)

**代价**:
- 目标降级(从 100% 完成变成 70% 完成)
- 必须明确降级的部分

**沟通话术**:
> "在现有资源下,如果保持 [时间],只能做到 [降级目标 Y]。具体放弃/降级的部分: [明确列出]。是否可以接受?"

---

### 情景 3 · 时间不动

```
   A: [维持原目标]
   R: [维持现有]
   T: [延后 X 天/周/月]
```

**适用**: 时间窗口可调(非关键 deadline)

**代价**:
- 错过预期时间(可能影响后续依赖)
- 领导可能失去耐心(必须解释清楚)

**沟通话术**:
> "保持 [目标] 和现有 [资源],完成时间需要从 [原时间] 延后到 [新时间],原因是 [具体原因]。延后的代价: [影响后续 X / 失去 Y 时机]。是否可以接受?"

## 4 步应用流程

### Step 1 · 显化当前三角

```
当前状态:
  A(目标): [原目标]
  R(资源): [现有资源]
  T(时间): [原时间]
```

### Step 2 · 识别瓶颈

- 是目标太激进?→ 动 A
- 是资源不够?→ 动 R
- 是时间太紧?→ 动 T
- **多数情况是 3 者都紧** → 必须做 trade-off

### Step 3 · 提出 3 个方案

```
方案 1: [保持 A+R,延长 T] — 资源够,接受延期
方案 2: [保持 A+T,追加 R] — 资源可借调/追加
方案 3: [保持 R+T,缩小 A] — 降级目标
```

### Step 4 · 让领导选 + 留痕

```
领导选定: 方案 [X]
理由: [简要说明]
时间: [决策日期]
留痕方式: 邮件确认 / 会议纪要 / 系统记录
```

## 跨部门 ART 协议

同事甩活过来,用 ART 三角回应:

### 模板话术

> "这件事我可以做,但 [主公当前手上有 X 件事]。你看我们要调整哪个:
> - 选项 A: 这件事的 [目标/范围] 缩小到 [Y]
> - 选项 R: 这件事的 [资源/时间] 增加到 [Z],从 [谁] 来
> - 选项 T: 这件事的 [deadline] 延后到 [新时间]
>
> 或者这件事 [整体重要性判断],可能优先级比 [我手上的某件] 还低。"

**为什么这样**:
- 不直接拒绝(显得不合作)
- 但逼对方做 trade-off(避免默认承接)
- **默认承接 = 默认背锅**(R6 协议)

## 4 大陷阱

### 陷阱 1 · 三角都没显化

> ❌ "我可能做不完"(模糊抱怨)
> ✅ "保持目标 X 和资源 Y,需要延后 Z 时间;或者保持 X 和 Z,需要追加资源 W"

### 陷阱 2 · 自作主张调三角

> ❌ 自行决定降低目标(没和领导沟通)
> ✅ 先沟通再调整 — **任何调整都要书面确认**

### 陷阱 3 · 把"加班"当资源

> ❌ "我们加点班就能做完"
> ✅ 加班是临时手段,长期不可持续;**真正资源 = 加人 / 加钱 / 加协作**

### 陷阱 4 · "都要"的虚假方案

> ❌ "我加班加点 / 团队想办法"(没说动哪个)
> ✅ 明确动哪个 + 留痕

---

## ART 与 PDCA 配合

- **PDCA 的 Plan** — 包含 ART 三角的初始设定
- **PDCA 的 Check** — 检视三角是否失衡
- **PDCA 的 Act** — 调整三角 + 留痕
