# PDCA 循环 · 完整说明

## 一句话核心

> **Plan → Do → Check → Act** — 4 步闭环,每步必出物,持续迭代。

---

## 4 步详解

```
   ┌──────┐
   │ Plan │ ← 制定计划
   └──┬───┘
      ↓
   ┌──────┐
   │  Do  │ ← 执行
   └──┬───┘
      ↓
   ┌──────┐
   │Check │ ← 检视
   └──┬───┘
      ↓
   ┌──────┐
   │ Act  │ ← 行动(标准化/调整)
   └──────┘
      │
      └→ 回到 Plan(下一轮)
```

---

## 每步必出物

| 步 | 输入 | 必出物 | 失败信号 |
|---|---|---|---|
| **P** Plan | 上一层目标 | 行动计划 + KPI + 责任人 + 时间表 | 没量化 / 没责任人 |
| **D** Do | Plan | 执行结果 + 过程数据 | 没数据记录 |
| **C** Check | Do 结果 | 偏差分析 + 根因 | 只看完成度不看根因 |
| **A** Act | Check 结论 | 标准化 / 调整计划 | 没沉淀 / 没调整 |

---

## Plan(计划)

### 5W2H 框架

| 维度 | 问题 |
|---|---|
| **What** | 做什么?具体目标 |
| **Why** | 为什么做?目的 |
| **Who** | 谁做?责任人 |
| **When** | 何时做?起止时间 |
| **Where** | 在哪做?范围 |
| **How** | 怎么做?方法 |
| **How much** | 多少?量化指标 |

### SMART 目标设定

参考 `smart-principles.md`。

### 风险预案

每个 Plan 必带 1-2 个预案。

---

## Do(执行)

### 执行原则

- **按计划执行**(不偏离)
- **过程数据记录**(为 Check 准备)
- **暴露问题**(不掩盖)
- **小步快跑**(快速迭代)

### 执行检查点

- **周检查**:目标进度 50% 时间点是否达成 50% 进度?
- **关键里程碑**:里程碑达成 / 偏差
- **紧急问题**:异常处理(找上级/调整)

### 反模式

- ❌ 埋头做不汇报 → 进度不透明
- ❌ 边做边改计划 → 没计划性
- ❌ 不记数据 → Check 无据可查

---

## Check(检视)

### 4 类检视

| 类型 | 内容 | 频度 |
|---|---|---|
| **目标达成** | KPI 是否完成 | 周/月/季 |
| **过程合规** | 是否按计划/规范执行 | 持续 |
| **问题暴露** | 哪里出问题 | 周 |
| **改进机会** | 哪里可以做得更好 | 持续 |

### 偏差分析

```
实际结果 vs 计划目标
├─ 偏差 > 10%: 找根因(5 Why)
├─ 偏差 5-10%: 微调
└─ 偏差 < 5%: 正常,继续
```

### 5 Why 根因法

```
问题:目标没达成
├─ Why 1: 为什么没达成?(进度落后)
├─ Why 2: 为什么落后?(资源不足)
├─ Why 3: 为什么资源不足?(原计划漏估)
├─ Why 4: 为什么漏估?(没参考历史数据)
└─ Why 5: 为什么没参考?(Plan 流程缺这一步)
→ 根因: Plan 流程缺历史数据参考
→ 改进: 下次 Plan 必须先看历史 Velocity/产能
```

## Act(行动)

### 4 类行动

#### 1. 标准化(Standardization)

- 把好做法写进 SOP/Skill
- 让下次能直接复用

#### 2. 调整计划(Adjustment)

- 重新设定目标
- 重新分配资源
- 重新排时间

#### 3. 问题解决(Problem Solving)

- 短期救火
- 长期根因解决

#### 4. 经验沉淀(Knowledge)

- 写进知识库
- 团队分享

### 输出物

- **SOP 更新** — 新流程/工具/模板
- **OKR/KPI 调整** — 下周期目标
- **知识库条目** — 规律沉淀
- **培训/分享** — 团队复制

## PDCA 与其他模型配合

### PDCA × OKR

```
季度 OKR
  └─ 月度 PDCA 循环
      └─ 周度 PDCA 循环
          └─ 日度 PDCA 小循环
```

### PDCA × Sprint

```
Sprint(2 周)
  ├─ Day 0: Sprint Planning = P
  ├─ Day 1-9: Daily Standup + 执行 = D
  ├─ Day 9: Review = C
  └─ Day 10: Retrospective = A
```

### PDCA × ART

- Plan 时:ART 三角设定
- Do 时:动态 ART 平衡
- Check 时:检视三角是否失衡
- Act 时:调整三角 + 留痕

## PDCA 应用场景

### 个人目标管理

```
P: 周计划(每周五)
D: 周执行(周一-周五)
C: 周复盘(每周五)
A: 调整下周计划
```

### 项目管理

```
P: 项目立项书
D: 项目执行
C: 阶段评审 + 里程碑检视
A: 调整计划 + 沉淀经验
```

### 团队管理

```
P: 季度 OKR + 月度计划
D: Sprint 执行
C: 月度 Review
A: 调整 OKR + 优化流程
```
