# GRAI 复盘 · 完整说明

## 一句话核心

> **G(目标) → R(结果) → A(分析) → I(洞察)** — 不追责,只挖规律,让下次更好。

---

## 4 步详解

### G · Goal 回顾目标

**关键问题**:
- 当时的目标是什么?
- 关键里程碑是什么?
- 为什么是这个目标?

**反模式**:
- ❌ "目标就是完成它"(没回溯原始意图)
- ✅ "目标是把新客从 50/月 提到 150/月,核心假设是 SEO 渠道 ROI 2.0+"

### R · Result 评估结果

**对比**:
| 维度 | 计划 | 实际 | 偏差 |
|---|---|---|---|
| 量化指标 1 | X | Y | Z% |
| 量化指标 2 | ... | | |
| 关键里程碑 | ... | | |
| 时间 | ... | | |
| 资源使用 | ... | | |

**关键**:
- 数据驱动,不靠感觉
- 不解释原因(原因放在 A)

### A · Analysis 分析过程

**维度**:
- **做的好的** — 为什么做得好?可复制吗?
- **做的不好的** — 为什么做得不好?根因是什么?
- **意外事件** — 哪里出了意外?如何应对?

**工具**:
- 5 Why 根因法
- 鱼骨图(人/机/料/法/环/测)
- 80/20 找关键因素

### I · Insight 提炼洞察

**洞察类型**:
| 类型 | 描述 | 示例 |
|---|---|---|
| **规律** | 可复用的模式 | "新客转化 > 5% 的关键: 第 1 周触达 ≥ 3 次" |
| **反直觉** | 与原本认知相反 | "高客单价客户反而流失率低,因为服务深度高" |
| **边界** | 适用条件 | "渠道 A 只在 [某条件] 下有效" |
| **风险预警** | 早期信号 | "团队连续 2 周加班 > 60h → 流失预警" |

## 4 步时间分配(2h 复盘会)

| 步 | 时长 | 占比 |
|---|---|---|
| G | 15min | 12% |
| R | 30min | 25% |
| A | 60min | 50% |
| I | 15min | 12% |

**关键**: A 占 50% 时间(分析过程),I 短但最重要。

---

## GRAI vs PDCA vs ORID 区别

| | GRAI | PDCA | ORID |
|---|---|---|---|
| 本质 | 事后复盘 | 过程循环 | 焦点对话 |
| 时点 | 项目/周期结束 | 持续 | 任意时点 |
| 关注 | 整体回顾 | 单循环 | 剥洋葱 |
| 输出 | 经验沉淀 | 调整行动 | 共识 + 决定 |
| 主持 | 复盘会 | 项目管理 | 团队对话 |

**实战组合**:
```
项目结束后 GRAI(整体复盘)
  → 沉淀洞察到 PDCA 模板
    → 下一个 PDCA 循环应用
      → 重大决策用 ORID 拉共识
```

## GRAI 主持脚本

### 开场(5min)

> "今天我们复盘 [项目]。不追责,只挖规律。每人发 3 张便利贴,分别写 1 件做得好的 + 1 件做得不好的 + 1 件想改善的。10 分钟后我们一起过。"

### G(10min)

> "我们先回顾原始目标:[展示立项文档]。大家还有印象吗?目标有变化吗?"

### R(20min)

> "现在看结果。计划 [X],实际 [Y],偏差 [Z%]。先列数字,先不解释原因。"

### A(45min) — 重点

> "现在分析为什么。重点讨论:
> 1. 做得最好的 3 件事 — 为什么做得好?
> 2. 做得最差的 3 件事 — 5 Why 根因?
> 3. 哪里出了意外 — 如何应对?效果如何?"

### I(15min)

> "最后提炼洞察。请每个人用一句话写:'下次再做类似项目,我学到的最重要的事是...'"

### 收尾(5min)

> "今天的复盘结论 3 条:
> 1. ...
> 2. ...
> 3. ...
>
> 这些结论会进入知识库,下个项目开始时再回顾。"

## GRAI 5 大陷阱

### 陷阱 1 · 复盘变追责

> ❌ "谁没做好?"(找人背锅)
> ✅ "为什么没做好?"(挖根因)

**规则**: 复盘会上**不写人名**,只写事和规律。

### 陷阱 2 · 流于形式(走过场)

> ❌ 30min 草草过(没深挖)
> ✅ 至少 1.5-2h,有充分讨论

### 陷阱 3 · 只看失败不看成功

> 成功也值得复盘(为什么做得好,如何复制)

### 陷阱 4 · 洞察不沉淀

> ❌ 复盘完写一份报告就完了
> ✅ 洞察进入知识库 + 下次项目开始前回顾

### 陷阱 5 · 复盘后无行动

> ❌ 复盘完不调整下个周期
> ✅ 复盘洞察 → 调整下周期计划 → 监控
