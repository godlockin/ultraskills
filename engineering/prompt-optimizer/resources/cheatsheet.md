## CO-STAR 框架

| 字母 | 含义 | 问自己 |
|:----:|------|--------|
| **C** | Context 上下文 | AI需要知道什么背景？ |
| **O** | Objective 目标 | 我要AI做什么？ |
| **S** | Style 风格 | 用什么风格表达？ |
| **T** | Tone 语气 | 什么情感基调？ |
| **A** | Audience 受众 | 写给谁看？ |
| **R** | Response 响应 | 要什么格式？ |

## 常用增强技巧

### 1️⃣ 角色扮演

```
你是一位拥有15年经验的[领域]专家...
```

### 2️⃣ 思维链

```
请一步步思考：
1. 首先分析...
2. 然后考虑...
3. 最后得出...
```

### 3️⃣ 少样本学习

```
示例1：输入A → 输出B
示例2：输入C → 输出D
现在处理：输入E → ?
```

### 4️⃣ 输出约束

```
要求：
- 使用Markdown格式
- 500字以内
- 包含3个要点
```

### 5️⃣ 反向约束

```
禁止事项：
- 不使用第一人称
- 不给出模糊结论
- 不超过规定长度
```

### 6️⃣ 质量标准

```
好的回答应该满足：
- 逻辑清晰
- 有数据支撑
- 可操作性强
```

## 常见prompt问题诊断

| 症状 | 可能原因 | 解决方案 |
|------|----------|----------|
| 回答太泛 | 目标不够具体 | 添加具体细节和约束 |
| 格式混乱 | 未指定格式 | 明确输出结构模板 |
| 偏离主题 | 缺少上下文 | 补充背景信息 |
| 风格不对 | 未定义风格 | 添加角色和语气设定 |
| 内容太浅 | 未要求深度 | 添加分析维度和深度要求 |
| 太啰嗦 | 未限制长度 | 添加字数/段落限制 |
| 缺失信息 | 未列明要求 | 使用检查清单确保完整 |

## 魔法句式

### 开场句式

- "你是一位..."
- "作为[角色]，请..."
- "假设你是[专家]..."

### 任务句式

- "请帮我[动作][对象]"
- "生成/创建/撰写..."
- "分析/评估/比较..."

### 约束句式

- "要求：..."
- "注意事项：..."
- "禁止/避免：..."

### 格式句式

- "按以下格式输出：..."
- "使用Markdown/JSON/表格..."
- "输出结构为：..."

### 质量句式

- "确保..."
- "重点关注..."
- "优先考虑..."

## 最小可行Prompt公式

```
[角色] + [任务] + [输入] + [输出格式]
```

**示例：**

```
作为Python专家，请审查以下代码并指出问题，
使用Markdown列表格式输出。

代码：
[代码内容]
```

## 快速自检 ✓

发送前问自己：

1. ❓ AI知道自己是谁吗？（角色）
2. ❓ AI知道要做什么吗？（任务）
3. ❓ AI有足够信息吗？（上下文）
4. ❓ AI知道怎么输出吗？（格式）
5. ❓ AI知道什么不能做吗？（约束）

## 领域速查

### 代码相关

- 指定语言版本
- 要求类型注解
- 包含测试用例
- 遵循编码规范

### 文案相关

- 定义目标受众
- 指定语气风格
- 限制字数篇幅
- 提供参考案例

### 分析相关

- 明确分析维度
- 要求数据支撑
- 给出可操作建议
- 指定对比基准

### 创意相关

- 定义创意方向
- 给出约束边界
- 要求多个选项
- 说明应用场景
