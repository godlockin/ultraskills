# Example 2 — Conflict handling

When `git pull --ff-only` fails, the script falls back to `git pull --rebase --autostash` and applies heuristic autoresolve on lockfile/deps conflicts.

## Command

```bash
bash $SKILL_DIR/scripts/git-batch-sync.sh ~/working/sourcecode
```

## Output (partial — conflict scenario)

```
[5/42] my_projects/web-app
  branch=main ahead=0 behind=3
  ⚠ dirty: 2 files
  ⚠ ff-only failed → rebase --autostash
    From github.com:me/web-app
     * branch            main       -> FETCH_HEAD
    Rebasing (1/3)...
    CONFLICT (modify/delete): package-lock.json deleted in HEAD and modified in upstream...
  ⚠ CONFLICT, attempting autoresolve...
    ↪ theirs: package-lock.json          ← auto-resolved
    ✗ manual: src/api/handler.ts          ← needs human
    ✗ manual: README.md                   ← needs human
  ✗ unresolved: 2 → src/api/handler.ts,README.md
  ⚠ stash pop conflict (run: git stash list)
```

## What happened

1. Dirty working tree detected (2 files)
2. `git stash push -u` before rebase
3. `git pull --ff-only` fails (diverged)
4. Falls back to `git pull --rebase --autostash`
5. Rebase hits conflicts on 3 files:
   - `package-lock.json` → matches autoresolve pattern → `--theirs` (will be regenerated by `npm install`)
   - `src/api/handler.ts` → code conflict → rebase aborted
   - `README.md` → code conflict → rebase aborted
6. `git rebase --abort` runs
7. `git stash pop` tried to restore — conflicted, told user to use `git stash list`

## Recovery

```bash
cd ~/working/sourcecode/my_projects/web-app
git status                  # check state
git stash list              # find the stash
git stash pop               # or specific: git stash pop stash@{0}
git rebase upstream/main    # or origin/main after manual resolve
# resolve conflicts in src/api/handler.ts and README.md
git rebase --continue
```

## Policy

| File pattern | Auto-handled |
|---|---|
| `package-lock.json`, `yarn.lock`, `pnpm-lock.yaml` | `--theirs` |
| `Cargo.lock`, `poetry.lock`, `composer.lock`, `Gemfile.lock`, `go.sum` | `--theirs` |
| `*.min.js`, `*.min.css`, `dist/*`, `build/*` | `--theirs` |
| `.DS_Store`, `.idea/*`, `.vscode/*` | `--theirs` |
| **Everything else** | abort + list |
