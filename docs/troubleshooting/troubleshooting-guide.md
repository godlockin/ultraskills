### Quick Diagnostics

Run this command first to check system health:

```bash
# Verify index exists and is valid
python3 devops/ultraskills-hub/scripts/search.py --clusters >/dev/null && echo "✅ Index OK" || echo "❌ Index broken"

# Check skill count
python3 -c "import json; d=json.load(open('index.json')); print(f'Skills: {len(d[\"skills\"])}')"

# Verify arena data
python3 -c "import json; d=json.load(open('index.json')); winners=[s for s in d['skills'] if s.get('arena',{}).get('is_winner')]; print(f'Winners: {len(winners)}')"
```

### Common Errors

#### 1. Index Not Found

**Error:**
```
{"error": "index.json not found at /path/to/ultraskills/index.json"}
```

**Cause:** `index.json` missing from repo root.

**Solution:**
```bash
# Rebuild index from scratch
python3 scripts/arena_scan.py && \
python3 scripts/arena_cluster_score.py && \
python3 scripts/arena_build_index.py
```

---

#### 2. Index Corrupted / Invalid JSON

**Error:**
```
❌ index.json is corrupted or incomplete (invalid JSON: ...). Run:
   python3 scripts/arena_scan.py && ...
```

**Cause:** 
- Interrupted build process
- Git merge conflict
- Manual edit introduced syntax error

**Solution:**
```bash
# Option 1: Rebuild
python3 scripts/arena_scan.py && \
python3 scripts/arena_cluster_score.py && \
python3 scripts/arena_build_index.py

# Option 2: Reset from git
git checkout HEAD -- index.json
```

**Verify fix:**
```bash
python3 -c "import json; json.load(open('index.json')); print('✅ Valid JSON')"
```

---

#### 3. Missing Required Keys

**Error:**
```
❌ index.json is corrupted or incomplete (missing required key 'skills'). Run:
```

**Cause:** Index generated by incompatible script version.

**Solution:**
```bash
# Full rebuild
python3 scripts/arena_scan.py && \
python3 scripts/arena_cluster_score.py && \
python3 scripts/arena_build_index.py
```

---

#### 4. Skill Not Found

**Error:**
```json
{"error": "skill not found: my-skill"}
```

**Possible Causes:**
1. Skill doesn't exist
2. Skill exists but not indexed
3. Typo in skill name

**Diagnosis:**
```bash
# Check if skill directory exists
ls -la community/my-skill/SKILL.md 2>/dev/null || echo "Directory not found"

# Check if skill in index
grep -l "my-skill" index.json || echo "Not in index"

# Search with partial name
python3 devops/ultraskills-hub/scripts/search.py my-skill
```

**Solution (if skill exists but not indexed):**
```bash
python3 scripts/arena_scan.py && \
python3 scripts/arena_cluster_score.py && \
python3 scripts/arena_build_index.py
```

---

#### 5. Zero Search Results

**Symptom:** Search returns empty `results` array.

**Causes:**
1. No skills match query
2. Query terms too specific
3. Chinese text not tokenized correctly

**Solutions:**

```bash
# Try broader terms
python3 devops/ultraskills-hub/scripts/search.py review
# Instead of: python3 devops/ultraskills-hub/scripts/search.py "code review best practices"

# Check "did_you_mean" suggestions in output
python3 devops/ultraskills-hub/scripts/search.py vidoe  # typo → suggestions

# For Chinese, try single characters
python3 devops/ultraskills-hub/scripts/search.py 视频
# Instead of: python3 devops/ultraskills-hub/scripts/search.py 视频剪辑软件
```

#### 6. Arena Pipeline Errors

##### scan.py fails

**Error:** `FileNotFoundError` or `SKILL.md not found`

**Cause:** Directory structure changed, missing SKILL.md files.

**Solution:**
```bash
# Validate skill directories
python3 devops/skill-manager/scripts/scan_and_check.py .

# Fix individual skills
python3 devops/skill-manager/scripts/scan_and_check.py --health community/broken-skill/
```

##### cluster_score.py fails

**Error:** `KeyError` or `skills_inventory.json not found`

**Cause:** `arena_scan.py` didn't run or failed.

**Solution:**
```bash
# Run scan first
python3 scripts/arena_scan.py

# Then cluster
python3 scripts/arena_cluster_score.py
```

##### build_index.py fails

**Error:** `scores.json not found` or merge errors

**Cause:** Previous steps incomplete.

**Solution:**
```bash
# Full pipeline (always run all 3)
python3 scripts/arena_scan.py && \
python3 scripts/arena_cluster_score.py && \
python3 scripts/arena_build_index.py
```

#### 7. Skill Loading Fails in Claude Code

**Symptom:** Skill invoked but Claude says "skill not found" or loads wrong content.

**Causes:**
1. Skill not deployed to `~/.claude/skills/`
2. SKILL.md has invalid frontmatter
3. Path mismatch between index and actual location

**Diagnosis:**
```bash
# Check if deployed
ls ~/.claude/skills/my-skill/SKILL.md

# Validate frontmatter
head -20 community/my-skill/SKILL.md

# Check path in index
python3 devops/ultraskills-hub/scripts/search.py --id my-skill
```

**Solution:**
```bash
# Redeploy
python3 scripts/deploy_skills.py deploy --winners

# Or deploy specific skill
cp -r community/my-skill ~/.claude/skills/
```

---

#### 8. YAML Frontmatter Errors

**Error:** Skill parsed incorrectly or fields missing.

**Common Issues:**

```yaml
# ❌ Missing dashes
name: My Skill
description: Does things

# ✅ Correct
---
name: My Skill
description: Does things
---
```

```yaml
# ❌ Unquoted special characters
description: Use : colons : freely

# ✅ Quote strings with special chars
description: "Use : colons : freely"
```

```yaml
# ❌ Tabs instead of spaces
---
name:	My Skill  # Tab character!

# ✅ Use spaces only
---
name: My Skill
```

**Validate:**
```bash
python3 -c "
import yaml
with open('community/my-skill/SKILL.md') as f:
    content = f.read()
    if content.startswith('---'):
        fm = content.split('---')[1]
        yaml.safe_load(fm)
        print('✅ Valid YAML')
"
```

---

#### 9. Git Submodule Issues (external/)

**Symptom:** Skills in `external/` show as empty or missing.

**Cause:** Submodules not initialized.

**Solution:**
```bash
# Initialize all submodules
git submodule update --init --recursive

# If corrupted, re-clone
git submodule deinit -f external/broken-submodule
git submodule update --init external/broken-submodule
```

---

#### 10. Permission Errors

**Error:** `PermissionError: [Errno 13]`

**Cause:** File permissions or macOS security.

**Solution:**
```bash
# Fix permissions
chmod -R u+rw .

# macOS: allow terminal access
# System Preferences → Security & Privacy → Full Disk Access → Terminal
```

### 常见错误

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| `index.json not found` | 索引缺失 | 重建索引 |
| `index.json is corrupted` | JSON 格式错误 | 重建或 git checkout |
| `skill not found` | 技能未索引 | 重建索引 |
| 搜索无结果 | 关键词太具体 | 使用更宽泛的词 |
| Arena pipeline 失败 | 前置步骤未执行 | 按顺序执行三步 |
| 技能加载失败 | 未部署到 ~/.claude/skills | 重新部署 |
| YAML 格式错误 | 缺少分隔符或特殊字符 | 检查 frontmatter |
| 子模块为空 | submodule 未初始化 | `git submodule update --init` |

python3 devops/skill-manager/scripts/scan_and_check.py --health community/my-skill/

# 重新部署技能
